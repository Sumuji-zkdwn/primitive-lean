# PRIMITIVE FOUNDRY — 工場を作るゲーム

スマホから遊ぶ（HTML単一ファイル・インストール不要）:
https://raw.githack.com/Sumuji-zkdwn/primitive-lean/main/games/primitive-foundry/play.html

従来のパズル・ROGUE465とは独立した工場自動化ゲームです。Factorioの「採掘→搬送→加工→研究→拡張」という仕組みを参考にした新規コードと独自のCanvas描画で、Factorioのソース・イラスト・音楽はコピーしていません。

## 遊び方

最初から小さな工場の試運転ラインが稼働し、鉄と銅の採掘→精錬→歯車・導線製造→制御回路組立→研究を観察できます。配置を変え、装置を増やし、詰まりを直してください。

物流／製造／補助の建設パレットを選択後、マップ上をタップすると装置を置けます。ベルトは指でなぞって連続配置、曲がり角の向きも自動で接続。「調べる」ではタップで機械を調査、ドラッグで地図を移動。右上のボタンで再生・一時停止・速度を切り替えられます。

研究所が生産した制御回路を消費するごとに研究ポイントが1増えます。研究では、実際の証明参照を集約したグラフを前提関係に使った技術ツリーから新機能を買えます。累積3、10、25ポイントで謎の設計書が見つかり、10ポイントで東部の鉱脈地域が開きます。累積30研究ポイントを生産すると最初の目標達成。その後も操業できます。

## 主要設備とレシピ

- 鉱脈上の採掘機：鉄鉱石または銅鉱石を取り出す。
- 石炭鉱脈上の発電機：鉱脈を消費して電力を供給する。
- 鉄・銅の精錬炉：鉱石1個を板材1枚に変換する。
- プレス機：鉄板2 → 歯車1。
- 巻線機：銅板1 → 導線2。
- 組立機：歯車1 + 導線2 → 制御回路1。
- 研究所：制御回路1 → 研究ポイント1。
- ベルト：1タイル1部品を前方へ運ぶ。行き先が満杯なら止まる。
- 研究後の分配器：受け取った部品を前方／右方へ交互に送る。

これらのレシピや技術効果はゲーム設計であり、Leanの連続数学の帰結ではありません。

## 証明由来の技術ツリー

tech.json には docs/dependency/data/source_edges.json の実際の「ソースファイル間の証明参照」を使い、初期4技術＋追加6技術を定義しました。各前提の元ファイルと証明参照件数を保存し、CIで全辺を元データと照合します。

このグラフは証明の参照を「ファイル単位」で集約したものです。465定理の個々の依存DAGを完全に再現したものではありません。ゲーム中の技術名は独自の表現です。

Core.lean は、ベルト移動・採掘・精錬・組立に関する有限の保存則を形式化します。ブラウザの全JavaScriptの正しさをLeanで証明したという主張ではありません。
