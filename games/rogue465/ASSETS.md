# Third-party game assets and systems (2026-11-23)

The game uses **existing human-made free software and pixel art**, not generated graphics. This is an attribution and source ledger; game mechanics remain distinct from the Lean formal proofs.

## Game system: rot.js v2.2.1 — BSD-3-Clause

- Creator: Ondřej Žára
- Source repository: https://github.com/ondras/rot.js
- Pinned upstream release source: https://github.com/ondras/rot.js/tree/v2.2.1
- Bundled file: `vendor/rot.min.js` (upstream `dist/rot.min.js`)
- **Full mandatory notice:** `vendor/rot.LICENSE.txt` (upstream `license.txt`)
- License: BSD-3-Clause. Copyright and conditions are preserved, including in the single-file bundled HTML.
- Actually used: `ROT.Path.AStar` for monsters' four-neighbour navigation and `ROT.FOV.PreciseShadowcasting` for fog-of-war, radius 5.
- If rot.js cannot load, the engine retains a built-in BFS and a basic line-of-sight fallback; the downloadable `play.html` includes rot.js inline, so runtime network access is not necessary for the system library.

This toolkit is **not** a proof checker and does not alter the kernel-checked original Lean theorems.

## Verification and provenance

- `node --test games/rogue465/free-assets.test.cjs` checks the rot.js API, actual shadowcast occlusion, the enemy A* path, and the presence of the bundled license and pinned source.
- `ui.test.cjs` boots the whole standalone HTML, including the actual inline rot.js, without network.
- `theorems.json` retains its separate, exact original 465-declaration inventory provenance. CC0 art and BSD game-system code provide display/navigation only, and **do not turn relic stat mappings into Lean theorems**.

No third-party sprites are copied into the repository from an unverifiable or restricted license. For a future fully offline graphic edition, download the original Kenney pack and bundle the selected PNGs with their CC0 provenance.
