## 遊び方

3階層を踏破し、「層1・部屋3」の番人を撃破して脱出すると勝利です。生命が0になると終了し、装備は引き継ぎません。部屋には敵・障害物・砂の配分・時に細胞状の胞子があります。敵に近づき方向キーを押すと攻撃、赤く光る敵は次の行動で攻撃します。衝撃波は気力2を消費して周囲の敵にダメージを与え、砂山を崩壊させます。

- 方向キー／隣接マスタップ：移動と近接攻撃。
- 二重観測：敵の隠れた係数 `X` を `E(0)-E(1)` で復元する。解析済み相手には追撃補正がつく。
- 入力極性：`+1`／`-1` に切り替え、`攻撃力 + u X` を変える。入力切り替え自体は手番を使わない。敵を先に観測するか推測で攻めるかを選ぶ。
- 移動の曲がり：直前と向きが変わると曲率チャージが増加する。次の近接攻撃に使われる（連続幾何の**ゲーム用離散化**）。
- 野営：敵を倒した部屋で資金3を使って回復する。
- 部屋制圧：部屋ごとの定理遺物を3つから1つ選ぶ。最大5個、上限では交換先を指定する。
- 結節点4：層0の部屋4で洞察2を払って**実際の符号付きLaakso接続**の平行辺3を反転する。到達可能な層が6状態から12状態へ増える。辺2と辺3は別の入口です。
- 死亡：終了。新しい探索では開始シードが変わる。自動保存・再開あり。

- **[Kenney — Tiny Dungeon](https://kenney.nl/assets/tiny-dungeon) (CC0 1.0)**：16×16ドット絵の主人公・敵・宝箱。改変・商用利用でき、元作者の意向に沿って出典を明記しています。
- 画像は特定GitリビジョンのCC0公開ミラーから取得し、接続不良なら記号表示で遊べます。Leanで定義した世界法則、定理台帳と数値バランスはそのままです。

配布物とライセンスの詳細は **[ASSETS.md](ASSETS.md)** を参照してください。

## 初期465件の正確な取り扱い

**Elastica 214定理 + LinearInput 251定理 = 465定理**です。全509宣言の元証拠は `evidence/local/2026-10-30-f0/joint.json`。本リポジトリには後続の数千件の証明もありますが、`theorems.json` は**初期基線だけ**を抽出しています。CIはこの証拠に対し、465件の名前・ファイルパス・行番号・順番が一致することを直接照合します。

この465件全てをゲーム中に得られる固有の遺物候補として用います。定理名とファイルへの出典がそのまま保存されています。遺物の攻撃力・防御などの **数値効果はゲーム開発者が割り当てたもの**であり、個々の定理がその効果を保証するわけではありません。実際のプレイは一回の探索でこの中から一部を獲得します。

## ＋α：世界法則として利用する既存の形式化

- **LinearInputObservation.recover_coordinate**（初期465の内）：`E=A-uX` の2入力の差から `X` を復元する戦闘解析。Leanの一般実数定理は既存ソースに、整数版の有限検査は `Core.lean` にある。
- **Elastica.Geometry**（初期465の内）：単位速曲線・曲率等のモデルを発想源とする、タイル移動と方向変更のゲーム化。離散チャージが元の連続定理から導出されたとは主張しない。
- **LinearInputLaaksoSigned**（後続）：6頂点6ラベル辺・2枚の層・中央の平行辺の符号による到達可能性の変化。画面内の実際の扉と層移動に実装。
- **ClockAvalancheExample**（後続）：wired sandpileの4粒崩壊・上下左右への配分・シンクへの流出。ここでは9×9の障害物付き有限模型へ拡張し、崩壊が敵や自分にダメージを与えるのはゲーム側の追加規則。
- **LinearInputRule481**（後続）：5セルの重み付き規則を胞子の周期変化として使用。元の3×3トーラス証明を9×9の環境へ適用する時、長期挙動の保証はない。
