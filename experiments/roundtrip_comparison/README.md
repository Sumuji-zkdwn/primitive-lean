### 1.3 GPT側の記述について気づいた点
- `max_abs_energy_derivative_along_shell` は、殻の外の軌道では「軌道全体での \|e′\| の最大値」を表しており、名前と中身が合っていません。
- 「ExponentialWeight.lean から代数的に従う」という説明について:
  - 初期の `exponentialWeight` は曲線 θ に対して定義されたものです。
  - GPT側の p はロジスティック関数で、共通しているのは写像 e ↦ exp(−βe) だけです。この部分は [意味] にとどまります。
  - 一方、e′ の式は初期の `Gradient.inc` の `hasDerivAt_energy_of_velocity` そのものです。ODE も初期の `RegularBand.IsTrajectory` の形（ただし b は定数）そのものです。
- GPT側で「Lean未実施」とされていた H′ の式は、今回 Lean で証明しました（§2 A）。

## 3. 二つの実験の比較

### 3.1 分岐点
両実験は、初期の同じ四次設計エネルギー E(λ, r, u, x, y) と、その勾配 gx, gy から出発しています。

- **GPT側**: `Gradient`・`RegularBand`・`Invariance` を経由し、**設計平面上の時間発展**（散逸的に目標準位へ近づく流れ＋準位面に沿った周回）へ進みました。パラメータは λ = 1, r = 1 > 0 で、ポテンシャルは単一井戸です。
- **こちら（R1〜R13）**: `Observation`・`Calculus`・`Design` を経由し、**時間を使わない最小化**（値関数・包絡）へ進みました。そこから r < 0 の二重井戸を経て `CurvatureBridge`（弧長を時間とみる見方）へ進みました。こちらは `RegularBand.IsTrajectory` も `Invariance` も一度も使っていません。

### 3.2 数学的に同一の構造に到達した箇所（数式として検証済み）
1. **2状態 Gibbs 分布（正準集団）** [Lean]
   - GPT側の観測量 p は、R05 の2状態自由エネルギーの微分です。
   - GPT側のエントロピー H は β(⟨E⟩ − F) に等しくなります。
   - R05 の tanh 型の応答は、同じロジスティック関数を別の座標で書いたものです。
   - 注意: 状態の**指示対象は異なります**。GPT側は「現在の点のエネルギー差 e」と「基準 0」の2状態で、軌道上の観測者が導入したものです。R05 は「設計エネルギーの二つの Maxwell 最小点」です。共通なのは式の形であり、同じ物理系を扱っているわけではありません。
2. **周回項 bJ∇E = 曲率の位相流（ハミルトン流）** [Lean]
   - b = −1, γ = 0, λ = 1/2 のとき、GPT側の ODE は初期の `CurvatureBridge` の流れそのものです。
   - 実際、R07 のソリトンは初期の `IsTrajectory` の解になっています。
   - GPT側の λ = 1 の殻上周回軌道は、α = 1/√2 で割ると λ = 1/2, r = 1 の軌道になります（共役は [Lean]）。そこから κ = √2·x は曲率方程式 κ″ = −κ − κ³/2（σ/k = −1）を満たします（残差 5.8e−7 [数値]）。初期の `forced_curvature_of_phase` により、この同値は一般に成り立ちます。
   - ただし、角度方程式・端点条件までは調べていません。この軌道が弾性曲線であるかどうかは**未検証**です。
3. **H 定理 = 初期の誤差単調性の言い換え** [Lean]
   - `entropy_le_iff_abs` により、「H が増える」ことは「\|e\| が減る」ことと同値です。
   - 後者は初期の `squared_error_antitone` です。したがって GPT側のエントロピー単調性は、初期の体系に対する新しい力学的事実ではなく、同じ事実の別表現です。

### 3.3 共通性が弱い（一般的事実に還元される）箇所
- **独立性の反例と R11・R12 の非加法性**
  - どちらも、乗法的な重み exp(−βe) を別の座標で読んだときの合成則です。
  - `logistic_fgl` と R11 によれば、ロジスティックのオッズ則もべき乗スケーリングも、座標 ρ をうまく選べば ⊕₁ になります [Lean]。
  - しかしこれは、「(ℝ_{>0}, ·) をどんな全単射で運んでも、適当な座標で ⊕₁ と書ける」という一般的な事実にすぎません。共通の中身は「exp は準同型である」ことだけで、**同一構造と呼ぶのは過大評価**です。具体的な法則は異なります。
    - GPT側: p についての有理式による合成。
    - R12: 自分自身の座標で ⊕_{−pβ}（多項式）。
    - R11: 拡大率についての ⊕ₚ。

### 3.4 一方にしか存在しない帰結
**GPT側のみ**
- γ > 0 の散逸的な流れ（目標準位への緩和、殻を引き寄せる集合として見ること）、時間に沿った p と H の推移、周回の周期 ≈ 5.06 [数値]。
- こちらの13往復には、設計平面上の時間発展は一つもありません。
- ただし、e′ と収束の部分は初期の定理群（`RegularBand`・`Invariance`・`StrictEnergy`）にもともと含まれています。GPT側で新しいのは、観測量 p・H の導入と数値の描像です。

**こちらのみ**
- R04・R13: Maxwell の角（一次相転移）と、それが変形しても消えないこと。
  - GPT側の領域（r = 1 > 0）では、最小点が一意なので**起こり得ません**（`unique_minimizer_of_r_pos` [Lean]）。
  - 値関数の片側傾きは、GPT領域で ±0.0005（つまり 0）、R04 領域（r = −1）で ∓1.0002 [数値]。
  - 「GPT側が見落とした」のではなく、パラメータ領域の違いによる帰結です。
- R07〜R10: 二重井戸のセパラトリクス（r < 0 が必要）、キンク角が実際に停留点であること、自己交差、κ = c²y、全回転角 2π とエネルギーのスケーリング。
- R03: 準安定帯、判別式、T₃。R11: 二次エネルギーの損失率則。

### 3.5 同じ既知構造の別表現か
次の3点は、**同じ既知構造の異なる表現**として数式で結べました。

- 2状態の正準集団（GPT: p, H ↔ R05: F, tanh）
- ハミルトン流 J∇E（GPT: 周回項 ↔ R06・R07: 曲率の位相流）
- 誤差の単調性（GPT: H 定理 ↔ 初期の `squared_error_antitone`）

一方で、相転移・ソリトン・停留する弾性曲線・自己交差はこちらにしかありません。散逸的な時間発展と、それに沿った観測量の描像は GPT側にしかありません。

これらの片側にしかない帰結は、いずれも**選んだ分岐（時間発展か最小化か）と、パラメータ領域（r > 0 か r < 0 か）**によって決まっています。r > 0 の領域では、こちらの R4・R7 の現象が成立しないことを Lean で示しました。

逆に、GPT側の勾配流を r < 0 で動かした場合の挙動（二つの殻の間の選択など）は、どちらの実験も調べていません。
