# ARC3 Explorer 0.1.0

2026-10-27（日本時間）。オフライン実行用の初回配布版です。

## 完成した範囲

- 公開MIT探索器を既定のエージェントとして起動。
- 旧自作モデル、記録モデル、ランダム版との比較実行。
- 依存版、出典、LICENSE、評価結果、各ファイルのハッシュを同梱。
- 固定した内容から再現可能なZIPを作成し、展開先で自己検査。

リポジトリ側と展開したZIP側の双方で162テストが成功しました。
展開先からのvc33・seed=3・30呼び出しの確認では1レベル突破し、未処理エラーはありませんでした。
500呼び出しの比較結果はQUICKSTART.mdとreports/を参照してください。

これは実行可能な既存探索器の配布版です。完全クリアや競技への提出は達成していません。
既存探索器のACTION7対応と、475定理の自動適用はこの版に含めません。

## 配布物

`python experiments/arc3/make_release.py --output /path/to/arc3-explorer-0.1.0.zip`

で同じZIPを作成できます。作成済み配布物の情報は `reports/release-0.1.0.json` にあります。
