## モデルに対する最も重要な判断

通常の「ゲルの点の位置変化」だけでは、重力波のTT成分は得られません。そこで内部距離を独立に与えることを試しますが、余分な自由度・拘束の問題が発生します。線形領域では既知のFierz–Pauli対称性で制約できますが、これは**重力の創発とは異なります**。

三次元の正値曲率緩和は平坦化する傾向があります。第10回の \`Z₂\` 2-form の保存量は周期格子に巻き付く構造を消さずに保てますが、局在する粒子ではありません。位相的拘束 \`d²=0\` をEinsteinのBianchi恒等式と無条件に同一視しないこと。

## 追加の検証を進める場合

- 周期境界を必要としない安定した三次元局在構造の条件を見つける。
- 四面体の共有辺整合とローレンツ的な時空更新・拘束代数を別々に監査する。
- 物体の全応力エネルギーへの普遍結合と、重力波の2偏極を同じ作用から示す。
- 既存のSkyrme、Maxwell粘弾性、Regge、Fierz–Pauli、高次形式ゲージ理論の主張と独自の発想を明確に分ける。

**科学的状態**: 現時点では仮説に対する有限検算と反例の台帳。重力のみから既存物理学を復元したとの主張はしません。
