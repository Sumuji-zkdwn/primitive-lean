# Individual original evidence files (automatically extracted)

This directory is a **byte-for-byte checked expansion** of `../original_archives/`.

- `stage_01/` ... `stage_30/`: the **623 original ZIP members** under their original inner paths.
- `supplemental/`: 18 additional loose outputs / preview variants absent or byte-different from the original ZIPs.
- Every source member SHA-256 is checked against the original immutable `manifest.json` before extraction.
- Original 30 ZIP archives and the additional ZIP remain available unchanged in `../original_archives/`.
- For a standalone verification: `python -B -X utf8 experiments/delayed_aether/materialize_original_archives.py --check`.

This directory is a historical evidence snapshot, **not** a validation of the physical theories or a proof that gravity emerged from a gel-like medium.
