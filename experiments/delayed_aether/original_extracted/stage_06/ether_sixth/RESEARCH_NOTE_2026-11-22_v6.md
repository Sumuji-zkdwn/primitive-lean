# 遅延硬化エーテル研究 第6回：非共形な実効計量とその真空障害

日付：2026-11-22（JST）／第5回からの継続。

**分類**：既存物理の計量表現を借りた検算用試験模型。新しいエーテルの実証でも、一般相対論・量子論・素粒子論の復元でもない。第6回は**重力セクターのみ**を重点的に変更し、前回の履歴依存硬化を含む3次元連成時間発展を実装したわけではない。今後の連成モデルへの制約を特定する研究である。

## A. 到達した結論

1. **非共形計量を具体化した**：固定したミンコフスキー計量 `η` と単位時間方向 `n`、変形スカラー `U` から、`g=e^{2U}η+2sinh(2U)n⊗n` を定義。`n` の静止座標で `ds²=-e^{-2U}dt²+e^{2U}d\mathbf x²`。これは TeVeS の静的な disformal 結合に類似した**既知の形式**であり、新規性を主張しない。
2. `U=m/r` とした指数型計量は、標準PPNの `β=γ=1` を満たす。軽い物体、光、時計が共通の物理計量に最小結合するなら、対応する主要な静的弱場効果を共有する。ただし `U=m/r` はまだ外部の真空解として仮定している。
3. **強い場と次の次数で失敗**：厳密な4次元曲率は `R=-2m²e^{-2m/r}/r⁴≠0`（`r>0`）。ゆえにこの計量は真空GRの外部解ではない。グラフ・光偏向・束縛軌道・重力赤方偏移でGRのシュワルツシルト計量と差が出る。
4. **形式的な自己整合スカラー作用を定義**して、物質が存在するときの発生源を `T_{μν}` の変分から得た。静的・共動完全流体なら `ρ+3p` が発生源となり、物体の応力を完全に無視する以前の結合の問題を一部改善する。ただし全エネルギーがGRと同じ仕方で重力源になるとは示せず、宇宙全体の力学ではない。
5. 同じtoy作用に対する一定密度・圧力支持の静的流体球を球対称BVPで数値解。7つの密度で収束。8番目の密度では数値非収束（物理的不可能性は未証明）。
6. **決定的な自由度の障害**：単一スカラー `U` からの線形空間摂動は `h_{ij}=2Uδ_{ij}` なので、任意方向の横波トレースレス（TT）射影が0。一般相対論の2つのテンソル偏極をこの一自由度の模型だけで再現することはできない。
7. GR真空方程式を**外から課す**と、時間・空間伸縮関数の補正係数を2次・3次まで解析的に決定できる。これは修復すべき方程式の必要条件を示すが、「エーテルからEinstein方程式を導いた」ことにはならない。

## B. 計量と主部（速度の共有）

単位を `G=c=1`、重力長さを `m=GM/c²` とする。計量符号 `(-+++)`、固定した `η=diag(-1,1,1,1)` と `η^{μν}n_μn_ν=-1` を用いる。計量 `g_{μν}(U,n)` を

```
g_{μν} = exp(2U)η_{μν} + 2 sinh(2U) n_μ n_ν
```

と定義。優先時間方向の静止座標 `n_μ=(-1,0,0,0)` では

```
g_00=-exp(-2U), g_ij=exp(2U)δij, sqrt(-g)=exp(2U).
```

時空的な主部が確実に同じ因果円錐となるよう、toyスカラー作用と物質作用の候補を

```
S[U,ψ] = -(1/(8πG)) ∫ sqrt(-g(U)) g^{μν}(U) ∂_μU ∂_νU d⁴x + S_m[ψ,g(U)]
```

と置く。ここで `n` の動力学は**導入していない**。`ψ` は任意の物質自由度で、すべての `ψ` は一つの `g` を使って結合すると仮定する（弱い等価原理を**仮定**）。`U` 単独の作用は静止座標で

```
L_U = (1/(8πG)) [exp(4U)(∂_t U)² - |∇U|²]
```

へ簡約し、`U` の小振幅波面速度は `v=exp(-2U)=sqrt(-g_00/g_xx)`。物質の波面速度も、物質の作用が `g` と正の運動項を共有する場合には同じ。形式的には1つの**物理計量**への結合によって揃えたのであって、固定エーテル背景と優先時間方向を除去したわけではない。

物質作用の変分は

```
δS_m/δU = (sqrt(-g)/2) T^{μν} ∂_U g_{μν}
```

（`δS_m=(1/2)∫sqrt(-g)T^{μν}δg_{μν}` の規約）。共動静止完全流体 `T^{00}=ρ/(-g00)`, `T^{ij}=p g^{ij}` で

```
δS_m/δU = sqrt(-g) (ρ + 3p) = exp(2U)(ρ+3p).
```

よってtoy場のオイラー・ラグランジュ方程式は

```
exp(4U)[U_tt + 2(U_t)²] - ΔU = 4πG exp(2U) (ρ+3p)
```

（上式右辺は共動静止完全流体の場合）。静的な場合

```
ΔU = -4πG exp(2U)(ρ+3p).
```

外部真空では `ΔU=0` であり、球対称・無限遠で0の解は `U=m/r`。`m` は内部源を積分して得る積分定数：`m=G∫_0^R 4πr² exp(2U)(ρ+3p)dr`。これは点質量を手で挿入することより一段整合的だが、元の物質場・圧力・状態方程式は**仮定**であり、全エネルギー・運動量をEinstein方程式に結合する構造ではない。

補足：静的な質量ゼロの実スカラー物質では、勾配エネルギーがあっても局所的な `ρ+Σ_i p_i=0` となり得る。**変形エネルギーの存在とtoy重力源が正になることは同値ではない**。表面応力を含む平衡系の総量と局所応力を混同してはいけない。

## C. 真空曲率を直接検算

外部 `U=m/r` で

```
A(r)=exp(-2m/r), B(r)=exp(2m/r),
ds²=-A dt²+B[dr²+r²dΩ²].
```

4次元のChristoffelからRicciテンソルを**直接**構成した独立スクリプト `audit_v6.py` により

```
R_tt=0,
R_rr=-2m²/r⁴,
R_θθ=R_φφ=0 (on respective coordinates),
R=-2 m² exp(-2m/r)/r⁴.
```

Schwarzschild（同じ等方座標）ではRicciテンソルが全成分0。したがって、指数計量の真空GR不一致は厳密な代数的事実であり、観測の誤差ではない。指数計量には有限正半径で `g00=0` となるKilling horizonがない一方、Schwarzschildの等方半径 `r=m/2` では `g00=0`（座標領域の境界）。

## D. 弱場 PPN と修復すべき次数

`u=m/r` とすると、指数計量は

```
A_exp = 1-2u+2u² - (4/3)u³+O(u⁴)
B_exp = 1+2u+2u² + (4/3)u³+O(u⁴).
```

標準の `g00=-1+2u-2βu²`, `gij=(1+2γu)δij` と照合して `β=γ=1`。Schwarzschildの等方計量は

```
A_S = [(1-u/2)/(1+u/2)]² = 1-2u+2u²-(3/2)u³+...
B_S = (1+u/2)^4 = 1+2u+(3/2)u²+(1/2)u³+...
```

なので、まず空間計量の `u²` 係数が `1/2` ずれる。

より構造的には、`ds²=-exp(2w)dt²+exp(2v)dx²` を `w=-u+a₂u²+a₃u³`, `v=u+b₂u²+b₃u³` と展開し、**Einstein真空条件** `R_{μν}=0` を課す。2次の係数は

```
R_tt^(2)    = + 2 a₂ m²/r⁴
R_rr^(2)    = - (6a₂+8b₂+2) m²/r⁴
R_θθ^(2)    = + 2 a₂ m²/r²
```

なので `a₂=0,b₂=-1/4` が強制される。3次も計算すると `a₃=-1/12,b₃=1/12`。これが既知のSchwarzschild関数

```
w_S = log[(1-u/2)/(1+u/2)]
v_S = 2log(1+u/2)
```

の展開と一致。これは**GRの方程式を使った逆算**であり、エーテルの最小規則からの導出ではない（`vacuum_series_v6.py`）。

## E. 光線・軌道・赤方偏移の数値検査

光が通るときの等方計量の光学屈折率 `n(r)=sqrt(B/A)` は指数模型で `exp(2m/r)`、Schwarzschildで `(1+m/(2r))³/(1-m/(2r))`。どちらも外部遠方で1。無限遠で測る衝突パラメータ `b=L/E` について最近接距離 `r0` は `b=r0 n(r0)`。

正確な角度積分

```
α(b) = 2 ∫_(r0)^∞ [ b/(r sqrt(n(r)²r²-b²)) ]dr − π.
```

`y=r0/r=1-t²` と置換して端点特異性を除去し、SciPy求積と `mpmath` 高精度積分で確認。単位 `m=1`。

**不変な条件を揃える比較**：光は遠方で測る `b` を同じにし、周回する質点の軌道は球面の周長から定義する areal radius `R=r sqrt(B(r))` の近日点・遠日点を同じにする。単純に等方座標 `r` を揃えるだけでは比較に座標依存が残るため、改良版 `compare_invariants_v6.py` を使う。

| 検査 | 指数型toy | Schwarzschild GR |
|---|---:|---:|
| 光の偏向、`b=10m` | `0.610437437` rad | `0.590395788` rad |
| 光の偏向、`b=100m` | `0.041306741` rad | `0.041222540` rad |
| `R_p=10m,R_a=14m` の一周期近点移動 | `2.886710006` rad | `2.738166887` rad |
| `R=10m` → 無限遠の赤方偏移 `z` | `0.118325592` | `0.118033989` |

`b=10` は非常に強い場に近い。この数値は現実太陽系の相対誤差ではない。離れるほど両者は同じ弱場極限へ近づくが、厳密には異なる。光子球の臨界衝突パラメータも toy `2e ≈ 5.43656m` とGR `3√3≈5.19615m` で異なる。グラフは `lensing_same_impact.png`, `precession_same_areal.png`。

比較の監査：`audit_v6.py` が4次元曲率の直接計算、43桁精度の光・軌道積分、エネルギー源項の代数確認を行う。結果 `audit_v6.json`。求積差は光で最大 `1.3e-12` rad、軌道で最大 `1.4e-10` rad。`verify_v6.py` の通常精度積分は、比較図・元データを作る。

## F. 外部点質量を使わない流体球の数値解

共動完全流体の静的保存則から、一定の密度 `ρ` を持つ球の圧力は

```
p'(r)=(ρ+p(r))U'(r).
```

球半径 `R=1`、球内部で

```
U''+(2/r)U'=-4πexp(2U)(ρ+3p),
p'=(ρ+p)U'
```

を同時に解く。中心正則性 `U'(0)=0`、表面 `p(R)=0`、外部真空 `U=m/r` との滑らかな接続 `U(R)+R U'(R)=0` を境界条件とする。原点付近は正則展開を用いて小さな `r=1e-4` で開始した。状態方程式は理想化した非圧縮性流体であり、安定な実在恒星のモデルではない。

`static_star_v6.py` により `ρ=0.002,0.005,0.01,0.015,0.020,0.024,0.026` は収束。例えば

```
ρ=0.020, R=1:
m=-R²U'(R)=0.12156940945
m_Newton=(4π/3)ρR³=0.08377580410
m/m_Newton=1.45113
p_center≈0.00138425
∫source dr と境界mとの相対不一致≈1.3e-9
```

流体のエネルギーに圧力と非線形な重み `exp(2U)` が加わることで場の強さが変化する。`ρ=0.028` では今回の境界値計算が非収束だったが、非収束から解の不存在・臨界崩壊を推論することはできない。連続族と分岐点の解析が別途必要。

## G. 線形重力波の決定的な不足

一様背景 `U=0` の近くでは

```
h_ij = g_ij−δij = 2U δij + O(U²).
```

伝播方向 `k` に垂直な射影 `P_ij=δij−k_i k_j/|k|²` を使って

```
h^TT_ij=(P_i^kP_j^l−(1/2)P_ij P^{kl})h_kl.
```

`h_kl∝δkl` だから、恒等的に `h^TT_ij=0`。`verify_v6.py` の乱数64方向の浮動小数検査でも最大誤差 `<5e-17`。比較として `h=diag(1,-1,0)` をz軸方向に伝えるGRの `+` 偏極はTTノルム `√2`。

**したがって、単一変形スカラーからなる本toy模型は、GRで存在する2つの独立したテンソル重力波の自由度を持たない。** スカラーの波動速度を光と揃えても、この問題は解決しない。追加のテンソル的せん断自由度、もしくはそれを生成するより基本的な幾何的仕組みが必要。一般的な preferred-frame の観測制約も残る。

## H. 現段階の地図と次の課題

- **厳密な数学的帰結**：指数型の計量からの `β=γ=1`、非零リッチ曲率、単一スカラーのTT消失、GR真空条件が必要とする `a₂,b₂,a₃,b₃`、toy作用のスカラー場方程式とその物質源。
- **再現可能な数値確認**：不変に揃えた光・軌道・時計の計算、同じ境界条件を持つ圧力支持流体球、独立高精度・曲率監査。
- **追加で仮定したもの**：平坦基準計量 `η`、優先時間方向 `n`、物理計量への普遍的な結合、スカラーの自由な作用、外部での `1/r` 解、流体物質と状態方程式、GRとの比較に用いるSchwarzschild計量。
- **未導出**：ローレンツ対称性を生じさせる機構、優先フレームの除去、一般共変な動的テンソル重力、TT重力波、Skyrme／ゲージ局所構造とスカラー源の自己無撞着連成、前回の遅延硬化模型の共有物理計量への完全な再定式化、量子場の理論・標準模型。

**次の最短課題**：スカラーの局所伸縮 `U` に加えて、内部接続またはせん断からトレースレスな2つの伝播モードを作り、**最初に**「その作用からGRの線形化真空方程式が出るか」を厳密に検査する。そこまで進まない限り、係数をシュワルツシルトへ寄せるだけでは本質的な統一にならない。
