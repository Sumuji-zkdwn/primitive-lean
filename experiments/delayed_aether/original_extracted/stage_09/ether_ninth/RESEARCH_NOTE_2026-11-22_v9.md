# 遅延硬化エーテル模型 第9回：四面体Regge幾何と非線形局所ゲージ・記憶

2026-11-22（日本時間）／第8回からの継続

## 結論

**確定（有限模型）**：四面体4個を中心で接合した三次元Regge幾何では、平坦背景において内部頂点の位置変更に対応する零方向が厳密に3つ存在する。内部の辺長を独立に変更すると角度欠損が生じ、同じ単純な頂点移動則では角度欠損は保存されない。これを有限数値検算した。

**確定（別の有限模型）**：同じ四面体複体の辺にSO(3)の輸送行列を置き、三角形ホロノミーの曲率型変数に遅れて追従する記憶を導入すると、**非線形な局所的SO(3)フレーム変換**に対してエネルギーと更新則が厳密に共変になる。これは代数的な証明があり、128個のランダムな例で丸め誤差まで検算した。

**確定（散逸試験）**：Regge角度欠損に直接結合した上限付きの硬化記憶を用い、曲率と記憶を時間発展させる正のエネルギー模型を実装した。240ステップでエネルギーは単調減少し、内部曲率は小さくなった。

**未達成**：非線形一般相対論の微分同相対称性、Hamiltonian/momentumの第一級拘束、四次元での2偏極、等価原理、物体の安定した局所化、光速不変の因果円錐。内部SO(3)ゲージ変換は微分同相変換ではない。三次元Reggeは局所重力波の二偏極の証明には使えない。

## 1. 四面体4個から構成するRegge模型

外側の4頂点を

```
v0=(1,1,1), v1=(-1,-1,1), v2=(-1,1,-1), v3=(1,-1,-1)
```

に置き、内部頂点4を中心に置く。四面体は `[4,0,1,2]`, `[4,0,1,3]`, `[4,0,2,3]`, `[4,1,2,3]`。外側の辺6本は全て長さ `sqrt(8)`、内部辺 `r_i` は初期値 `sqrt(3)`。4本の内部辺が内部hingeとなる。各四面体の二面角は6辺長からグラム行列を使って算出する。内部hinge `i` の角度欠損は

```
delta_i = 2*pi - sum_{tet containing edge(4,i)} theta(tet,edge(4,i)).
```

平坦状態では3個の二面角がそれぞれ `2*pi/3` なので `delta_i=0`。中心頂点を外側の四面体内で移動し、スポーク長を幾何的に計算し直す限り、**有限な頂点移動に対して**角度欠損はゼロである（各三角錐が隙間なく一つのユークリッド四面体を分割するため）。256個のランダムな内部頂点移動で最大欠損 `7.11e-15`。

### 対称性の零方向は厳密に3つ

応答行列 `J_ij = d delta_i / d r_j` を考える。正四面体の対称性から平坦状態で `J_ij=c` は一様。全スポークを同時に `r=sqrt(3)+eps` と変えれば、

```
cos(theta) = (r^2 - 4) / [2*(r^2-2)]
delta(r) = 2*pi - 3*acos(cos(theta))
```

より `d delta / dr` は `r=sqrt(3)` で正確に12となる。したがって `4c=12` なので **`J_flat=3 * ones(4,4)`** と厳密に得られる。固有値は `{0,0,0,12}`。

一方、内点 `x` の移動がスポークへ与える一次の変化は `d r_i/dx = -v_i/sqrt(3)` であり、4本について合計ゼロ（`sum_i v_i=0`）。この3方向は `J_flat` の核を張る。

### 内在辺長を独立に変えた場合

`r_0` だけ8%増大させ、他は保持する。角度欠損は `[0.307024,0.360391,0.360391,0.360391]` rad。`J`の対称化固有値は `[-0.414717,-0.331314,-0.331314,9.423452]`。零固有値はない。この曲率あり状態は**真空Regge方程式の解ではない（off shell）**。したがって「一般の曲率あり解で微分同相対称性が破れている」という証明にはならず、**単純な平坦背景の頂点移動則を曲がった非平衡配置に延長しても幾何不変性は保たれない**という有限反例である。

境界の二面角も含むRegge作用

```
S = sum_{interior edges e} l_e * delta_e
  + sum_{boundary edges e} l_e * (pi - sum_theta_e)
```

の内部辺長微分は、Schläfli恒等式により `dS/dr_i=delta_i` となる。数値差分の最大誤差は `5.61e-10`。平坦背景のHessianが上の`J_flat`になり、3方向の零モードが現れる。

## 2. 別経路：局所フレーム回転と記憶を非線形で厳密に保つ

頂点数5、辺数10、三角面数10の同じ抽象的複体に、辺輸送行列 `U_ij in SO(3)` を持たせる。向きを反転すると `U_ji=U_ij^{-1}`。各頂点に独立な `G_i in SO(3)` を作用させる。

```
U_ij -> G_i * U_ij * G_j^{-1}
H_ijk = U_ij * U_jk * U_ki
H_ijk -> G_i * H_ijk * G_i^{-1}
```

三角面の曲率型変数は `F_f=skew(H_f) = (H_f-H_f^T)/2`。各面の記憶`M_f`を面の最初の頂点のフレームに置き、`M_f -> G_i M_f G_i^{-1}`と変換させる。エネルギーは

```
E = sum_faces [3 - tr(H_f) + (kappa/2)*||F_f-M_f||_F^2].
```

トレース不変性とFrobeniusノルムの直交共役不変性により、エネルギーは厳密に局所ゲージ不変。記憶更新

```
M_f(t+1) = (1-lambda)*M_f(t) + lambda*F_f(U(t+1))
```

も非線形な全SO(3)変換に共変。リンクにはEのSO(3)上の左接勾配を用いる群値更新 `U_ij(t+1)=exp(-eta*grad_ij^)*U_ij(t)` を採用した。群上の不変計量に基づく勾配も変換に共変。128組のランダム回転テストで、エネルギー不変性誤差最大 `1.07e-14`、勾配共変誤差 `8.12e-15`、1ステップ後のリンク共変誤差 `5.53e-16`、記憶共変誤差 `3.87e-16`。

記憶のずれから算出する**観測用**硬化係数を `A_f=1+3*tanh^2(||F_f-M_f||/0.24)` とした（注：この`A_f`は今回の群値更新のエネルギーの係数としては戻し入れていない）。初期のリンクへの急激な回転入力後、90ステップで最大硬化係数は約 `3.9876`、最終値は記憶追従率 `lambda=0.05` で `1.0359`、`0.12` で `1.00003`、`0.3` でほぼ `1.0`。各条件のエネルギーは毎ステップ単調に減少。

このSO(3)対称性は **ローカルな内部フレーム対称性** であり、頂点位置・辺長・時空座標を変更する意味での微分同相対称性とは違う。SO(3)リンク輸送とRegge辺長を同じ複体に置いたが、幾何からホロノミーを一意に導く写像や重力の拘束代数は実装していない。

## 3. Regge角度欠損への遅延硬化の直接結合

独立な実験として、4本の内部スポークの角度欠損ベクトル `delta(r)` に遅れて追従する記憶 `m_i` を追加する。正値エネルギーを

```
H(r,m)= (mu/2)*sum_i delta_i(r)^2 + sum_i Phi(delta_i(r)-m_i)
Phi(y)= (k+Delta)*y^2/2 - Delta*a^2*log(cosh(y/a))
mu=0.5,k=0.8,Delta=3,a=0.16
```

とした。ここで

```
Phi''(y) = k + Delta*tanh^2(y/a)
```

なので追加剛性は `0.8 ... 3.8` の間にある。`Phi(0)=Phi'(0)=0`, `Phi''>=k>0`より `Phi(y)>=k*y^2/2`。したがって`H>=0`。

連続時間の勾配流

```
rdot = -alpha * grad_r H
mdot = -beta * grad_m H
```

では `dH/dt=-alpha*||grad_r H||^2-beta*||grad_m H||^2<=0` が厳密。`grad_r H=J(r)^T*(mu*delta + Phi'(delta-m))`, `grad_m H=-Phi'(delta-m)`。数値更新では、必要ならラインサーチで一歩のエネルギー減少を保証した。

曲率を入れた初期値で240ステップ計算：エネルギー `0.582834 -> 2.45e-7`、最大角度欠損 `0.360391 -> 0.0004097`、最大の記憶剛性 `3.67023 -> 0.800007`。エネルギー増大ステップは0。240ステップの刻みを半分にした480ステップ版では最終最大欠損 `0.0002051`。結果が連続時間に収束する傾向を確認した。

**負の重要結果**：外部源・位相的障害のないこの正値エネルギーでは、`delta=0,m=0`の平坦配置が全体の最低エネルギーを達成する。ゆえに、この遅延硬化だけで、非零曲率を持つ永久の「物体」を**基底状態として**安定化させることはできない。曲率を作る源、位相的保存量、またはその他の保存・非平衡維持機構が必要。局所的な準安定構造まで全否定するものではない。

## 4. 到達範囲と次の課題

1. 辺長から内部幾何と曲率を作る有限Regge部分：成立。ただし3次元・固定境界・オフシェル反例。
2. 局所内部SO(3)フレーム対称性と有限記憶更新：成立。**微分同相ゲージではない**。
3. 角度欠損に応じた記憶硬化と正値散逸：成立。これは緩和力学であり、相対論的な有限伝播速度の保証はない。
4. 四次元Lorentzian単体へ拡張し、辺長から計量、三角ヒンジ欠損、離散Hamiltonian/運動量拘束の保存を検証する。
5. 内部SO(3)リンクを幾何的なLevi-Civita接続から構成し、辺長・リンク間の独立自由度を減らす。
6. 平坦化以外の結果を得るため、局所保存量や位相安定化を導入し、同じ枠組みに安定した局在源を実現する。
