# 遅延硬化エーテル模型 第5回：共通の因果円錐、局在の不可能性、重力のスカラー限界

日時：2026-11-22（JST）。第4回の `RESEARCH_NOTE_2026-11-22_v4.md` から継続。これは**実在のエーテルや新しい重力法則の発見ではない**。既存の波動写像・ヤン＝ミルズ＝ヒッグス・スカラー重力の理論を、これまでの構想に照らして比較し、実行可能な有限検算と反例を構成した研究記録である。Leanでの形式化、現実の観測データへのパラメータ適合、4次元GRの導出は未実施。

## 1. 今回の結論

1. **厳密に成立する条件付きの改善**：標準的な時空計量を**先に仮定**した二場の非線形シグマ模型では、変形履歴の差によって空間方向の剛性が増しても、時間方向の慣性も同じ係数で増すため、すべての滑らかな背景に対し局所的な特性円錐をミンコフスキー光円錐に一致させられる。これは速度の「真空でのパラメータ調整」より強いが、相対論を創発させたことにはならない。
2. 二場模型を一次元格子で実際に時間積分し、内部状態の差による一時的な硬化（最大係数 `A=3.83276`）と全エネルギー保存（相対誤差 `1.45e-10` 以下）を確認。256点と512点で最大硬化の差は `0.000278`。
3. 硬化した領域は**波の速さを変えなくてもインピーダンスを変えられる**。凍結した係数が左 `1`・右 `3` の界面では理論上エネルギー反射率が `1/4`。一次元差分で `0.2500083`（透過率 `0.7500250`）。ただし凍結界面は二場の自己無撞着解ではない。
4. **厳密な反例（Derrick縮尺）**：この二場作用だけでは三次元の安定した静的「粒子」に足りない。正の二階微分エネルギー `E2` と正のポテンシャル `E0` は、半径 `R` への縮尺で `R E2+R³E0` となり、`R→0` で減少する。これまでのSkyrme項や、別の場の機構が必要。
5. **既存の回避例**：ヤン＝ミルズ＝ヒッグス系のBPS磁気単極子は、時間的な高次微分なしに三次元局在構造を持ち、同じ標準光円錐に従う既知の模型である。既知の閉形式解を数値的に検算した。ただし、新たなゲージ場を仮定するため、エーテル模型からの自動導出ではない。
6. **重力への反例**：一つのスカラー場だけで物質を共通の共形計量 `g_{μν}=Ω²η_{μν}` に結合しても、光は曲がらない。現実の太陽縁の偏向 `約1.751''` に対して予言は `0''`。単なる「重力らしい1/rの場」と一般相対論は異なる。

## 2. 作用と局所因果円錐：導出

時空を **固定した** `η_{μν}=diag(-1,1,1,1)` とする。二つの実スカラー場 `u,z` と `y=u-z` を用いる。

```
A(y) = 1 + Δ tanh²(y/a),   Δ>0, a>0
V(y) = κ y²/2 + λ y⁴/4,     κ>0, λ≥0
S = ∫ d⁴x L
L = - A(y)/2 η^{μν} (∂μu)(∂νu)
    - 1/2 η^{μν} (∂μz)(∂νz) - V(y)
```

`A` は `[1,1+Δ]` に収まり、`A` は `u` の空間勾配（剛性）と時間変化（慣性）に同一の係数として掛かる。

Euler–Lagrange 方程式の最高階微分の係数（主部）を行列で表せば

```
P_AB(ξ) = diag(A(y),1) (η^{μν} ξ_μ ξ_ν).
det P = A(y) (η^{μν} ξ_μ ξ_ν)^2.
```

`A>0` より零点は **正確に** `η^{μν}ξ_μξ_ν=0`。背景 `u,z` の値や一次微分がどれほど大きくても、解が滑らかな限り**局所的主部**の特性円錐は共通である。この証明は低次の質量項・モード分散・大域的解の存在・重力の創発について何も述べない。典型的な非線形シグマ模型の構造と同じであり、数学的新規性を主張しない。

**注意：ここでの「履歴」は減衰記憶でない。** `z` 自体をローレンツ対称な波動場にしたことで、外力下・過渡応答に遅れが生じるが、エネルギーは散逸しない。以前の `τ ż = e-z` という実験室時間に沿った不可逆緩和は**この作用では放棄した**。真に散逸するダイラタンシーを再現するには、多自由度の環境への粗視化、あるいは共変的な物質の流速場と因果的な緩和法則を別途導入する必要がある。

同時並進 `u→u+C, z→z+C` は対称性なので、線形化したモード `(u+z)/√2` は質量ゼロ、`(u-z)/√2` は `m²=2κ` の質量ありモードになる。質量ありモードの**群速度**は1以下であり、両者とも**波面速度**は1。群速度・位相速度・波面速度を混同しない。

正値エネルギー密度：

```
H = [A(y)/2] [u_t² + |grad u|²]
    + [1/2] [z_t²+|grad z|²] + V(y) ≥ 0.
```

局所的なエネルギー運動量テンソルを定義して保存則 `∂μT^{μν}=0` を得られるが、`η` が固定されているのでこれは**重力の場の方程式ではない**。

## 3. 二場模型の時間発展の有限検算

`verify_v5.py` が上記作用をそのまま**空間離散ハミルトニアン**に落とし、4N個の変数 `u,z,pu,pz` に対してDOP853法を使う。空間は周期境界 `L=80`、`N=256,512`。`Δ=3,a=0.3,κ=1.2,λ=0.6`、初期 `u=z=0`、局在した `u_t=0.9 exp(-x²/(2×1.7²))`、`z_t=0`。計算時間 `[0,12]`。

最終的な値（実行スクリプトにassertあり）：

| 量 | N=256 | N=512 |
|---|---:|---:|
| 初期全エネルギー | 1.22033447635 | 1.22033447635 |
| 最大相対エネルギー誤差 | 1.44681e-10 | 1.41812e-10 |
| 最大lag RMS | 0.12886087 | 0.12885207 |
| 最大A(y) | 3.83276487 | 3.83248733 |
| 終端lag RMS | 0.09511086 | 0.09506739 |

初期には両場が一致して `A=1`。パルスで `u` が動いても `z` がすぐには追従しないため `y` が非ゼロとなり、一時的に `A>1` になる。今回の数値は**エネルギー保存と有限時間での一時的硬化**を確かめたもので、漸近的な緩和や散逸性、三次元粒子の安定を証明していない。

## 4. 硬さが違っても波の速さは同じ：界面反射の実験

固定された係数 `A(x)` の線形テスト `A(x)u_tt=∂x[A(x)u_x]` を使う。これは**二場全体の厳密解ではなく凍結媒質の独立ベンチマーク**。左右 `A_L=1,A_R=3` で、どちらも `c=√(A/A)=1`。

連続する変位と応力の境界条件から

```
r_amplitude = (A_L-A_R)/(A_L+A_R) = -1/2
t_amplitude = 2 A_L/(A_L+A_R) = 1/2
R_energy = r² = 1/4
T_energy = (A_R/A_L)t² = 3/4.
```

一次元の保存的差分に右向きのガウスパルスを入れ、`x≈0` の境界で散乱させた：

- 反射率 `0.2500083362`、透過率 `0.7500249954`。
- 全エネルギーの前後差 `3.33e-5`（実装内の測定時刻差による分を含む）。
- 時刻44で左右のエネルギー重心 `-21.9843` / `+21.9843`。速さ1と一致。

**硬化=必ず波の速度が変わる、という先入観が不要になった。** ただし内部状態 `z` を使ってその境界を自己維持させることは、まだできていない。

## 5. 二つの追加不可能性：局所構造と長距離電荷

**Derrickの縮尺**。非負の静的ポテンシャルと二次勾配だけを持つ三次元の任意の滑らかな局在配置に対し、`q_R(x)=q(x/R)` とすると `E(R)=R E2+R³E0`。`E2+E0>0` なら `dE/dR=E2+3R²E0>0` で、縮小方向の変分は必ずエネルギーを下げる。さらに `(u,z)∈R²` 自体に `π3(S³)` のような非自明な次数はない。位相的に重要な `S³` をターゲットに置き換えても、二次微分だけでは縮小する障害が残る。

**無電荷な質量ゼロモード**。同時平行移動のNoether流は

```
j^μ = A(y) ∂^μ u + ∂^μ z,
∂_μ j^μ = 0.
```

滑らかな静的配置で特異源がなく、全球で定義されていれば、任意の球面に対して `∮ j·dS=0`。したがって同時並進対称性から出た質量ゼロモードは、そのままでは一般の局所構造に対する非ゼロの `1/r` モノポール電荷を担わない。**質量ゼロ波があることと、ニュートンの万有引力を源から導けることは別**。

## 6. 既存の安定化ベンチマーク：BPS磁気単極子

三次元の局在と共通の光円錐を同時に実現する既知例として、**Yang–Mills–Higgs**（SU(2)ゲージ場+三成分ヒッグス場）のBPS極限を独立検算した。規格化 `e=v=1`、無次元半径 `r`、既知のPrasad–Sommerfield解：

```
H(r)=coth(r)-1/r
K(r)=r/sinh(r)
H'(r)=(1-K(r)²)/r²
K'(r)=-H(r) K(r).
```

これは代数的に両ODEを厳密に満たす。有限格子（r=.04..25、2000点）の浮動小数監査で、2式の最大残差 `1.80e-13`、`4.05e-15`。静的エネルギー密度を積分した値と境界項の差 `1.9e-5`。厳密な無限空間エネルギーは `4πv/e`（上記単位では `12.5663706144`）。有限半径25内は尾部が残るため `0.96` 倍であり、解析式に一致。

この模型ではゲージ場の磁気エネルギーとヒッグス場の勾配エネルギーが互いに釣り合い、Skyrmeのような**時間に関する高階微分を入れず**に静的な局在構造を維持する。ゲージを適切に固定すれば主部はローレンツ対称である。しかしSU(2)、ゲージ接続、真空期待値、磁荷を**新たに仮定**しており、まだゲル状空間の最小模型から得られたわけではない。電磁単極子の存在の確認でもない。

## 7. 重力への最短ルートの失敗：共形スカラーは光を曲げない

もし一つのスカラー `χ` を「重力の全て」とし、物質が一様に結合する物理計量を `g_{μν}=Ω(χ)^2η_{μν}` とした場合、低速質点にニュートン的引力を生じさせることはできても、光の無パラメータ測地線は `η` のものと同一であり、曲がらない。これはNordström型の理論に既知の障害である。

`g_{00}=-Ω²` と `g_{ii}=Ω²` なので屈折率の比 `n=√(g_ii/(-g_00))=1` がすべての `Ω>0` で成立。今回 `log Ω∈[-0.45,0.45]` の101点で数値確認し `n−1=0` となった（解析では全Ωで0）。

IAUの公称値 `GM☉=1.3271244e20 m³/s²`, `R☉=6.957e8 m` と厳密定義の光速を使うと、GRの太陽縁偏向 `4 GM☉/(c² R☉)=1.7511903256 arcsec`。**共形スカラーは0 arcsec**。これには相対論的な非共形の空間計量成分を入れるなど、別の仕組みが必要である。なお単に `g` を動的計量とし、Einstein-Hilbert項を最初から付ければGRに埋め込めるが、それは**導出ではなくGRの仮定**。

**弱い重力場のための必要条件を追加検算した。** `ds²=-(1+2Φ/c²)c²dt²+(1-2Ψ/c²)dx²`、`Φ=-GM/r`、`Ψ=γΦ` と置くと、光学的屈折率は弱い場で `n≈1-(Φ+Ψ)/c²`。太陽縁 `b=R☉` を通る光について

`α=2(1+γ)GM/(bc²)`。

`γ=-1` が共形計量で `0''`、`γ=0` は `0.875595''`、`γ=1` はGRの `1.751190''`。`weak_field_lensing.py` は `z=b tanθ` 変数変換した光線偏向の積分を64点Gauss-Legendre求積して解析式に一致することを検算する。**γ=1は必要な弱場条件の一つであって、これだけでGRを導出したことにはならない。** 現モデルではγを決める動力学自体が無い。

## 8. 確定・暫定・未確定

**確定（指定モデルに対する数学的事実）**：SPDな標的計量の光円錐因子化；正値エネルギー；静的な3D収縮障害；正則源無しのNoether流零フラックス；共形スカラーの光偏向ゼロ；BPS解のODE・エネルギー下界（いずれも既知構造）。

**数値確認**：格子の一時硬化と保存エネルギー、凍結界面の反射・透過、BPSの残差（物理的測定データではない）。

**未確定**：散逸的な記憶の相対論的模型、ゲルの単一自由度からゲージ場・トップロジカル粒子・重力テンソルが生じるか、全エネルギー運動量への普遍結合、光偏向の再現、物理定数の導出、3D動的安定、量子論への接続。

**次の有限課題**：モードの共通因果円錐を保ったまま、ゲージ接続または同等の内部幾何から静的な三次元局在構造を作り、さらにその応力エネルギーを**外から与えずに**実効的な非共形時空幾何へ結合させられるか。まず非共形計量の光偏向の1次摂動とテンソル源の整合を別々に検算する。
