# 遅延硬化エーテル模型：第8回 — 内在距離の自由度と拘束保存の有限格子実装

2026-11-22 JST / 第7回から継続

## 要約

前回の「空間計量6成分を独立にすると余剰自由度が出る」問題に対して、線形・平坦背景の局所格子模型を構成し、拘束保存を数値的に検証した。結果は**線形の二偏極問題については整合するが、一般相対論の創発ではない**。

- 3次元格子の各サイトに対称内部計量の摂動 `h_ij` と共役運動量 `pi_ij` を置く。両者は6成分ずつ。
- 4つの一次拘束とそれらが生成する4つのゲージ方向を区別すると、非零波数モードで `12 - 2×4 = 4` 位相空間次元 = 2偏極が残る。ゼロ波数の大域モードは別扱い。
- 中心差分を使った局所更新則は、離散Bianchi恒等式、座標微小変更への不変性、拘束の時間発展に関する恒等式を浮動小数点精度で満たした。
- `17³`格子、320ステップで拘束最大残差は約 `9.04e-16`、正準二次エネルギーの最大相対変動は約 `2.91e-6`。
- 一般の4パラメータの局所二次空間エネルギーから、ゲージ不変性だけで係数比 `(1,-2,2,-1)` が選ばれ、運動量トレースの係数も拘束保存から `lambda=1/2` に決定できる。
- 曲率に応答する遅延記憶の試験結合は、拘束保存を壊さず有限時間の散逸を実現した。しかし、四階空間微分が高周波分散を作るため、相対論的な最大波面速度は未確保。

## 1. 内在辺長を計量に変換

一つの四面体で、基準辺方向を `e1,e2,e3` とすると、基点から各方向の平方辺長 `l_{0i}²=g_{ii}` と残りの平方辺長 `l_{ij}²=g_{ii}+g_{jj}-2g_{ij}` が与えられる。よって

`g_{ij}=(l_{0i}²+l_{0j}²-l_{ij}²)/2` (`i != j`)

により対称計量6成分が復元される。正値性が成立する限り局所計量は有効。100個のランダムな正定値例で最大再構成誤差 `1.11e-16`。

**重要な限定:** これは一つの四面体のGram計量の復元にすぎず、共有辺の整合、四面体メッシュの接合、Regge deficit angleを用いた完全な動的格子はまだ実装していない。今回の主計算は立方格子の各サイトに計量を割り当てる有限差分模型。

## 2. 独立距離に拘束を入れる

対称な内部計量摂動 `h_{ij}` と共役運動量 `π_{ij}` を置き、`D_i` を隣接格子点を用いる中心差分、`Δ=Σ_i D_i D_i` と定義する。周期境界かつ奇数格子数を使い、中心差分のNyquist零点を避ける。

4つの拘束は

```
C(h) = D_i D_j h_ij - Δ h_ii = 0
M_i(π) = D_j π_ij = 0
```

線形化3次元Einsteinテンソルに相当する局所演算子を

```
G3_ij(h) = 1/2 [ D_i(D_k h_kj) + D_j(D_k h_ki)
                 - Δ h_ij - D_i D_j h_kk - δ_ij C(h)]
```

と定義する。

ゲージ固定 `n=shift=0` の正準更新則は

```
hdot_ij = 2 π_ij - δ_ij π_kk
pidot_ij = -G3_ij(h)
```

この式は**既知の線形化Einstein / 正準Fierz–Pauli力学**に等価である。係数を説明する次項の逆算は、より基本的な仮定からこの形が選ばれる条件を明確にするが、スピン2場の存在をゲルから導いたものではない。

`D_i D_j = D_j D_i` と周期格子の和の部分積分により、

```
D_j G3_ij(h) = 0                (離散Bianchi恒等式)
dot M_i = D_j dot π_ij = 0
dot C = 2 D_i M_i
```

となる。したがって初期拘束 `C=M_i=0` は時間発展で保たれる。leapfrog離散時間更新でも、同じ線形恒等式を使い拘束が浮動小数点丸め誤差を除き保存される。

非零フーリエモードでは、4つの拘束行列が階数4、4つのゲージ方向が階数4、かつゲージ方向は拘束の核に入ることをSymPyの有理数行列で検査。特にゼロ波数では階数が変わるため、全格子の大域自由度を「全て2偏極」とは主張しない。

## 3. 4パラメータから局所空間エネルギーを逆算

並進不変・空間回転対称・パリティ偶・空間一階差分に関して二次のエネルギーを、部分積分による同値を除いて一般形

```
V(h) = a |D h|² + b |div h|²
     + c (div h) · D tr(h) + d |D tr(h)|²
```

から始める。純座標変更 `δh_ij=D_i ξ_j+D_j ξ_i` について、全ての `h,ξ` に対して `V(h+δh)=V(h)` が成立することを要求する。オイラー演算子が `δh` を消す条件をSymPyで連立一次方程式化したところ、階数3、1次元の核になり

```
(a,b,c,d) = const * (1,-2,2,-1)
```

だけが残った。実装では `(1/4,-1/2,1/2,-1/4)` に規格化した。さらに任意のフーリエ波数ベクトル `q=(qx,qy,qz)` に対して純ゲージのオイラー演算子が恒等的に0となることを記号式として確認した。

この定理は**仮定した4項の範囲に限る**。高次微分、トーション、追加場、格子非等方、非局所結合などを許せば一意性は言えない。また、質量ゼロスピン2場の作用の一意性は既知の結果。

## 4. 運動量の係数も拘束保存から確定

最も簡単な二次運動量エネルギーを

`K(π)=π_ij π_ij - λ (π_ii)^2`

と置く。このとき

```
hdot_ij = 2 π_ij - 2 λ δ_ij π_kk
Cdot = 2 D_i M_i + (4λ - 2) Δ tr(π)
```

となる。`M_i=0` でも `Δ tr(π)` は一般にゼロではない。したがって**全ての拘束を満たす初期状態に対して拘束を保つ**には `λ=1/2` が必要。

有限反例として `π_xx=π_yy=cos(2πz/N)`, 他成分0を `N=17` で与えた。運動量拘束は厳密に0だが、`λ=0`または`λ=1`では `max|dot C|=0.521982...`、`λ=1/2`では数値的に0。

**ここまでの結果は既知の線形スピン2理論の『選択原理』を格子で再構成したことであり、非線形Einstein-Hilbert作用を媒体から導出したものではない。**

## 5. 数値監査

- 3次元局所恒等式検査 `13³`格子：Bianchi残差 `1.47e-17`、ゲージ変換によるG3変化 `2.78e-17`、拘束伝播恒等式残差 `2.78e-17`。
- `17³`格子320ステップ：スカラー拘束残差最大 `9.04e-16`、運動量拘束残差最大 `1.09e-17`、正準二次エネルギー最大相対変動 `2.91e-6`。
- 独立の `21³`格子96ステップ：スカラー拘束残差最大 `1.69e-16`、運動量拘束最大 `7.38e-18`、エネルギー最大相対変動 `1.38e-6`。
- 初期値には非平行な波数の複数のTTモードと純ゲージ変位が混在。二次エネルギーの微小な変動は時間離散化誤差で、厳密な4次元重力エネルギー保存を意味しない。

## 6. 時間遅れを戻す試みと新たな障害

空間曲率 `Q_ij=G3_ij(h)` は純座標変更に不変。したがって内部履歴 `z_ij` との偏差の正値エネルギー

`H_mem = (κ/2) Σ |Q-z|²`

を設け、`τ zdot=Q-z` とすると、定常状態の変形に対する応答遅れが作れる。場の正準方程式に

`pidot = -G3(h)-κ G3(Q-z)`

を追加する（周期格子でG3は自己共役）。`D_j G3_ij=0` のため拘束保存は維持される。連続時間のエネルギー散逸式は

`d(H_0+H_mem)/dt = -(κ/τ) Σ |Q-z|² <= 0`

となる（正準場の項が相殺する場合）。

`17³`格子240ステップ、`dt=.09`, `κ=.5`, `τ=.8` で拘束最大残差 `4.42e-16`、相対エネルギーは `1.0` から `0.50867`。サンプル点列では単調に減少した。

**致命的な保留:** 高周波で内部記憶が凍結すると、TT偏極の分散関係は概ね `ω²=q²+(κ/2)q⁴` となる。格子の細分化極限で高周波速度の一様上界がない。したがって今回の曲率記憶結合は、完全な相対論的模型としては未完成。この模型で「硬化と光速不変が両立した」とは主張しない。

## 7. 次に実装すべきもの

本当に元の仮説に近づくため、記憶変数を曲率に直接結合するのではなく、共通の因果円錐をもつ局所物質自由度へ結合する必要がある。いずれも今後の検証課題：

1. **辺長の共有条件を持つ四面体メッシュ**へ移行し、局所ゲージ条件を維持する。
2. 非線形の辺長更新則で拘束保存が成立するか監査する。線形レベルの成功は非線形では保証しない。
3. 履歴・粘弾性を共変な物質場として構成し、その応力エネルギーの保存から幾何への結合を試みる。
4. 等価原理・重力波の伝播・太陽系の弱場観測・強場観測と比較する。
