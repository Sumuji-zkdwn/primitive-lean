# 遅延硬化エーテル模型・第14回：指数計量、四面体の許容条件、位相を保護する更新則、ローレンツ署名

日付：2026-11-22 JST。第13回（`ether_topology_shear_v13_2026-11-22.zip`）からの差分検証。**これは既存の一般相対論の導出ではなく、有限格子上の構成模型**である。

## 要旨：何が進んだか

1. 三次元の内部距離を **`g_v = exp(B_v)` (`B_v = B_v^T`)** に変更した。全ての有限な対称 `B_v` で `g_v` は正定値である。内部場 q、計量の対数 B、記憶 Z は共通の作用とRayleigh散逸の変分により連成する。
2. **明確な反例**：各頂点の計量が正定値でも、共有辺の長さから決める四面体の実現可能性は自動ではない。長さ `(1,1,sqrt(20))` が一つの三角形に現れる正定値頂点計量の具体例を構成した。
3. この反例への対策として、Freudenthal四面体に特化した**十分条件**を導出した：`max_v ||B_v||_op < 0.039643279588...` なら、今回の共有辺長規則による全四面体のGram行列は正定値。10分割・12分割の時間積分では毎ステップ端点のBが条件を満たした。積分器の中間ドリフトではBは端点間の線形補間なので条件が持続する。
4. 四成分単位場 `q_v∈S³` に対して、各四面体の任意の頂点対の内積が正であることを**一ステップごとに証明可能な範囲で保つ**時間刻み制御を実装した。補間は全ての時刻で非零、従って連続な正規化アフィン補間の位相次数が保存される。**発散するポテンシャル障壁を使わない**が、動力学に対して外部から許容制約を課している。無条件の全時間実行は保証しない。
5. `N=exp(phi)>0`、シフトβ、空間計量 `g=exp B` からADM型四次元計量を構成し、**ローレンツ署名を恒等的に保証**できることを示した。しかし `phi` とβの運動方程式やEinsteinの拘束方程式はまだない。

## 1. 指数計量と作用

箱 `[-1,1]³` を `n³` 立方格子、各立方体をFreudenthalの6四面体に分割する。外周の `q=(1,0,0,0)`、`B=Z=0` を固定する。内部頂点の状態：

- `q_v ∈ S³`：局在した四成分内部状態（正規化した場）
- `B_v ∈ Sym(3)`：対数計量、`g_v=exp B_v`
- `Z_v ∈ Sym(3)`：遅延記憶テンソル

一辺の長さは一意の共有辺値として

`l_ij² = (x_j-x_i)^T exp((B_i+B_j)/2) (x_j-x_i)`.

全体の半離散エネルギーは第13回に準拠し、内部状態の勾配 `S_ab = (D_a q)·(D_b q)` を用いて

`V = V₂ + V₄ + V_B + V_mem`,

`V₂ = (c₂ h³/2) Σ_v sqrt(det g_v) tr(g_v⁻¹ S_v)`,

`V₄ = (c₄ h³/4) Σ_v sqrt(det g_v) [(tr(g_v⁻¹ S_v))² - tr(g_v⁻¹ S_v g_v⁻¹ S_v)]`,

`V_B = (K h /2) Σ_(ij axis edges) ||B_i-B_j||_F² + (m_B²h³/2) Σ_v ||B_v||_F²`,

`V_mem = h³ Σ_v Φ(||B_v-Z_v||_F)`、

`Φ(r) = ((k+Δ)/2) r² - Δ a² log cosh(r/a)`.

係数は第13回と同一：`c₂=1`, `c₄=0.08249624119`, `K=0.35`, `m_B²=1.2`, `k=0.55`, `Δ=3`, `a=0.035`, `μ_B=1`, `μ_Z=0.75`, `γ=0.6`。

`Φ(r) >= k r²/2`（`log cosh s <= s²/2`）なので非負。`S>=0` と `g>0` により `V₂,V₄>=0`。従ってこの半離散エネルギーは下に有界。`g_v=exp B_v` なので正定値性は全ての有限 `B_v` で**解析的**に保証される。数値上は有限精度の制限がある。

作用 `L=T-V`、Rayleigh散逸 `R=(γ h³/2)Σ||dot Z||²_F` から導かれる連続時間半離散力学では、

`d(T+V)/dt = -γh³Σ||dot Z||²_F <=0`.

実装はq方向には単位球面に沿う測地ドリフト、B,Zには速度VerletとRayleigh分割を用いる。`V` の `B` 勾配には対称行列指数のFréchet微分を使用し、ランダムな非可換行列でも有限差分監査した。時間離散での収支は近似的。

## 2. 反例：頂点ごとの正定値性だけでは辺長の三角不等式が破れる

四面体頂点を `x₀=(0,0,0),x₁=(1,0,0),x₂=(0,1,0),x₃=(0,0,1)` とする。

`B₀=B₃=0`、`B₁=diag(0, ln(100), 0)`、`B₂=diag(ln(100),0,0)`。

これらの指数行列は全て正定値。しかし共有辺長規則から

- `l₀₁=l₀₂=1`
- `l₁₂=sqrt(20)=4.47213595499...`

となる。`l₀₁ + l₀₂ < l₁₂` なので、三角形が成立せず、四面体のGram行列も正定値にはならない。**結論：対数計量の指数化とRegge辺長の許容条件を混同しない。**

## 3. 四面体の許容条件の十分条件

Freudenthal四面体では、基準頂点からの3ベクトルによる無次元Gram行列が（頂点2,3の交換まで）

`G₀/h² = [[1,1,1],[1,2,2],[1,2,3]]`.

その最小固有値 `μ=0.307978528369...`。全頂点で `||B_v||op<=b` とすると、各共有辺について

`|l_ij² - |x_j-x_i|²| <= (exp b - 1)|x_j-x_i|²`.

四面体Gram行列の対角要素と非対角要素にそれぞれこの誤差を代入し、Frobeniusノルムで評価すると、

`||G-G₀||₂ <= ||G-G₀||F <= sqrt(58)(exp b-1)h²`.

Weylの固有値摂動不等式より、

`lambda_min(G) >= [μ - sqrt(58)(exp b - 1)]h²`.

したがって、

`b < log(1+μ/sqrt(58)) = 0.039643279588...`

が十分条件になる。これは必要条件ではなく保守的。実際の動力学で`B`が強くなると別の四面体許容監査が必要になる。

## 4. 位相的に安全な一ステップの証明書

頂点状態を `||q_i||=1` とする。四面体の全6頂点対（辺）で `q_i·q_j >= m>0` なら、各点のバリセントリック係数 `w_i>=0, Σw_i=1` に対して

`||Σ_i w_i q_i||² = Σ_ij w_i w_j(q_i·q_j) >= m`.

従って各四面体の正規化アフィン補間 `q(x)=Q(x)/||Q(x)||` はゼロ割を起こさない。時間発展経路でも正が維持され境界を固定すれば、連続写像のホモトピー不変性により位相次数は保存される。

実装の各時間ステップで実際にqが変化するのは単位球面測地ドリフトのみ。各頂点の移動角は `θ_i = dt ||p_i||`。この経路の途中では `||q_i(s)-q_i(0)|| <= θ_i` だから、

`(q_i·q_j)(s) >= (q_i·q_j)(0) - (θ_i+θ_j) >= m - 2 max_i θ_i`.

右辺が正の時だけステップを採用し、負なら半分の時間刻みに分割する。**局所の発散エネルギー障壁は使わないが、外部の更新許容条件を組み込んだ制約付きアルゴリズム**である。許容領域の境界へ接近するとステップが無限に細分化され得る。例えば、n=10では模型時間約0.046付近で現在のガードが継続不能になった。これは物理的な有限時刻特異性を証明するものではない。

## 6. 四次元のローレンツ署名は作れるが、重力法則はまだない

`g=exp B`, `N=exp phi>0`, `shift=beta` として

`ds² = -N²dt² + g_ij(dx^i+beta^i dt)(dx^j+beta^j dt)`.

行列を合同変換すると `diag(-N²,g)` になる。従ってBの大きさにかかわらずローレンツ署名`(-+++)`で、

`det(g_4) = -N²det(g) = -exp(2phi + tr B)`.

これは**構造的な署名保証**であり、Einstein方程式を意味しない。特にN、shiftをどのように決めるか、Hamiltonian・運動量拘束を時間発展で保持できるか、背景依存性を取り除けるかは未解決。空間計量の6成分を動かすだけでは2偏極は自動的に選別されない。

## 7. 何を導出できていないか

- 物質・光・重力波の共通の相対論的な因果円錐
- ハミルトニアン／運動量拘束の非線形保存、4次元微分同相不変性
- 物体に相当する局所構造の無条件・長時間安定性と量子論
- 普遍的なエネルギー運動量への結合、Newton/Einstein方程式の出現
- 3D四面体のRegge角度欠損と4Dの重力方程式の同一視

## 8. 次の有限課題

- 指数化された空間計量のADM形式に、拘束を課した4D作用（最初は既知ADM作用を対照）を接続し、変形・記憶結合の追加によって拘束が壊れるかを計算する。
- qの位相的な許容領域に接近して時間刻みが尽きる問題を、非自明な更新アルゴリズム（局所的な再メッシュまたは位相セル変数）で改善できるか比較する。保護規則を外したのに位相が保存されると主張しない。
- 有限値のBに対する正定値性は厳密だが、辺長許容条件を大振幅の条件で保証することは別の研究課題。
