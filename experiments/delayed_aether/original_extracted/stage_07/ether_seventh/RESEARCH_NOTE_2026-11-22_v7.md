# 遅延硬化エーテル研究：第7回 — 変位ひずみのTT不可能性と内在計量の最小要件

日付: 2026-11-22 JST。第6回の連続研究。

**分類:** 数理的一般論、既知の線形化一般相対論を基準とした構成的検査、有限格子上の例。ゲルからアインシュタイン方程式を導出した結果ではない。

## 0. 今回の要約

1. **決定的な障害:** 通常の弾性体の適合する変位ひずみ `e_ij = (∂i u_j + ∂j u_i)/2` は、非零波数ごとにTT成分が恒等的にゼロになる。したがって通常の変位ひずみだけではGRの二つのテンソル重力波を再現できない。
2. **内在距離は独立に変更できる:** 六三角形からなる2次元離散円錐で、頂点のユークリッド座標変位は曲率（角度欠損）を作らない一方、独立に割り当てた辺長は有限の正・負曲率を作る。
3. **二つのTT波のベンチマーク:** 線形化Einstein（Fierz–Pauli）方程式を基準として用いると、plus/cross二偏極の真空波を実装できる。640格子点、速度 `0.9998001`, `0.9998837`（理論値1）、離散波動エネルギー相対ドリフト最大 `4.44e-15`。
4. **形式的代数監査:** 4次元の線形化Einsteinテンソルについて、Bianchi恒等式、微小座標変換に対する不変性、純ゲージ変位の線形化Riemann曲率が0であること、二つの真空波、Newtonの静的極限を、`sympy` で波数と場の成分を一般の記号として検証。
5. **到達していない点:** TT波を持つ正しい作用は今回は既知の一般相対論から借りた。元のゲル・履歴硬化の最小法則からその作用が選ばれる理由、安定局在構造、量子論、完全な非線形重力は未解決。

## 1. 命題: 変位ひずみのTT射影は消える

`u_i(x)` をR³上の滑らかな変位、`e_ij=(∂_i u_j+∂_j u_i)/2` とする。空間波数 `k≠0` に対して

```
P_ij = δ_ij − k_i k_j/|k|²
TT(e)_ij = (P_i^a P_j^b − (1/2)P_ij P^{ab}) e_ab.
```

フーリエ空間では `e_ij(k) = (i/2)(k_i u_j(k)+k_j u_i(k))`。`P_i^a k_a=0` より第一項は消える。また `P^{ab}e_ab = 0` だから第二項も消え、**`TT(e)(k)=0`**。これは通常のゲルに横波が存在しないという意味ではない。横波の変位は通常 `k⊥u` を満たすが、そこから作られる3次元計量のTT摂動は依然0となる。

さらに時空間全体で `h_{μν}=∂_μ ξ_ν+∂_ν ξ_μ` なら、線形化Riemannテンソル `R^(1)_{μνρσ}(h)=0`。これは平坦背景の純座標変更である。一般の曲がった計量の微小変形を得るには、少なくともこの純変位表現の制約を外す必要がある。

**限定:** 不適合ひずみ、内部欠陥、埋め込み次元の追加、独立接続など他の方法もありうる。新しい独立 `h_{ij}` だけが唯一の可能性であるとは主張しない。

## 2. 独立距離と曲率 — 六三角形の有限模型

正六角形の6頂点を外側に置き、中心と各隣接頂点を三角形で結ぶ。外周辺の長さを1、中心からの内在辺長を一律 `c` とすると、中心角は

```
θ(c)=acos(1-1/(2c²))     (c>1/2)
Ω(c)=2π−6θ(c)            (中心の角度欠損、2次元Regge曲率)
```

- c=0.9 → Ω=-44.9878631507°
- c=1.0 → Ω=0°
- c=1.1 → Ω=+35.5716985271°

これに対し内在辺長をユークリッド座標から再計算する通常の中心点の移動では、中心周囲の角の総和は常に2π。乱数1024条件で最大角度欠損 `1.78e-15 rad`。内在辺長を独立自由度にすると、座標変位ではない本物の局所曲率を持ちうる。

この実験は2次元の離散幾何であり、3+1次元の動的重力、等価原理、運動量保存、Einstein方程式を導くものではない。

## 3. 既知の線形化一般相対論を基準にした代数監査

符号規約 `η=diag(-1,1,1,1)`, `g=η+h`, `h=η^{μν}h_{μν}`, `□=η^{μν}∂_μ∂_ν`。線形化Einsteinテンソルは

```
G^(1)_{μν}=1/2 [
 ∂_ρ∂_μ h^ρ_ν + ∂_ρ∂_ν h^ρ_μ − □h_{μν} − ∂_μ∂_ν h
 −η_{μν}(∂_ρ∂_σ h^{ρσ} − □h)
]
```

とする。`verify_v7.py` は `∂→ik` で任意の4成分波数と対称10成分の `h` を記号変数として、以下を**一般の多項式恒等式として**検査した。

- `k^μ G^(1)_{μν}=0`（線形化Bianchi）。
- `G^(1)(h+k⊗ξ+ξ⊗k)=G^(1)(h)`（純ゲージに不変）。
- `R^(1)(k⊗ξ+ξ⊗k)=0`（純ゲージ曲率なし）。
- z方向の `plus = diag(0,1,-1,0)` と `cross_{12}=cross_{21}=1` について `G^(1)=(k_z²−ω²)h/2`、したがって `ω²=k_z²` で真空解。
- `plus` について `R^(1)_{0101}=ω² h_{11}/2`（振幅規格化1）：波が純ゲージでなく潮汐曲率を持つことの確認。
- 静的 `h_00=-2Φ`, `h_ij=-2Φ δij` では `G^(1)_{00}=2ΔΦ`、残りの `G^(1)_{μν}=0`。既知のEinstein方程式 `G^(1)=8πG T` と `T_00=ρ` を使えば `ΔΦ=4πGρ`。

**線形化Einstein方程式はこの監査で導出した前提ではなく、入力したベンチマークである。** 制約と自由度の充足検査であって、エーテルからの創発の証明ではない。


### 追加: なぜ独立した6成分を置くだけでは不十分か

伝播方向を `k=(0,0,kz)` とし、3次元対称行列を `(hxx,hyy,hzz,hxy,hxz,hyz)` の6変数で表すと、TT射影は階数2の線形作用素であり、固有値は **1が2個・0が4個**。残る4次元の核は、通常の変位ひずみ3次元と等方スカラー変形1次元の和に一致する。この階数・核の恒等式は `polarization_rank_v7.py` によって有理数演算で確認した。

したがって `hij` の独立6成分を波動方程式に従わせるだけなら、一般には余分なモードが残る。適切な制約とゲージ対称性が必要となる。Fierz–Pauli理論はその既知の答えだが、ゲルの局所更新規則から制約が創発するかどうかは未確認。

## 4. 二偏極の時間発展計算

TTゲージの真空線形化場では `∂_t² h^TT_{ij}=∂_z² h^TT_{ij}`。z方向に伝わる波は

```
h^TT_ij = [[a,b,0],[b,-a,0],[0,0,0]].
```

`a,b` を初期ガウス波束として独立に与え、周期境界条件で2次精度の中心差分+leapfrogで追跡した。

- 空間長80、N=640、dx=0.125、dt=0.05、観測時間22
- 波束中心の回帰速度：plus=0.9998001343, cross=0.9998837059
- leapfrog用の厳密な保存離散エネルギー `E_{n-1/2} = dx[1/2 Σ((h^n−h^{n-1})/dt)^2 + 1/2 Σ(Dh^n·Dh^{n-1})]`
- 計算した最大相対エネルギードリフト `4.4408279337e-15`
- TT射影2048方向の検査：変位ひずみの最大ノルム `4.729e-15`、等方場の最大ノルム `1.273e-15`、+および×偏極の再現誤差 `1.024e-15`以下。

離散保存量はleapfrogスキームの不変量であり、フルGRのエネルギーが局所的に定義できるとの主張ではない。

## 5. 「ゲルの記憶」を戻すときの条件

まず、数学的に整合した**収容先**として次の作用を考えられる。

```
S[g,u,z] = ∫d⁴x √(-g) [ M_Pl² R(g)/2
                          −A(u−z)g^{μν}∂μu∂νu/2
                          −g^{μν}∂μz∂νz/2
                          −V(u−z) ]
A(y)=1+Δ tanh²(y/a), Δ≥0, a>0, V(y)≥0.
```

これは共通計量への最小結合と、速度の増大を直接引き起こさない正値のスカラー運動項を持つ**Einstein重力＋二つの物質場**の模型。背景 `u=z=0`, `g=η` では二つのテンソル偏極が標準の速度で伝播する。変分で得る `T_{μν}` を Einstein 方程式に結合すれば `∇^μ T_{μν}=0` が物質場の運動方程式と整合する。

ただし以下の限界を持つ。

- Einstein-Hilbert作用 `R(g)` を最初から置いたので、エーテルから重力の法則を復元していない。
- `u,z` は保存的な場であり、不可逆な遅延硬化・粘弾性をまだ含まない。
- `τ∂_t z+z=u` を真空中に直接書くと、ローレンツ変換で `∂_t` が空間微分も含むため、優先時間方向が生じる。物質の局所4速度を使った `τ v^μ∇_μ z+z=u` は共変的な書き方だが、非平衡・散逸の整合と、その流体4速度の動力学が必要。
- 幾何の安定局在構造（物体）、強い重力場、電磁気・量子論はこの作用から導出していない。

## 6. 次の具体的課題

「Einstein-Hilbert作用を最初から導入しなくても、局所的な内在辺長の更新規則が長波長で `G^(1)=8πG T` に近づくか」を検査する。必要な有限試験は次のとおり。

1. 空間を3次元の四面体格子にして、独立辺長から離散曲率を計算する。
2. 時間方向も含む3+1次元の局所更新規則を与える（拘束を意識する）。
3. 真空線形化で縦・スカラー成分を除去でき、**独立な二つのTT波のみ**が物理モードとして残るか確認する。
4. 保存されたソースを結合した静的解について `G00≈2ΔΦ` と `Gij≈0` を検査する。
5. どの段階で既存のEinstein作用を再入力したか台帳に明示する。

この検査が失敗すれば、単純な局所辺長更新規則では線形重力も再現できないという反例となる。
