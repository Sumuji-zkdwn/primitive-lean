# 遅延硬化エーテル模型 第4回検証：非球対称性・因果的伝播・等価原理の障害

実行日：2026-11-22 (JST)。第3回の正値Skyrme型局在構造 + スカラー長距離場 + 遅延硬化模型から継続。既存の物理法則を導出した、実在するエーテルを発見した、新たな重力理論を検証した、という主張ではない。今回の範囲は、厳密な不等式と有限のPython数値検査。

## 結論

**確定した数学的性質**

1. 基本エネルギーの正の下界 `E>=3 sqrt(2) pi^2 |B| ≈ 41.8731852|B|` は、任意の滑らかな三次元写像 `q:R³→S³` （無限遠で一定）に成立し、球対称性を仮定しない。証明は下に記す。
2. 球対称hedgehogを非球対称・体積保存のアフィン変形で伸ばし、スカラー場 `h` も同時に座標変換する一族について、厳密に `E(eps)/E(0)=[1+2 cosh(2eps)]/3` が成立する。**これはスカラー場を毎回最適化した全変形空間の安定性証明ではない**。
3. 線形記憶枝の波面速度を真空で共通の1に調整することは可能だが、速度分散と固定時間に対する緩和則は消えない。
4. もとの非線形四次記憶と、固定慣性に結合したSkyrme型四次空間勾配は、強い背景変形で局所的な波面速度を任意に大きくし得る。**真空の速度だけを揃えても全背景の共通因果円錐は保証できない**。
5. 非線形記憶エネルギーを飽和型に改めれば、記憶由来の接線剛性には上限を与えられ、散逸不等式と正値エネルギーを維持できる。**しかしSkyrme四次勾配の問題とローレンツ非共変性はそのまま残る**。
6. 現在のスカラー場発生源 `rho2` は、物体の全エネルギーに普遍結合していない。同じ位相次数・同じ静的全エネルギーで実効スカラー電荷が異なる有限エネルギー配置を、実数計算で構成した。

**数値的に確認した事柄**

- `49^3`, `61^3`, `91^3` のCartesian格子で、球対称アンザッツの制約を外した変形試験を実施。場 `h` は都度3Dの線形楕円方程式で再最適化。
- 指定した楕円・せん断・四極・双極・角方向・滑らかなランダム摂動の各方向ではエネルギー増加。全三次元摂動に対する極小性は未証明。
- 連続の位相次数は `B=1`。格子上のJacobian積分はそれぞれ `0.91251,0.94092,0.97384` で、刻みを細かくすると1へ近づいた（離散量は整数そのものではない）。
- 最適化した `h` の方程式残差 `1.6e-10` 以下。縮退した並進モードの人工的エネルギー変化は解像度とともに小さくなり、格子誤差の内部監査になった。
- 飽和型記憶の球対称時間発展（161サンプル）でエネルギー単調減少と `H(t)+D(t)=H(0)` を確認、最大収支差約 `7.83e-9`。**動的な非球対称安定性は未検査**。

## A. 模型と定義

場 `q(x)∈S³⊂R⁴`（内部配向）、`h(x)∈R`（長距離スカラー）を持つ。`q` の各方向微分を `q_i=∂_i q` とする。

```
rho2 = 1/2 sum_i |q_i|^2
rho4 = 1/2 sum_{i<j} (|q_i|^2|q_j|^2 - (q_i·q_j)^2)
c(h) = 1 - g h + (g h)^2/2 = ((gh-1)^2+1)/2 >= 1/2
E_static = ∫ [ c(h)rho2 + rho4 + K/2 |grad h|² ] d³x
```

計算条件 `g=0.5, K=1, q(∞)=(1,0,0,0), h(∞)=0`。radial基準場は `q=(cos F(r), sin F(r) x/r)`、`F(0)=π,F(∞)=0`。前回のradial離散最適化に基づく `E=66.9229465432`（有限半径 `L=16`, harmonic exterior boundary）。ターゲット `S³`、二次・四次エネルギーは既存Skyrme型の**追加前提**であり、単なるゲルの遅延から導出したわけではない。

## B. 三次元に通用する位相的エネルギー下界（厳密）

微分 `Dq` の特異値を `λ1,λ2,λ3≥0` とすると、

```
rho2 = (λ1²+λ2²+λ3²)/2
rho4 = ((λ1λ2)²+(λ2λ3)²+(λ3λ1)²)/2
```

相加相乗平均を3回適用すると各 `i` について

`c λ_i² + λ_j² λ_k² >= 2 sqrt(c) λ1 λ2 λ3`

よって

`c rho2 + rho4 >= 3 sqrt(c) |Jac(q)| >= 3 / sqrt(2) |Jac(q)|`。

`q:R³∪{∞}≅S³→S³` なら `∫ |Jac(q)| d³x >= |∫Jac(q)| = 2π² |B|`。したがって

`E_static >= 3 sqrt(2) π² |B|`。

この正値下界は任意の非球対称写像、任意の `h`、さらに正値の記憶エネルギーを足した場合にも有効である。**ただし局所的な厳密極小、時間発展の大域存在、非球対称摂動への漸近安定性は証明されない**。普通のSkyrme理論の既知手法を今回の係数に合わせたもの。

## C. 厳密な非球対称試験族：アフィン楕円変形

`A_eps=diag(exp(eps),exp(-eps),1)`、`q_eps(x)=q0(A_eps x)`、`h_eps(x)=h0(A_eps x)` とする。`detA=1` で位相次数は不変。等方な球対称基準場の角度積分により、二次形式・スカラー勾配の伸長率は `(tr AᵀA)/3`。四次形式の伸長率は `(tr cof(A)ᵀcof(A))/3`。この `A` では両方同じ `f(eps)=[1+2cosh(2eps)]/3` なので

`E(q_eps,h_eps)=f(eps)E(q0,h0)>=E(q0,h0)`。

`eps=0.15` では `f=1.030225676`、元のradial energyを使った増加は `+2.022791305`。これは同時に `h` を伸長した試験族の厳密結果である。`h` を固定境界下で再最適化したCartesian格子の結果と同一視しないこと。

## D. Cartesian 3D の有限試験（hの非球対称再最適化）

`nonradial_3d.py` は `q` を実際に4成分の `(n,n,n,4)` 配列で保持し、三次元中央差分で `rho2,rho4,Jac` を計算する。`h` は

`(-K Delta + g² rho2)h = g rho2`

を固定Dirichlet境界（基準radial hの外周値）で解く。PCG前処理はDST-IでのLaplace逆演算。境界が有限立方体であるため、静的総エネルギーは先のradial連続値 `66.9229` と直接同一ではない。

## E. 真空の共通波面と、その不十分さ

一次元の線形化した配向波変数 `u` と内部記憶 `z` の例は

```
M u_tt = G0 u_xx + k ∂x(u_x-z)
tau z_t = u_x-z
```

`u=exp(st+ipx)` の分散多項式は

`M tau s³+M s²+tau (G0+k) p² s+G0 p²=0`。

`G0,k,M,tau,p>0` のときRouth-Hurwitz判定が成立：全根の実部は負。`G0=1,k=.9,tau=1.2`、旧 `Mq=1,Mh=2,K=1` に対し、新 `Mq=1.9,Mh=1` と置くと、

```
c_q,front=sqrt((G0+k)/Mq)=1
c_h,front=sqrt(K/Mh)=1
c_q,low=sqrt(G0/Mq)=0.72547625
```

高波数の振動枝は共通波面に近づくが、緩和・分散は残る。さらに `tau z_t=...` は媒質に固定した時間を選び、ローレンツ共変的な真空理論になっていない。

**強い背景での局所的速度上限不在：**

- 四次記憶 `Psi=k y²/2+eta y⁴/4` は `Psi''=k+3eta y²` を持ち、`|y|→∞` で発散する。
- 静的Skyrme項 `rho4` は、ある点で `∂₂q=A v₂`、これと直交する方向の波 `δ(∂₁q)=epsilon v₁`（`v₁⊥v₂`）を入れると、局所的に `delta rho4=A²epsilon²/2`。固定質量 `Mq` の玩具動力学では局所波面速度 `c_local=sqrt((G0+k+A²)/Mq)`。`Mq=1.9`、`A=0,2,5` で `1,1.76218,3.76270`。

後者は**第3回の静的Skyrme四次項＋単純な二次運動項という動的構成に対する反例**であり、時間的な四次項も含む標準的なローレンツ共変Skyrmeラグランジアンの超光速証明ではない。標準Skyrme模型にもハイパーボリシティの条件があり、単純に「標準模型なら全問題解決」とは言えない（Gibbons 2003）。

## F. 硬化の上限を持つ修正と時間発展

記憶差 `y=e-z` の四次ポテンシャルを以下へ置き換える。

`Psi_sat(y)=(k+Delta)y²/2 - Delta a² log cosh(y/a)`。

```
Psi_sat'(y)=(k+Delta)y - Delta a tanh(y/a)
Psi_sat''(y)=k+Delta tanh²(y/a)
k <= Psi_sat'' <= k+Delta
Psi_sat >= k y²/2 >= 0
```

最後の正値性は `log cosh x ≤ x²/2` より。`Psi'` は単調・奇関数で `y Psi'(y)≥0`。前回の遅延法則 `tau z_dot=e-z` なら、履歴による散逸量は `∫ y Psi'(y)/tau >=0`。したがって運動方程式をエネルギー変分で定める限り `dH/dt≤0`。

`k=.9,Delta=6,a=.05,tau=1.2`、同じ外力なしの球対称摂動、修正後の慣性値 `Mq=1.9,Mh=1` で実際に時間積分した。全161点でエネルギー単調減少、最大収支誤差 `7.83e-9`、最大追加剛性 `6.89998 ≤6.9`、模型時刻8での局所形状RMS変位 `0.00024819`。比較した非飽和四次硬化モデルでは `0.00031028`、ただし初期の記憶エネルギーも異なるため、この差を理論全般での「改善率」としては扱えない。

飽和で対処したのは**記憶の剛性無限大**だけであり、Skyrme四次勾配の強背景問題、優先時間、非球対称時間発展はなお未解決。

## G. 等価原理への具体的障害：同じEでも異なるスカラー電荷

場 `h` のソースは `g rho2(1-gh)` であり、その遠方の係数となる実効電荷は `Q=g∫rho2(1-gh)d³x`。全静的E（`c rho2+rho4+K|grad h|²/2`）とは違う量である。

最適化されたradial次数1場 `F0` を `F_R(r)=F0(r/R)` と伸縮して、`h` を各Rで再最適化した。`R=.65` と `R=1.40747420448` の二つは（off-shell）配置として

```
B_small = B_large = 1
E_small = 73.24971322213578
E_large = 73.24971322213659
Q_small = 8.818814712651246
Q_large = 20.21993751149117
Q_large / Q_small = 2.292818045319
```

であり、有限精度の範囲で全Eが同じでもスカラー荷は大幅に異なる。したがって**今の源の定義だけから普遍的な重力質量=慣性質量の結合は導けない**。ただしこれらは静的平衡解ではないので、これをそのまま実験的な等価原理違反と呼ばない。実際の運動時の受ける力や重力的自由落下は未導出。

## H. 評価と次の有限課題

今回の確定事項は、普遍的な位相エネルギー下界、アフィン変形の正のコスト、真空波面速度の調整可能性、強い背景での因果速度上限不在、現在の長距離源と全エネルギーの不一致。数値的には、全3D静的な指定摂動で正のエネルギー増分、飽和型の球対称時間発展で正値・散逸を確認。

**現物理を復元したという結論にはならない。** 局所構造の安定化に用いている `S³` と `rho4` は、既存Skyrme型の構造を持ち込んでいる。次に取り組むのは（i）全Skyrme動力学に時間成分まで含めたローレンツ共変な作用からの方程式導出とハイパーボリシティ検査、（ii）全エネルギー・運動量と整合する長距離場の普遍的結合、（iii）Cartesian 3Dでの真の時間発展とランダム摂動の増幅率の測定。これらは別課題であり、いずれも今回未完了。
