# 遅延硬化エーテル模型 第3回：エネルギー散逸付き時間発展・有限伝播・速度不一致

2026年11月22日（日本時間）。静的・球対称Skyrme型試験模型の**動的拡張**。実在のエーテルや新たな重力理論の発見を主張するものではない。

## 結論（確定／数値的／未確定）

- **数学的に確定（指定した離散模型の代数式として）**：正値エネルギーの保持、記憶内部変数の散逸符号、時間発展における全エネルギー単調減少の微分恒等式。
- **数値的に確認**：球対称の次数1欠陥に局所摂動を加えると、全6条件で模型時間0〜8の間、形状が元の静的プロファイルに近づき、欠陥の有限サイズが残った。離散化間隔0.16と0.08で主要観測値が近い。これは全三次元での漸近安定性の証明ではない。
- **数学的に確定（線形・真空・波動部門）**：長距離スカラー場hの真空方程式を波動型に変更すれば伝播速度 `sqrt(K/M_h)` が定まり、局在した波束の前線は有限速度で進む。
- **数学的な障害（本モデルの選択パラメータ）**：内部配向の伝播速度とスカラー場hの伝播速度は異なり、内部配向の高速・低速応答にも速度差がある。単一の普遍的な光円錐は得られていない。
- **未確定**：非球対称摂動による安定性、連続体極限、ローレンツ対称性、等価原理、重力波、電磁気、量子論など。全物理学の復元には至らない。

## 1. 出発点：前回の正値な静的模型

内部配向場 `q(x)∈S³` の球対称次数1アンザッツ `q=(cos F(r), sin F(r) x/r)` を使う。`F(0)=π`, `F(L)=0`（最外面は真空状態）、領域 `0≤r≤L=16`。以下は球対称変形族であり、球対称以外を扱っていない。

```
ρ₂ = 1/2 (F_r)² + sin²(F)/r²
ρ₄ = sin²(F) (F_r)²/r² + 1/2 sin⁴(F)/r⁴
c(h) = 1-gh+(gh)²/2 = [(gh-1)²+1]/2 ≥ 1/2
E_base = ∫[c(h)ρ₂ + ρ₄ + K/2 |∇h|²] d³x.
```

静的hは前回 `-KΔh+g²ρ₂h=gρ₂` を満たした。今回はこの楕円方程式で毎時刻hを再決定するのをやめ、hに運動項を持たせる。

## 2. 新しい遅延・硬化機構

球対称変形の二つの独立なひずみ成分を

```
e_r = ∂r F,      e_t = sin F/r.
```

とし、各々に内部記憶 `z_r,z_t` を与える。この二成分は球対称に縮約した試験用のもの。現時点では、任意の非球対称変形に拡張できる客観的・共変的構成則ではない。

記憶が変形へ遅れて追従する：

```
τ ∂t z_r=e_r-z_r,     τ ∂t z_t=e_t-z_t.
y_r=e_r-z_r,          y_t=e_t-z_t.
Ψ(y)=k y²/2 + η y⁴/4,       k≥0, η≥0, τ>0.
E_mem=4π ∫₀ᴸ r²[Ψ(y_r)+2Ψ(y_t)]dr.
```

応力と微分剛性の追加分は `σ_mem=k y+η y³`、`G_mem=k+3η y²`。履歴が追いつく定常状態では追加応力は消える。急な変形でずれが蓄積した瞬間に大きな抵抗が生じ、緩和後には消える。これは**一つの粘弾性型の記憶モデル**であり、粒子のジャミングや現実のダイラタンシー流体と同一視していない。

## 3. エネルギーと運動方程式

球対称場の運動エネルギーは

```
T = 4π∫₀ᴸ r² [ M_F (∂tF)²/2 + M_h (∂th)²/2 ] dr.
H = T+E_base+E_mem.
```

波動型の運動方程式を場のエネルギー変分で定める：

```
M_F F_tt + γ_F M_F F_t = - δ(E_base+E_mem)/δF  (半径積分の体積重みによる正規化)
M_h h_tt + γ_h M_h h_t = - δ(E_base+E_mem)/δh  (同上)
τ z_dot=e-z.
```

境界ではFを固定、hには外側の正のRobin境界エネルギーを付ける。実装は有限体積離散化の質量行列を使用。

`c(h)≥1/2`, `ρ₂,ρ₄,Ψ,T,K|∇h|²≥0` だから、**どんな配置でも**

```
H ≥ 1/2 ∫ρ₂ d³x + ∫ρ₄ d³x ≥ 0.
```

さらに運動方程式と記憶更新を代入すると、境界からの仕事がないとき

```
dH/dt = -γ_F ∫ M_F F_t² d³x - γ_h ∫ M_h h_t² d³x
        -(1/τ) ∫{ k y_r²+η y_r⁴ + 2k y_t²+2η y_t⁴ }d³x ≤ 0.
```

これは今回の中心的な**散逸恒等式**である。硬化が現れても、それ自身がエネルギーを無から創り出すことはない。数値積分時には積算した右辺の散逸量 `D(t)` を独立した時間変数として追跡した（`H(t)+D(t)=H(0)` を確認）。

## 4. 時間発展の数値条件と結果

使用定数：`g=0.5,K=1, M_F=1,M_h=2, γ_F=0.25, γ_h=0.4, L=16`。通常格子幅 `dr=0.16`（100セル）。非線形硬化ありなら `k=0.9, η=20`。静的に最適化した欠陥に `δF=0.19 exp(-[r-1.1]²/(2·0.42²))` を加える。`h` と `z` は変形前の静的プロファイルから初期化し、初速度はゼロ。**全条件で同じ初期形状変化**を与えている。

時間積分：SciPy `solve_ivp(method='DOP853')`、`rtol=2×10⁻⁷`, `atol=10⁻⁹`, `max_step=0.025`。`t∈[0,8]`、161サンプル。角運動量励起や非球対称崩壊は計算していない。欠陥の次数1は境界条件で維持されるため、次数の保存そのものは試験による新発見ではない。

形状のずれは、静的プロファイルとの球対称の半径方向質量重み付きRMS（領域全体 `[0,16]`）で測定。初期値は粗格子で全て `0.00509317`。

| 比較条件 | τ | 最終RMS | 最終全エネルギー | 最大瞬間追加剛性 | 最大 `|H(t)+D(t)-H(0)|` |
|:--|--:|--:|--:|--:|--:|
| 履歴なし | — | 0.00135196 | 67.082879 | 0 | 1.3×10⁻¹¹ |
| 速い緩和 | 0.08 | 0.00064115 | 66.933151 | 5.309 | 1.7×10⁻¹⁰ |
| 中程度の緩和 | 1.2 | 0.00028714 | 66.934605 | 7.677 | 7.8×10⁻¹⁰ |
| 遅い緩和 | 4.0 | 0.00083984 | 67.031542 | 8.678 | 9.2×10⁻¹⁰ |
| 線形記憶（η=0） | 1.2 | 0.00028548 | 66.933829 | 0.9 | 2.2×10⁻¹¹ |
| 細格子／中程度 | 1.2 | 0.00028475 | 66.946785 | 7.455 | 4.3×10⁻⁹ |

注意：異なる記憶項では初期の保存エネルギーも異なるため、上表の最終エネルギーを単純に比較して「優れている」と順位付けできない。同じ初期形状変化からの**最終RMS**を主指標とする。ただし有限時間 `t=8` での比較であり、τの普遍的な最適値ではない。

静的基準エネルギー（`dr=0.16`, 先行正値模型）`66.9229465`。中程度の緩和は初期形状変化の約94.36%をRMS比で解消した。非線形硬化ありと線形記憶のみの最終回復率がほぼ同じなので、回復の改善は主に**履歴遅延の導入**による可能性があり、今回の結果だけから四次項の必要性は主張できない。一方で四次項はピーク追加剛性に明確に寄与する。

独立した解像度比較：中程度の緩和で、`dr=.16/.08` の最終RMS相対差約`0.84%`、見かけ半径相対差約`0.18%`、実効源電荷相対差約`0.056%`。積分の全161時点でエネルギーの増加は検出されず、累積散逸との差は上表の程度。最初・途中・最後の状態について数値微分による変分と散逸率の方向微分も確認。

## 5. 周波数依存の硬化：解析結果

線形記憶枝 `η=0` を周期ひずみ `e=e₀ Re[e^{iωt}]` で駆動すると、`τ z_dot=e-z` より、記憶応力の複素弾性率は

```
G*(ω)=k iωτ/(1+iωτ)
G'(ω)=k(ωτ)²/[1+(ωτ)²]
G''(ω)=k ωτ/[1+(ωτ)²].
```

低周波では内部記憶が追従し、追加の弾性率が小さい。高周波では追従できず、追加の保存弾性率がkに近づく。中間周波数では損失が大きい。これは既知のMaxwell型レオロジーと同じ機構で、新規物理の発見ではない（参考：https://doi.org/10.1016/j.jmps.2024.105649）。

## 6. 有限速度で伝わる長距離場

旧第2回模型ではhを毎時刻の楕円方程式で決めていたため、源の変化が遠方へ**瞬間的**に反映される数学的近似だった。今回はhに運動項を追加した。

源がない真空の線形部門、減衰なしのとき、

```
M_h h_tt = K Δh,   c_h=sqrt(K/M_h)=1/sqrt(2)≈0.7071068.
```

球対称では `u=r h` と置くと `u_tt=c_h²u_rr`。初速度ゼロで、r=1.4を中心とした滑らかなコンパクト台の波束（半幅0.3）を与える。初期外縁はr=1.7、遠方rの最初の到達時刻は厳密に `(r-1.7)/c_h`。

| 観測半径 | 解析的な到達時刻 | 実装上の最初の検出時刻 |
|--:|--:|--:|
| 3.5 | 2.545584 | 2.546 |
| 5.5 | 5.374012 | 5.376 |
| 7.5 | 8.202439 | 8.204 |

検出時刻は0.002刻みと強度閾値の影響を受ける。これは**スカラー場単独の真空線形極限**の検証であり、結合模型全体が相対論の因果律を満たす証明ではない。

## 7. 重大な未解決点：伝播速度が揃わない

この試験パラメータでは、真空に近い弱い配向変動qの低速・高速応答の弾性極限（減衰無視）はそれぞれ

```
c_q,slow=sqrt(1/M_F)=1,
c_q,fast=sqrt((1+k)/M_F)=sqrt(1.9)=1.3784049,
c_h=sqrt(K/M_h)=sqrt(1/2)=0.7071068.
```

つまり、**このままでは異なる励起が共通の伝播速度を持たず、相対論的な普遍光円錐を回復できない**。単にパラメータを低周波で揃えても、時間遅延による高周波の剛性変化が速度差を再導入する。高周波・非線形・分散・減衰の扱いを含めた根本的な再設計が必要。さらに、指定した記憶の緩和時間τと媒質に固定した時間微分は優先静止系を選ぶため、**正確なローレンツ共変性は導かれていない**。

これは「相対論の復元に成功」ではなく、その反対の**試験模型に固有の具体的障害**である。

## 8. 主張の範囲・次の有限課題

既存のSkyrme型ソリトン安定化とMaxwell型粘弾性を結合した**有限の数値試験**としては、エネルギー生成なしの動的硬化、局所構造の時間発展、hの有限伝播を一つの枠組みで扱えた。これらの構成要素には先行研究があり、2026年にも球対称Skyrme模型の安定性解析がある（例：https://arxiv.org/abs/2611.05352）。

次の選択肢は、全3Dの非球対称摂動の成長率・エネルギーを実測するか、普遍伝播速度の障害を優先して真空線形化と低エネルギー極限の対称性を詳細に分類すること。現在の模型を「重力理論」として先に命名・公表する根拠はない。
