# 遅延硬化エーテル模型 — 第23回：空間依存ゲージ・二偏極波・記憶場

作成日：2026-11-23（日本時間）

## 要約

第22回では、時間再パラメータ化だけでは Bianchi I 作用の係数 `λ` が決まらなかった。今回は空間依存・**時間依存**の座標の再ラベル付けを含む有限変換を使って、その係数が **λ=1** に限定されることを導いた。非線形な横断計量と記憶場の作用密度について、任意の試験状態512件で、ヤコビアンを含む変換則の最大残差が **6.66×10⁻¹⁶** となった。

別の独立計算では、二つの横方向偏極を含む非線形な Rosen 型平面波と2つの同一 null スカラーの結合について、四次元曲率および3+1のハミルトニアン・運動量拘束を、解析式と数値行列計算で検証した。

**ただし、重力作用は既存の Einstein–Hilbert/ADM 作用を採用している。重力の創発は示していない。** 平面波の厳密解では記憶のずれが0であり、動的硬化は発生していない。今回の二つの成果を混同しない。

## 1. 空間依存の ADM 縮約

空間のうち `x` のみへ依存し、二つの横方向座標 `y,z` に沿った並進対称性を仮定する。これは**一般の3+1次元場を計算したものではなく、一次元に非一様な3+1計量の縮約**である。

\[
 ds^2=-N^2dt^2+e^{2a}(dx+Vdt)^2 +H_{AB}(t,x)dy^A dy^B,
 \qquad A,B\in\{y,z\}.
\]

内部距離の横断ブロックを

\[
H=e^{2b}\begin{pmatrix}e^{2p}&c\\c&e^{-2p}(1+c^2)\end{pmatrix},\qquad \det H=e^{4b}>0
\]

とする。`p` と `c` は線形領域でプラス・クロスの横断偏極に対応する二つの独立な成分を与える。

`U=H^{-1}H_x` と置くと、三次元曲率は

\[
{}^{(3)}R=e^{-2a}\big[-\partial_x\mathrm{tr}U+a_x\mathrm{tr}U
-\tfrac14(\mathrm{tr}U)^2-\tfrac14\mathrm{tr}(U^2)\big].
\]

外部曲率について `K_{ij}=+(1/2)\mathcal L_n\gamma_{ij}` の符号規約を用い、

\[
k_x=\frac{a_t-Va_x-V_x}{N},\qquad
K_T=\frac{H^{-1}(H_t-VH_x)}{2N}.
\]

重力部分は、既知の ADM 理論に従い `√γ N [³R + K_ij K^ij − K²]` を用いる。全体係数 `1/(16πG)` はゲージ変換試験では省略した。

記憶のモデルとして2スカラー `q,z`、差 `r=q-z`、反応係数

\[
A(r)=1+2.5\tanh^2(r/0.45)
\]

を用い、物質作用密度を

\[
\mathcal L_m=\sqrt\gamma N\left[
\frac12 A(r)(D_tq)^2+\frac12(D_tz)^2
-\frac12\gamma^{xx}(A(r)q_x^2+z_x^2)
-\frac12(1.3)^2(q-z)^2\right],
\quad D_tq=(q_t-Vq_x)/N.
\]

ここでの記憶は**可逆的な内部場**である。散逸の生成を仮定していない。

## 2. 時間依存の空間座標変換：厳密な関係

時刻に依存して `x'=f(t,x)` と置き、`J=f_x>0`, `W=f_t` とする。

\[
N'=N,\quad e^{a'}=e^a/J,\quad H'=H,\quad V'=JV-W,
\quad q'=q,\quad z'=z.
\]

したがって `D_t q` もスカラーとして変換される。曲率 `³R`、各 `K` 不変量と物質の運動項もスカラーで、

\[
\boxed{\mathcal L'(t,f(t,x))\,J=\mathcal L(t,x)}
\]

を満たす（座標変換による境界の取り扱いは局所密度の比較で回避）。

第22回で未定だった `e^{λ(a+b+c)}` 型の重力体積係数について、`a+b+c` を空間の3方向の対数スケールの和とすると、変換後の積分密度の因子は `J^(1−λ)`。すべての `J>0` で不変である条件から、

\[\boxed{\lambda=1}\]

が従う。これは**この体積因子の族についての一意性**であり、すべての重力作用の一意性ではない。

### 独立した数値的検査

`f(t,x)=x+0.29sin(x)sin(0.77t)` とし、`a,b,p,c,N,V,q,z` をすべて独立の三角関数として非自明に与えた。シード固定の512点で比較：

| 項目 | 最大絶対残差 |
|---|---:|
| 重力・記憶場の正しい密度変換 | 6.66e-16 |
| `³R` のスカラー変換 | 4.44e-16 |
| 体積密度の変換 | 2.22e-16 |
| **誤った**運動項（`q_t/N` をそのまま使用） | **0.05195** |
| **誤った**shift変換（`−f_t` を省略） | **0.08614** |

正しい規則と間違った規則の差が定量的に現れた。試験は場の方程式を用いない **off-shell** の検証である。

### 反例：空間の対称性だけでは GR は一意でない

`√γ N (³R)^2` を重力作用に追加しても、同じ空間座標変換のもとで密度は不変である。実際、係数0.15で追加した別作用も変換残差は6.66e-16以下だったが、元の作用との差は最大0.07855である。

この項は**全四次元の時間方向の変形まで含む対称性を自動的に満たすと主張していない**。したがって、次は lapse/shift の拘束代数、時間方向の hypersurface deformation、物質結合の整合性を要する。

## 3. 非線形二偏極平面波：厳密に解ける基準模型

光の進行に沿った `u=t-x` を用い、

\[
ds^2=-dt^2+dx^2+H_{AB}(u)dy^A dy^B,
\]

\[
H(u)=e^{2b(u)}R(\theta(u))
\begin{pmatrix}e^{2p}&0\\0&e^{-2p}\end{pmatrix}R(\theta(u))^T,
\quad \theta(u)=ku,\quad b(u)=\ln\cos(\Omega u)
\]

とする。定数 `p`、回転 `θ=ku` により横断のプラス・クロス両成分が非零になる（この厳密解の2偏極の波形は独立に指定した関数ではなく、この回転則で関係づいている）。

四次元リッチテンソルを一般の `H_AB(u)` から計算すると、唯一の非零候補は

\[
R_{uu}=-\tfrac12\mathrm{tr}(H^{-1}H'')
+\tfrac14\mathrm{tr}[(H^{-1}H')^2].
\]

横断の回転行列について

\[
\mathrm{tr}[(M^{-1}M')^2]=8k^2\sinh^2(2p)
\quad(M=R\mathrm{diag}(e^{2p},e^{-2p})R^T)
\]

が厳密に成り立つ。

記憶の内部場を `q=z=σu` とした場合、`q−z=0` なので `A=1`, ポテンシャル0、`T_uu=2σ²`。アインシュタイン方程式 `R_uu=8πG T_uu` は

\[
\boxed{\Omega^2=k^2\sinh^2(2p)+8\pi G\sigma^2}
\]

で成立する。これは既存の一般相対論に従う厳密解であり、**重力の法則を独立に導いていない**。記憶のずれがないため硬化も起こらない。

`p=0.33`, `k=0.30`, `G=0.03`, `σ=0.07` で、`u∈[-3,3]` の601点を別プログラムで計算した：

| 残差 | 最大絶対値 |
|---|---:|
| 四次元 `R_uu−8πG T_uu` | 1.74e-16 |
| ADMハミルトニアン拘束 | 4.04e-16 |
| ADM運動量拘束 | 2.02e-16 |

さらに、四次元Christoffelから直接 `R_μν` を求め、任意の一般的な横断ブロック `H(u)` について、`R_uu` 以外の9個の独立な成分が厳密に0になることを別のSymPyプログラムで検証した。

## 4. 達成・未達成

**今回の新しい確定事項**

1. 時間再パラメータ化で不定だった体積因子の指数は、時間依存の空間再ラベル付けで `λ=1` に固定される（限定族内）。
2. 二つの横断自由度と可逆的な記憶場を含む、一次元に非一様な3+1 ADM 縮約において、作用の空間ゲージ不変性を off-shell で厳密式と512件の数値検算により確認した。
3. 記憶場の非共変な運動項と、shift の誤った変換がそれぞれ不変性を破る、定量的な反例が得られた。
4. プラス・クロス偏極をともに含む既知の非線形重力波と、2つの null スカラーの厳密結合解を四次元曲率とADM拘束から独立監査した。
5. `³R²` という具体的な反例によって、**空間対称性だけでは重力法則の一意性は得られない**ことを確認した。

**未達成・不能な主張**

- 重力のスピン2自由度を、初期の「遅延硬化するゲル」の原始的な変形規則だけから生成すること。
- 任意の3次元に非一様な**完全な4次元の時空微分同相対称性**と拘束代数を、記憶場込みで検査すること。
- 非零の記憶ずれ・非線形硬化・二偏極の非線形重力波が**同時に作用する厳密解**を作ること。
- 温度・内部浴・エントロピーの増加を含む、不可逆な硬化・散逸の共変模型。
- 新しい実験予測と既存物理からの識別。

## 5. 次の有限課題

次は縮約を維持したまま **時間方向と空間方向の両方の変換を含む hypersurface-deformation bracket** を実装し、記憶場を含むハミルトニアン拘束と運動量拘束の Poisson 括弧を検査する。一次元格子の場合は局所密度の形を厳密に定め、境界項、場依存の構造関数と有限差分誤差を分離する。

成功した場合でも、既知の ADM 構造の検算にとどまる。**本当の創発の判定は、スピン2自由度や重力の拘束代数を原始的な変形規則から導けるかどうか**に置く。
