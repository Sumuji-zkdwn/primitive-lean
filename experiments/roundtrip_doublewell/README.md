# GPT側の流れを二重井戸（λ > 0 > r）で動かす

比較記録（[`../roundtrip_comparison/`](../roundtrip_comparison/README.md)）§3.4 で「どちらの実験も調べていない」と書いた領域の調査です。

- **流れ**: GPT側の流れは、初期定理の `LinearInputRegularBand.IsTrajectory` と同じ形です。
  `z′ = −γ(E − T)∇E + b·J∇E`、`J(gx, gy) = (−gy, gx)`
- **パラメータ**: GPT側は r = 1 > 0（単一井戸）でした。ここでは λ = 1、r = −1、γ = 1 です。
  - 井戸の底は ±a₀ = ±1（エネルギー −1/4）、鞍点は原点（エネルギー 0）です。
- **変更しないもの**: 先の13往復と比較記録は変更していません。`assemble.py` は、初期60ファイルと R01〜R13 のSHA-256を記録と照合してから使います。

区別の記号:
- **[Lean]** Lean で証明した命題。初期509宣言、R03・R04、Mathlib だけに依存します。
- **[数値]** 数値計算でのみ確認したこと。
- **[未証明]** 手計算や推定にとどまり、Lean でも数値でも確定していないこと。

python3 -B experiments/roundtrip_doublewell/assemble.py              # Lean

## 2. Lean で示したこと（`D01_DoubleWellFlow.inc`）

| 定理 | 内容 |
|---|---|
| `field_norm_sq`・`rest_iff_of_b_ne` | 速度の大きさの2乗は (γ²e² + b²)·‖∇E‖²。b ≠ 0 なら、流れが止まる点は **R03 のカスプ平衡面 {y = √2x, u = input(x)} にちょうど一致**する |
| `rest_energy`・`const_isTrajectory` | 静止点のエネルギーは初期の臨界値 −3λx⁴/4 − rx²/2 であり、静止点に留まる定数関数は軌道になる |
| `stuck_at_saddle_and_well` | u = 0 では、鞍点と井戸の底に留まる軌道のエネルギー差がそれぞれ −T と −r²/(4λ) − T のまま変わらない。**帯の仮定がないと目標準位には到達しない**ことの具体例 |
| `energy_between` | 初期の `energy_gap_exact` から、エネルギーは常に初期値と T の間にある |
| `barrier`・`confined`・`confined_right` | 初期エネルギーと T がともに障壁 f(c) より低ければ、軌道は直線 x = c を越えない |
| `trapped` | さらに、その側でのポテンシャルの下限 m が T より大きければ、エネルギー差は常に m − T > 0 以上。**目標には決して到達しない** |
| `well_selection` | u = 0、T < 0、初期エネルギー < 0 なら、x の符号は変わらない。到達する殻は、出発した井戸で決まる |
| `mirror` | u = 0 では、b が何であっても z ↦ −z が軌道を軌道に写す |
| `energy_lower_bound`・`unreachable_below_bottom` | E ≥ −r²/(4λ)。T がそれより低ければ、どこから出発しても到達しない |
| `two_shells` | −r²/(4λ) < T < 0 なら、目標準位の集合は左右両方の半平面に点を持ち、x = 0 上には点を持たない（二つの殻） |
| `metastable_rest_point` | R03 の準安定点は、平面エネルギーの局所最小であり、流れの静止点でもある。しかも、それより低いエネルギーの点が存在する |
| `maxwell_wells_equal` | u = 0 では、両方の井戸の底のエネルギーが R04 の値関数の値 −r²/(4λ) に等しい |

## 3. 数値で確かめたこと（λ = 1, r = −1, γ = 1, u = 0）

| 実験 | 結果 |
|---|---|
| **二つの殻**（T = −0.1, b = 0）41×41格子 | 右の殻 840・左の殻 840・鞍点 1。E < 0 から出発した186点で x の符号が変わった例は0件（`well_selection` と整合）。鏡像対称性に反する例も0件 |
| 同（b = 0.5） | 右 840・左 840・鞍点 1。符号変化0件、対称性違反0件 |
| **流域境界**（鞍点の周りの半径0.05の円、720方向） | 境界の角度は b = 0 で 2.3606、b = 0.5 で 1.2872。鞍点で線形化した系の安定方向（2.3562 と 1.2864）と、角度の刻み π/720 ≈ 0.0044 の範囲で一致。**E > 0 から出発した場合、左右の殻は鞍点の安定多様体を境に分かれ、周回項 b はその向きを回す** |
| **一つの殻**（T = 0.3） | 閉じ込めは起きない。E < 0 から出発した44点のうち2点が反対側へ移った |
| **底より下の目標**（T = −0.4） | すべて底か鞍点で止まる。最終的なエネルギー差の最小値は 0.15 で、Lean の下限 −r²/(4λ) − T = 0.15 と一致（底で等号） |

鞍点で線形化した系の固有値は実数で、符号は逆です（b = 0: 0.041, −0.241。b = 0.5: 0.420, −0.620）。手計算では、行列式が (γ²T² + b²)·det H = (γ²T² + b²)·r < 0 となるので、どの b でも鞍点になります [未証明・手計算]。

## 4. Maxwell点の動的な現れ方（u を少し傾けた二重井戸）

全体の最小値を φ(u) = min(f(左の底), f(右の底)) とし、目標を **T = φ(u) + δ** とします。各井戸の底から少しずらした点（エネルギーは底 + 2×10⁻⁶）から出発しました。

- **[Lean] 到達不能側**: 底 > T となる井戸からは決して到達しません（`trapped`）。数値でも、この場合は**全例が未到達**でした。すべての軌道は出発した井戸に留まっています。
- **[数値] 到達側**: 底 < T となる井戸からは目標に到達しました。例外は、底 − T が −2.5×10⁻⁷ や −3.9×10⁻⁹ しかない窓の端だけです。そこでは殻が非常に小さく勾配もほぼ0なので、t = 600 までに収束しきりませんでした（残ったエネルギー差は約2×10⁻⁶）。
- **両方の井戸から到達できる u の窓**:
  - 定義上、窓は「両方の底の差 |f(左) − f(右)| が δ より小さい u」の範囲です。
  - その半幅は数値計算で δ = 0.02 のとき 0.010001、δ = 0.005 のとき 0.002501 でした。一次近似 δ/(2a₀) で、これは R04 の角の片側傾き ±a₀ から決まる値です [未証明]。
  - 実際の軌道で確かめた範囲は、δ = 0.02 で |u| ≤ 0.0075（格子の刻みは0.0025。±0.01 は窓のちょうど端で、上記の未収束例）でした。
- **解釈**:
  - δ → 0 で窓は u = 0 に縮みます。つまり、R04 の値関数の角（静的な一次相転移）は、この流れでは「**どちらの井戸から出発しても目標に届く入力が Maxwell 点だけに縮む**」という形で現れます。
  - 二つの井戸の役割（届く側と閉じ込められる側）は、u = 0 を境に入れ替わります。
  - この対応のうち、閉じ込め側は Lean で、届く側と窓の幅は数値で確かめています。

## 5. 二つの実験の位置づけについて分かったこと

- **GPT側の「目標準位への収束」は、r > 0 の領域、または帯の仮定のもとでの性質です。** 二重井戸では次の三つが起きます。いずれも Lean で示しました。
  - 鞍点や井戸の底に留まる軌道
  - 底より下の目標への到達不能
  - 準安定な井戸への閉じ込め
- **流れが止まる点の集合は、R03 のカスプ平衡面そのものです**（Lean）。静的な往復（R03・R04）と GPT側の時間発展は、ここで直接つながります。
- **意味上の類似にとどまるもの**: 「対称性の破れ」「準安定状態」「流域境界」「動的な一次相転移」という呼び名。数式として示したのは §2 の定理と §3・§4 の数値だけです。

## 6. 未解決のこと
- 「底 < T なら到達する」こと（収束の十分条件）の Lean 証明。初期の帯の定理は臨界点を含まない帯を仮定しているので、そのままでは使えません。
- 流域境界が鞍点の安定多様体と大域的に一致すること。確かめたのは鞍点の近くでの接線の向きだけです。
- 鞍点の線形化と窓の幅の一次近似の Lean 化。
