# 亜Laakso空間：反論可能性を潰すための独立監査と強化定理

日付：2026-11-23。対象：提供された4本のLaakso/砂山研究ノート、および `Sumuji-zkdwn/primitive-lean` PR #171 の形式化資料。原稿中の「砂山から作る空間」は物理砂山の**観測を利用して設計された幾何模型**であり、すべての経路費用・測度・異スケール極限が自動的に砂山力学から導出されるという意味ではない。

## 0. 主張の正確な範囲

証明すること：同一の三進ゲート商、同一の一様標本測度、同一の先頭桁観測、同一の円周因子の上に、二つの長さ座標 `Φ_good`,`Φ_bad` が存在し、あらゆる深さ `m>=0` の**観測ファイバー最大直径** `A_m` は同じである。一方で、`good` は倍加性と弱(1,1)-PIを満たし、`bad` は両方を満たさない。

証明しないこと：任意の有限距離、全ての局所観測、物理的な粒投入費用、あるいは全ての砂山配置が同一だという主張。`A_m` は各深さについて「最大値を一つだけ残した」統計量である。

## 1. 自己完結した模型の定義

`S={0,1}^N`, `T=R/Z` とし、`W_k={j/3^k:0<j<3^k,3∤j}` で高さ `s∈W_k` に限り第 `k` ビット反転を無料で貼る。貼り合わせでは角度 `θ` は保存する。`X=(([0,1]×S)/~)×T`、標本測度 `μ=q_#(ds⊗ν⊗dθ)` を固定する（νは公平なBernoulli積）。任意の増加同相 `Φ:[0,1]→[0,1]` に対し、同一シート上の水平移動費を `|dΦ(s)|`、円周移動費を円周弧長とした道距離を `d_Φ` とする。全ビットの距離は有限段商距離の上限で定める。

高さの弧長座標 `z=Φ(s)` は全ての許容経路に対して **1-Lipschitz** である。特に、ある高さの帯を横切らずに左右の異なる高さへ移動する迂回路はない。`C_n=[ε,2ε]` の内部には `W_1,…,W_n` に属するゲートがないため、`C_n` 内の道は先頭 `n` ビットを変えない。`I_n=[4ε/3,5ε/3]` の両端は `W_{n+1}` に属し、`I_n` 内には全ての `k>n+1` のゲートがある。したがって、`I_n` を両端まで訪れる道は尾部の任意の有限ビット反転を実現する（無限尾部については有限段距離の上限を取る）。

## 2. 重みの具体式と有理数の正規化

`ε_n=3^{-n}`, `ℓ_n=ε_n/3`, `I_n=[4ε_n/3,5ε_n/3]`, `c_n=3ε_n/2`, `S_n=[c_n-ε_n ℓ_n/2,c_n+ε_n ℓ_n/2]`。

- 良い重み：`w_good(s)=89/104` for `0<=s<2/3`, `w_good(s)=1` for `2/3<=s<=1`。
- 悪い重み：各 `n>=1` に対して `I_n\S_n` 上だけ `w_bad(s)=ε_n`、それ以外では `w_bad(s)=1`。`I_n` は互いに交わらない。

質量を規格化する係数は厳密に共通である：

```
J = ∫_0^1 w_good ds = ∫_0^1 w_bad ds = 47/52,
∑_{n=1}^∞ (ε_n/3)(1-ε_n)^2 = 5/52.
```

実際、`x=3^{-N}` とおくと欠損の尾和が `x/2 - 3x²/4 + 9x³/26` と正確に計算できる。`Φ(s)=J^{-1}∫_0^s w(u)du` とする。二つとも増加同相で `Lip(Φ)=1/J=52/47`、しかも `[2/3,1]` 上では `Φ` の傾きが常に `1/J` である。`good` では正の上下傾きが一様にあり、標準Laakso×円周と双リプシッツ同値である。

## 3. 定理I：全段の観測最大直径は同じ

`π_m` は高さ・角度・先頭 m ビットを残した商射影、`A_m=sup_{π_m x=π_m y} d_Φ(x,y)` とする。`h=3^{-(m+1)}`。

**上界：** 高さ s を含む長さ h の三進セルの両端を順に訪れ、最初の m ビットを変えずに尾部を揃えて戻る。セルの両端の少なくとも一方が `W_{m+1}` のゲートで、以後の全ての桁のゲートはセル内にある。よって `A_m<=2 Lip(Φ) h`。

**下界：** 高さ s=1 で第 m+1 桁だけを異なる値にした二点は、`W_{m+1}` へ行って戻らない限り一致しない。最寄りのゲートは `s=1-h`。`[1-h,1]` の傾きは `Lip(Φ)=1/J` だから距離は正確に `2h/J`。他の桁を変えても高さの往復を短縮できない。したがって

```
A_m(good) = A_m(bad) = (104/47) 3^{-(m+1)}  (ALL m>=0).
```

**注意：** この主張は商空間での等号であり、個々の距離が等しいという意味ではない。`[4/9,5/9]` の同一シート内水平距離は good が `89/846`、bad が `260/3807`。有限観測のファイバー**直径**と有限観測から読み取れる**全ての数値**を混同しない。

## 4. 定理II（追加新結果）：bad は一様倍加性を持たない

`n` を十分大きく取り、`ε=3^-n`, `ℓ=ε/3`, `δ=εℓ/J`。高さ `c=3ε/2`、全ビット0、角度0の点を `x_n` とし `r=δ/4` と置く。

(小球) `S_n` の弧長は `δ` で、その中央から境界まで `δ/2`。高さの `z` 射影は 1-Lipschitz なので、`B(x_n,r)` は `S_n` の内部にあり、先頭 n ビットは0、角度は長さ `2r` の円弧内にある。`w_bad=1` on `S_n` から、高さ幅は高々 `2Jr=εℓ/2`。従って

```
μ(B(x_n,r)) <= 2^-n · (εℓ/2) · (2r) = 2^-n εℓr.
```

(32倍球) `I_n` の全弧長は `H=(2ε-ε²)ℓ/J=(2-ε)δ`。中心から `I_n` の両端を通り尾部の任意の有限ビットを切り替え、任意の `s∈I_n` へ至る水平経路の長さは高々 `2H<4δ`。さらに `|θ|<=δ` を許しても長さは `5δ<8δ=32r` だから、`B(x_n,32r)` は `s∈I_n`、先頭 n ビット0、任意の尾部ビット、`|θ|<=δ` の全点を含む。したがって

```
μ(B(x_n,32r)) >= 2^-n · ℓ · 2δ.
```

両者を割れば

```
μ(B(x_n,32r)) / μ(B(x_n,r)) >= 8/ε = 8·3^n → ∞.
```

もし一様な倍加定数 D が存在すれば半径32倍の比は `D^5` 以下のはずで矛盾。これは測度・円周・全ビットを含む極限空間での定量的な非倍加性の証明である。

## 5. 定理III（追加独立証明）：bad は弱(1,1)-PIを持たない

上と同じ `I_n,S_n` で、`H=(2ε-ε²)ℓ/J`、`R=4H` とする。任意の拡大率 `λ>=1` を固定し、`ε<=1/(16λ)` とするような大きい `n` を選べば、`λR<ℓ/J` と `λR<1/2`、`2JR<=ℓ` が同時に成立する。これは球が `C_n=[ε,2ε]` の外に出ず、先頭 n ビットが固定され、円周での円弧長が通常の `2λR` で測れることを保証する。

`f_n(s)=0` to the left of `S_n`, `=1` to its right, and linear **in z=Φ_bad(s)** inside `S_n`。上勾配は `g_n=J/(εℓ)·1_{S_n}`（閉帯で定義し、任意の可長曲線について成り立つ）。

**平均振動の下界：** 球 `B_n=B(x_n,R)` は、高さ `I_n`、先頭 n 桁0、尾部自由、`|θ|<=H=R/4` の全点を含む。`I_n` の両側各4分の1区間は f の値がそれぞれ0,1なので、球内に各 `2^-n·(ℓ/4)·(R/2)=2^-n ℓ R/8` の質量を持つ部分がある。一方で、高さの分布は `I_n` と両側の `JR` 以内に限られ、角度幅は `2R`、最初の n 桁は固定だから `μ(B_n)<=2^-n(ℓ+2JR)·2R<=2^-n 4ℓR`。両側の相対質量は少なくとも `1/32`。任意の平均値に対して

```
mean_{B_n} |f_n-(f_n)_{B_n}| >= 1/32.
```

**上勾配平均の上界：** `μ(λB_n ∩ {s∈S_n})<=2^-n·(εℓ)·2λR`。`μ(λB_n)>=μ(B_n)>=2^-n ℓR/2` なので

```
R mean_{λB_n} g_n <= 4λ J R/ℓ = 16λ(2ε-ε²) <=32λε.
```

PIがあれば左辺は固定 C 倍した右辺以下でなければならないが、`n→∞` で `1/32<=32Cλε→0` は不可能。つまり、**倍加性を仮定しない意味でも**直接PIが破れている。

## 6. 査読時に切り分けるべき反論

- `"有限計算から無限のPIを導いている"`：導いていない。定理II・IIIは全 n に対する解析的構成と不等式。有限計算は独立の境界検査。
- `"無限尾部の全反転は有限操作で不可能"`：各有限接頭列の条件を満たす道を構成し、定義に従って有限商距離の上限を取る。無限回の物理投入を有限費用の実操作と混同しない。
- `"角度移動や別シートで帯を迂回できる"`：`z=Φ(s)` が各経路で連続・1-Lipschitzなので、左右を結ぶ道は帯の高さを必ず通る。ねじれ/一粒貼り合わせは本証明の仕様外。
- `"A_mが全部同じなら距離も同じ"`：誤り。`A_m`は各段の単一最大値であり、`[4/9,5/9]` で距離が異なる。
- `"PI成立側はLeanの定理だけで完結する"`：誤り。標準Laaksoの弱PI・Ahlfors正則性は文献による解析的入力であり、現行主定理も仮定として受け取る。
- `"砂山の粒数をそのまま距離とみなしている"`：誤り。無料ゲート反転と高さ弧長は設計条件で、粒投入回数を経路費用とする模型とは異なる。
- `"この結果から物理宇宙の模型が導出される"`：導出されない。ここでの結論はゲート付き距離測度空間の例と観測限界に限られる。

## 7. 検証の所在と残す問題

本監査のPythonコード `test_referee_counterexample.py` は **標準ライブラリだけ**を使う。三進セル重みを無限尾和まで `fractions.Fraction` で厳密計算し、深さ1〜4の有限グラフの実測 `A_m` が2模型とも上の分数に等しいことを検査する。上の不等式に現れる有理数の大小関係について複数の `n,λ` を確認する。ただし無限のPI証明をPython実行で代用するものではない。

主な残課題：

1. 定理II・IIIの**連続空間上の全量化**と、投影と尾部自由化の測度論的細部をLean kernelまで形式化する。現状は厳密な紙上証明と有限検算。
2. 既存 `SingleSquare.single_square_realization` の標準Laakso×円周のPIと正則性の入力を、文献の正確な定理と繋ぐ（無断で公理化しない）。
3. 正方格子砂山のサイズをまたぐ自然な状態写像がない点と、ゲート・測度・長さの外生的な指定を、別の研究課題として残す。
4. π_mの全測度・位置付き距離量を指定したときのPI判定の最小十分観測を探索する。「A_mだけでは不足」までは確定だが必要十分条件は未完成。
