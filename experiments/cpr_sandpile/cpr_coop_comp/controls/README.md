# Coop / Comp：投入数と採取配置を分ける記述的対照

対象は既存ASM解析の2人条件157試行。Compは79試行・10ペアID、Coopは78試行・10ペアID。元の生ログは追加読取せず、既存の `summary.csv`、`events.csv`、試行別NPZのみを使った。

模型は変更していない。初期砂0、Moore8方向、閾値8、盤外sink。採取時に各方向へ整数砂1粒を直接撒き、追加のtoppling回数を `v` とする。既存の源に8粒を入れる表現では `v=u−K`。

数値は各ペアID内で試行平均を取り、条件内の10ペアIDを等重みで平均したもの。試行ごとの `v/K` を先に計算してから同じ集計を行うため、群平均vを群平均Kで割った値とは一致する必要がない。参加者表記の重複に関する別監査があるため、ここでは独立性の仮定を置いたp値や信頼区間を出していない。

## 1. 最初の90採取にそろえる

全試行で記録採取数が94以上なので、最初の90件を使う比較には157試行全てが含まれる。90は初期トークン数に合わせた入力件数であり、個体としての初期トークン90個を追跡したものではない。

| 指標（ペア等重み平均） | Comp | Coop |
|---|---:|---:|
| 90採取後の追加発火総数 v | 1.277 | 14.600 |
| 1採取あたり v / 90 | 0.01419 | 0.16222 |
| 非自明連鎖が起きた採取件数 | 0.302 | 2.496 |
| 最大イベントu面積（セル） | 1.614 | 6.063 |
| 最大イベントv面積（セル） | 0.652 | 5.242 |
| 90採取までの経過時間（秒） | 48.90 | 105.80 |

非自明連鎖は、その採取の直接近傍配分後に `v_event>0`、すなわち追加topplingが少なくとも一回起きたものと定義した。最大イベントu面積は従来と同じく保証された源セルを含む。直接配分版のv面積も別列で保存した。

投入件数を同じ90にしても、Coopの平均値が大きい。一方、全試行が分離しているわけではない。vが正の試行はComp10/79、Coop27/78。ペア平均vの中央値はComp0.0714、Coop9.375、範囲はそれぞれ0–5.75と0–47.125で、Coopにもペア平均0のIDが2つある。

**同じ時間長の比較ではない。** 模型の更新規則には秒数を使わないが、実験記録から切り出す区間の長さは異なる。90回に達するまでの時間・資源の履歴までそろえた因果比較とは解釈しない。終端vは最初の90件のセル別回数だけで決まるが、非自明連鎖件数や最大イベント面積には採取順序も関わる。

## 2. 終端Kを99回、位置だけ置換する

各試行の終端セル別採取数Kを平らに並べ、99回独立に位置を置換した。総採取数とセル別回数の度数を厳密に保ち、同じ19×19盤・境界・初期0で計算した。乱数は試行ごとに `SeedSequence([20261121, pair_number, round])` を使う。

| 終端指標（ペア等重み平均） | Comp | Coop |
|---|---:|---:|
| 実測配置のv総数 | 42.739 | 775.104 |
| 置換配置のv総数の期待値（99回平均） | 14.774 | 633.881 |
| 実測配置 − 置換平均：v総数 | 27.965 | 141.224 |
| 実測配置のv/K | 0.23912 | 3.21704 |
| 置換配置のv/Kの期待値 | 0.07892 | 2.57217 |
| 実測配置 − 置換平均：v/K | 0.16020 | 0.64487 |

実測配置のv/Kの群差は2.97792、置換平均の群差は2.49325、両者の差は0.48467。位置を混ぜても大きな群差が残る。置換は各試行の入力総数や反復採取数の度数を保持するので、元の全差を特有の空間配置だけに帰すことはできない。

実測配置から置換平均を引いた量は、同じ模型内でその配置がどの程度の追加発火を生むかを記述する。境界への近さの変化も含み、「クラスタリングだけの効果」や統計的に調整済みの条件効果ではない。`v/K` で割っても閾値模型の非線形な投入量依存は消えない。

このshuffleはCPRとして実行可能な採取系列を生成するものではなく、条件割当てや被験者特性の因果調整でもない。99回の平均は有限個の模型出力の平均である。

## 3. 保存ファイル

| ファイル | 内容 |
|---|---|
| `analyze_controls.py` | 再実行スクリプト。既存の派生データだけを読んで本フォルダへ出力 |
| `prefix90_trials.csv` | 157試行の固定90採取指標と到達時刻 |
| `prefix90_pairs.csv` | ペアID内の試行平均 |
| `prefix90_group_summary.csv` | 条件ごとのペア等重み平均、ペア平均の中央値・標準偏差・範囲 |
| `prefix90/*.npz` | 試行別K、u、v、終端砂、90イベントの時刻・位置・発火数・面積 |
| `spatial99_trials.csv` | 実測配置、99回平均、両者の差。u総数、v総数、v/Kを含む |
| `spatial99_pairs.csv` | 配置対照指標のペアID内平均 |
| `spatial99_group_summary.csv` | 配置対照指標の条件別記述集計 |
| `spatial99/*.npz` | 実測K/u/v、99個の置換K/u/v/終端砂、平均u/vと点別差分 |
| `group_differences.csv` | 各指標のComp・Coop等重み平均とCoop−Comp |
| `metadata.json` | 規則、集計、乱数、入力hash、検算記録 |

点別の `difference_u` と `difference_v` は別に保存した。総量ではKの総数が置換で変わらないためu差とv差は等しいが、点別では採取位置が変わるので両者は異なる。

## 4. 検算

- 90×157＝14,130採取イベントを直接近傍配分で再生し、既存q8イベントの発火数−1、u面積、sink量と一致した。
- 全157試行の90件時系列処理と、同じKを一括投入した終端が整数で一致した。
- 全157試行の既存終端u・砂を再計算と照合した。
- 99×157＝15,543置換全てでKの度数・総数、非負性、安定性、整数の質量収支、局所Laplacian収支が一致した。
- 別に既存の単盤面安定化器で3試行×2置換を再計算し、新しいbatch実装の終端砂・uとの一致を確認した。

今回の結果は投入件数・空間配置に対する模型内の感度を整理する補助解析であり、条件間の因果差や独立した参加者集団への一般化を確立するものではない。
