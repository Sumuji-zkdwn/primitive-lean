# 採取駆動Moore砂山の定義と読み方

ここでは、2026-11-21の既存解析で採用した模型と集計規約を記す。リポジトリへの追加日は2026-11-22。最新の条件比較は [README.md](README.md) と [Coop／Comp詳報](cpr_coop_comp/README.md)、実行手順は [REPRODUCE.md](REPRODUCE.md) を参照する。

これは**実測採取の位置と順序を、別に定義した蓄積・再配分場へ写す模型**である。砂は操作的な量であり、実験トークンそのものでも再生確率でもない。以下の定義は [砂山の実装](cpr_redefinition/harvest_asm/analyze_harvest_asm.py) と [直接近傍配分による対照計算](cpr_coop_comp/controls/analyze_controls.py) に対応する。

## 1. 入力・格子・状態

有限の正方格子を $V$ とし、同じセルを除くMoore近傍8方向を使う。元の実験座標を保持し、周期境界・補間・対称化は行わない。Coop／Comp比較の盤面は19×19である。

| 記号 | 定義 |
|---|---|
| $M$ | 盤内Moore隣接行列。$M_{ij}=1$ はセル $j$ からセル $i$ への盤内方向を表す |
| $d_i$ | 盤内次数。角3、辺5、内部8 |
| $\Delta=8I-M$ | 砂山のtoppling行列。対角は境界でも8 |
| $z_i$ | 非負整数の砂粒数。安定時は $0\le z_i\le7$ |
| $h_i=z_i/8$ | 正規化した高さ。安定時は $0\le h_i<1$ |
| $K_i$ | そのセルで記録された成功採取の累積件数 |
| $\kappa=\sum_iK_i$ | そのラウンド・読み出しまでの総採取件数 |
| $u_i$ | 採取位置に8粒置く実装での累積toppling回数（odometer） |
| $v_i=u_i-K_i$ | 直接配分の後に起きた追加topplingの累積回数 |

各ラウンドは $z=0$ から始める。入力となるのは、最初のTokenField記録時刻以上、最後の記録時刻未満にある採取である。採取時刻順、同着時は元CSVの行順に処理する。読み出し時刻 $t$ に含めるのは採取時刻が $t$ 未満のイベントであり、各採取後に完全に安定化してから次の採取へ進む。[入力処理の実装](cpr_redefinition/harvest_asm/analyze_harvest_asm.py)

## 2. 固定した再配分とsink

セル $i$ の $z_i\ge8$ を不安定とする。合法的な1回のtopplingは

$$
z\longmapsto z-8e_i+Me_i
$$

である。自分から8粒を取り出し、Mooreの各方向へ1粒ずつ送る。盤外方向の粒はsinkへ流出し、戻らない。1回のtopplingによる流出は $8-d_i$ 粒である。

**辺や角でも分母・閾値は8のまま**にする。盤内の3方向・5方向へ全量を再配分する規則には変えない。また、実験トークンの占有状態や占有近傍数によって砂の受入先を制限しない。固定の再配分行列とsinkが、この模型の前提である。

正規化高さでは、$h_i\ge1$ で1単位を取り出し、各方向へ $1/8$ ずつ送る。砂山内の反復更新段数は計算上の段数であり、実験の秒数を表さない。

## 3. `q8`と直接近傍配分は同じ模型

### 採取位置に8粒置く表現（`q8`）

採取位置が $i$ なら $z\leftarrow z+8e_i$ とし、その後安定化する。この表現では、採取に伴う源セルの最初のtopplingも $u$ に数える。

採取直前は全セルが安定しているため、投入直後に不安定なのは源セルだけである。そのセルは8〜15粒なので、まず1回合法的に崩せる。最初の1回を実行すると、盤内の状態は採取直前の状態に $Me_i$ を加えたものになる。

### 採取が近傍へ直接撒く表現（`direct`）

上の保証された最初のtopplingを、採取イベント自体の配分とみなす。

1. 各採取でMoore8方向へ各1粒を直接送る。正規化単位では各 $1/8$。
2. 盤外方向の分は、この直接配分時点でsinkへ流す。
3. その後、閾値8のtopplingを安定するまで続ける。

直接配分後の状態は `q8` の最初の源toppling後と同じなので、残砂もその後の連鎖も同じである。セルごとに、採取1回につき保証された源の1回を除くと

$$
v=u-K\ge0
$$

となる。源がその後に再び崩れた分は $v$ に含む。$v$ は統計的残差でも、境界作用を除去した量でもない。[直接配分の独立な実装・照合](cpr_coop_comp/controls/analyze_controls.py)

## 4. `q1`から`q8`への変更は入力規約の変更

既存解析では、採取位置へ1粒置く `q1` も比較した。閾値はどちらも8で、初期砂も0である。

| 入力規約 | 採取1件の投入量 | toppling閾値 |
|---|---:|---:|
| `q1` | 源へ1粒 | 8粒 |
| `q8` | 源へ8粒 | 8粒 |
| `direct` | 8方向へ各1粒（盤外分も含む） | 8粒 |

`q8`は、`q1`に対して閾値に対する入力を8倍にした別のイベント対応である。単なる単位換算ではない。単位換算は、同じ`q8`の $z$ を $h=z/8$ と表し、入力・閾値・移送量を一緒に割る操作を指す。

既存の全397試行では、`q1`は崩壊0だった。この結果と、`q8`／`direct`で連鎖が現れた結果を同じ規約のままの変化と説明しない。[保存集計](cpr_redefinition/harvest_asm/summary.csv)

## 5. 局所収支とsinkの分解

初期0からの`q8`表現では

$$
z=8K-\Delta u.
$$

$u=K+v$ を代入すると、直接近傍入力の表現が得られる。

$$
z=MK-\Delta v.
$$

したがって、$v$ は近傍入力 $MK$ を安定化したodometerである。全体の整数収支は

$$
8\kappa
=\sum_i z_i
+\underbrace{\sum_i(8-d_i)K_i}_{\text{採取時の直接流出}}
+\underbrace{\sum_i(8-d_i)v_i}_{\text{追加連鎖中の流出}}.
$$

正規化単位では全式を8で割る。

$$
\kappa
=\sum_i h_i
+\frac18\sum_i(8-d_i)K_i
+\frac18\sum_i(8-d_i)v_i.
$$

保存される`q8`の `sink_grains` は、直接流出と連鎖中の流出の合計である。$\sum u_i$ や $\sum v_i$ は再配分の回数なので、砂の保存量やsink量とは区別する。[整数収支の検査](cpr_redefinition/harvest_asm/analyze_harvest_asm.py)

## 6. アーベル性と終端が忘れる情報

固定の有限格子、固定の閾値・再配分、盤外sinkへの到達可能性の下で、合法的な安定化は停止し、最終安定状態と累積odometerは合法な処理順序に依存しない。Moore近傍であること自体は、この性質を妨げない。これは採用した固定砂山の数学的性質であり、実験の再生過程についての主張ではない。

この性質から、初期盤面を固定した終端の $h,u,v$ は、セル別総採取数 $K$ だけで決まる。同じ採取集合を時間的に並べ替えても終端は同じになる。実装は、時系列入力の結果と、同じ $qK$ の一括投入・安定化の結果を照合する。[安定化と終端照合](cpr_redefinition/harvest_asm/analyze_harvest_asm.py)

したがって、終端図だけから採取の間隔、協力のタイミング、行動の同期を復元できない。各採取直後の状態・イベント別増分・最大イベント面積・連鎖発生率には入力の途中経過が関わるので、時間順序を調べる場合はそちらを見る。最初90件の対照も、入力件数を固定した比較であり、同じ実験時間や同じ資源履歴を固定した比較ではない。[固定90採取の説明](cpr_coop_comp/controls/README.md)

## 7. 保存配列と主指標の対応

主な試行配列は [harvest_asm/trials/](cpr_redefinition/harvest_asm/trials/) にあり、元の $(x,y)$ 座標を保つ。

| 保存名・指標 | 読み方 |
|---|---|
| `drive_grains` | 入力規約の軸。`[1,8]` |
| `height_grains` | 整数高さ $z$。軸は `(drive,time,x,y)` |
| `odometer` | 各規約での累積toppling回数。`q8`の軸が $u$ |
| `harvest` | 累積採取数 $K$。軸は `(time,x,y)` |
| `sink_grains` | 整数粒数での累積流出。軸は `(drive,time)` |
| `x` | 参照用の実験トークン占有。砂山の受入判定には使わない |
| `events.csv` の `topplings` | 1採取の $\sum_i\Delta u_i$。保証された源の1回を含む |
| 追加崩壊／採取 | ラウンド内の $\sum_i v_i/\kappa$ を計算した後、組内・条件内の順に平均 |
| 連鎖発生率 | 追加崩壊 $\sum_i\Delta v_i>0$ が起きた採取の割合 |
| 主比較の最大イベント面積 | $\Delta u_i>0$ のセル数のラウンド内最大。源の初回配分を含む |

1イベントでは $\Delta K=e_i$ なので、追加崩壊回数は `topplings−1` となる。追加連鎖のないイベントでも、初回込みの回数と面積は1である。$\Delta v>0$ の面積と、保存済み主指標の $\Delta u>0$ の面積を混同しない。[主指標の集計](cpr_coop_comp/analyze_conditions.py)

## 8. 実験トークン再生・既存形式化との境界

実験のトークン再生は観測盤面と採取ログから扱う。ここでのtopplingは、固定砂山の閾値によって生じる模型内の再配分である。採取が砂山を駆動しても、砂山の結果を実験トークンの出生へ戻してはいない。再生確率 `0.01(1−x)n/d` の1秒台帳や、実測birth時に砂をresetする旧模型とも定義が異なる。

中央の山や広い連鎖には、採取配置だけでなく固定境界とsinkの作用も含まれる。位置置換対照は、その同じ模型内で配置を変えた比較であり、実行可能なCPR行動の生成や因果調整ではない。アーベル性・整数収支・計算の再現だけで、再生機構への適合、自己組織化臨界性、条件の因果効果を証明したとはしない。[対照の定義と留意点](cpr_coop_comp/controls/README.md)
