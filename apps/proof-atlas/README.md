# PRIMITIVE ATLAS — 証明の地図

スマホ・PC用の**独立した証明グラフ閲覧／考察ツール**です。Factoryゲーム、研究ポイント、定理装備、採掘機などはありません。研究部分を単独で育てる構成にしました。

## 使う

単一HTML（インストール不要、ダウンロード後はオフライン動作可能）:

https://raw.githack.com/Sumuji-zkdwn/primitive-lean/main/apps/proof-atlas/play.html

特定の定理を開くときは番号を付けます。例: ?n=230 は「二入力の観測が一致すれば状態の基底量と入力係数が一致する」を開きます。

検索 → グラフで定理をタップ → 「読み解き」「依存関係」「Lean原文」を開く、という最短の操作です。Androidではグラフを1本指で移動、2本指で拡大縮小できます。読み解きは下から開くシート、横画面では右側のパネルです。

「全体」で465定理全体を層状に表示し、「近傍」で選んだ定理の前提・後続へ移ります。グラフ内の色や線は控えめにし、元のLean完全名は原文で確認できるようにしています。

## 論証を必要なときだけ展開する

読み解きタブでは結論の概説を先に表示し、「論証を展開」で仮定と段階的な論証を開きます。「前提の論証を展開」は元の証明参照を推移的にたどり、重複なしの依存順で定理を表示します。各前提カードの説明・命題・証明を個別に開けます。ユーザーの点線はこの計算には含めません。

Elastica 系の全214定理（#001–#214）に日本語論証が揃いました。幾何・曲率・変分法・厳密な端点制約・曲率方程式・指数重み・べき対数応答と密度を網羅しています。LinearInput 系は99件、合計313件を解説済みです。#001–#312 は全件解説済みで、勾配・散逸・エネルギー帯の不変性と収束・曲率と位相系の対応・フィードバック速度分解まで連続して読めます。未解説の定理にも「さらに詳しい日本語論証を依頼する」資料があり、対象と直接参照先の命題・証明原文・固定ソースリンクが含まれます。オフラインでコピー／選択できます。この画面自体はAI生成やLeanの再検証を実行しません。

## 複数定理から新しい命題を構想する

読み解きの「構想に追加」で、最大20件の定理を研究構想に集められます。別の定理を選択しても選択リストを保持し、仮説文と一緒に localStorage に保存します。「検証資料を作る」は選択定理とその直接参照先の命題・証明原文・固定出典・仮説的探索リンクをひとまとめにします。この資料をChatGPT等へ渡し、実際のLean定式化と検証を依頼できます。アプリ自体が命題を証明したり、GitHubへの書き込みを行ったりするものではありません。

## 自分でグラフをつなぐ

「依存関係」→「この定理から別の定理へ線を引く」で定理を2つ選び、理由を文章でメモすると**点線の探索リンク**になります。

このリンクはローカルな考察用です。元のLeanの証明参照（実線）とは区別して描画し、正式な依存グラフを変更しません。リンクはブラウザの localStorage に保存されます。削除も可能です。したがってどこから考え始めても構いませんが、仮説の線から数学的な定理間依存を「証明した」ことにはなりません。

## 本物の命題と証明原文を表示

- 元の初期465定理（Elastica 214件 + LinearInput 251件）の**465命題とLean証明本文をすべて、原ファイル60本から取り出しています**。apps/proof-atlas/proofs.json は検査対象の記録で、全文／出典行番号も保持します。
- 依存グラフは従来の games/primitive-foundry/tech.json に保存された、465定理間の629本の**直接の証明項参照**と一致します。定義などへの783参照と補助定理への9参照もグラフ側に保持されています。
- 原ファイルのコメントがあるものはそのまま英語で表示（340件）。
- 313の定理について、日本語の人間向け**論証の概説・成立条件・論理の手順**を個別に用意しています。これらは apps/proof-atlas/narratives.json に保存しています。
- ほかの152件では、証明内容に根拠のない日本語解説を自動生成したふりはしません。Leanの命題、実際の証明本文、証明が使う前提、著者の原文コメント（あれば）を表示します。
- 元の出典へのGitHubリンクは検証に使った固定のソースリビジョンを指します。

このアプリはLeanカーネルそのものをブラウザで実行しません。従来の証明参照台帳に基づく閲覧と独立な説明機能です。個別の定理の証明の真偽や、引用が数学的に必要不可欠かどうかを新規に確立するものではありません。

## 検証とビルド

次の手順で全データの正確性、実際の60ファイルとの一致、DAGの非巡回性、ヒューマンコメント件数、313解説の対応を検査できます。

    python3 -B apps/proof-atlas/audit.py
    python3 -B games/primitive-foundry/check_dag.py
    node --test apps/proof-atlas/atlas.test.cjs apps/proof-atlas/ui.test.cjs
    python3 -B apps/proof-atlas/build_play.py --check

スタンドアロンHTMLを再生成する場合:

    python3 -B apps/proof-atlas/build_play.py --write

専用GitHub Actions .github/workflows/proof-atlas.yml はAndroid相当の縦（412×915）・横（914×411）画面とPC画面の実際のブラウザ描画も保管します。

## 実装のスコープ

「定理の依存をつないで辿る」「考察上の関連を自分でつなぐ」「実際の命題・Lean証明・人間向け論証を必要なときだけ開く」までを扱います。学習進捗の点数化、ゲーム内製造装置、汎用的な自然言語証明生成、すべての定理への人手解説は含めていません。
