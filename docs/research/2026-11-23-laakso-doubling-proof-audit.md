# PR #211：倍加性の紙上証明を閉じるための補題監査（2026-11-23）

対象：同じ三進Laakso商上の `d_0` と `d_Φ`。この文書は有限の数値サンプリングを無限次元の証明にすり替えないため、成立に必要な補題と、その証明を独立に書き下す。下記は**紙上証明**であり、数学的な定理としての最終認定には外部査読・対応するLean形式化が残る。

## 1. 密度の記号と訂正

`z_n=6^{-n}`、`I_n=[z_{n+1},z_n]`、`\ell_n=(5/6)6^{-n}`、`v_n(z)=2\min(z-z_{n+1},z_n-z)/\ell_n` とする。密度は
`ρ(z)=4/5+(8/5)(2^n-1)v_n(z)`（`z∈I_n,n≥1`）、`ρ(z)=4/5`（`z≥1/6`）。
`u(z)=2^n v_n(z)`（`z∈I_n,n≥1`）、`u(z)=0`（`z∈[1/6,1]`）とおく。すべての `z>0` で

`(4/5)(1+u(z)) ≤ ρ(z) ≤ (8/5)(1+u(z))`

が成立する。左側は `2(2^n-1)≥2^n` (`n≥1`) による。従って `(1+u)dz` が倍加的なら `ρ dz` も倍加的（比較定数は2）である。

**訂正済みの注意**：`u(z)dz` を右側 `(1/6,1]` でゼロと定義した測度は**全区間では非倍加**。以下は `[0,1/6]` に制限した相対倍加性の証明である。

## 2. 相対測度 `u(z)dz` の倍加性：全スケールの証明

`I=[0,1/6]` に制限し、`ν_u(A)=∫_{A∩I}u(z)dz` とする。`ν_u` は原子がなく、`I` の任意の非空な相対開区間に正の質量を与える。

`u(z/6)=2u(z)` は厳密な恒等式である。実際 `v_{n+1}(z/6)=v_n(z)` である。これを両側に反復し、全正半直線上の自己相似な「基準密度」`u_*(t)` を定義する。区間 `[6^{-(j+1)},6^{-j}]` (`j∈ℤ`) 上で `u_*(t)=2^j v_j(t)` とし、各節点で0とする。任意の整数 `k≥1` で、元の定義域において

`u(6^{-k}t)=2^k u_*(t),\quad dz=6^{-k}dt`

なので、拡大・縮小後の質量には共通因子 `3^{-k}` が付く。この因子は球質量比で消える。なお `∫_0^{10}u_*(t)dt<∞`。原点近くの殻の質量が `(5/12)3^{-j}` で総和収束するためである。

**有限折線補題**：非負の連続な有限区分線形関数で、零点が孤立し、各零点の許された側で非零の線形傾きを持つものは、その定義コンパクト区間で倍加測度を与える。証明：零点の近くでは密度が `c|t-t_0|` と上下定数倍で比較でき、この密度の2倍球質量比は一様有界。正の点では上下の正定数と比較できる。有限被覆のLebesgue数より小さい半径を局所評価で扱い、それ以上は分母の正の一様下界と分子の有限性で扱う。端点では相対区間の球を使う。

ここで倍加性の失敗を仮定し、`x_i∈I,r_i>0` と `ν_u(B_I(x_i,2r_i))/ν_u(B_I(x_i,r_i))→∞` を取る。半径が正数以上なら連続な分布関数とコンパクト性で分母に一様正下界があるので、`r_i→0` としてよい。

- **(i) `x_i≤8r_i` の場合**：`6^{-k_i-1}<r_i≤6^{-k_i}` を選ぶ。`k_i→∞`。変数 `t=6^{k_i}z` で中心 `X_i∈[0,8]`、半径 `R_i∈(1/6,1]` に写る。十分大きい `i` では両球が `I` 内にあり、比は基準密度 `u_*` の球質量比に等しい。分子は `∫_0^{10}u_*<∞` 以下、分母はコンパクト集合 `[0,8]×[1/6,1]` 上で正で連続（基準密度の任意の非空区間への正質量）なので一様に下から抑えられる。
- **(ii) `x_i>8r_i` の場合**：`x_i` が0から離れる部分列なら、有限区分線形密度の局所補題を適用できる。`x_i→0` の場合は `6^{-k_i-1}<x_i≤6^{-k_i}` を選び、`X_i=6^{k_i}x_i∈(1/6,1]` とする。半径 `R_i< X_i/8` なので、2倍球も `[1/8,5/4]` の中に入る。この区間上の `u_*` は非負の**有限**区分線形関数で、零点はいずれも単純。有限折線補題が中心・半径について一様の上界を与える。

いずれも比の発散に矛盾する。従って `ν_u` は `I` 上で倍加的である。Lebesgue測度も相対区間 `I` 上で倍加的なので、両者の和 `(1+u)dz` も相対倍加的である。

**全区間への貼り合わせ**：`z_2=1/36,z_1=1/6`。半径 `r≥5/144` の球は `ρ≥4/5` と全質量1より倍加比が高々36（`r>1` も自明）。`r<5/144` で2倍球が `[0,z_1]` 内なら相対倍加性でよい。2倍球が `(z_1,1]` に達するなら同時に `[0,z_2)` には達せない（必要な直径は `4r<z_1-z_2=5/36`）。この場合、両球は `[z_2,1]` 内にあり、その上で `4/5≤ρ≤12/5`、かつ相対Lebesgue球の長さの2倍比は高々2なので質量比は高々6。以上より**`ρ(z)dz` は全区間で倍加的**である。

## 3. Laaksoの径方向距離比較：明示定数

`ν_Φ([a,b])=Φ(b)-Φ(a)`、`Ω_s(R)=ν_Φ([s-R,s+R]∩[0,1])` とおく。`ν_Φ` が1次元の倍加定数 `D≥1` を持つと仮定する。

ゲートを訪問する許容区間 `J=[l,u]` の標準走査費用は `c_0(J)=2(u-l)-|s-t|`。座標 `Φ` による費用は `c_Φ(J)=2(Φ(u)-Φ(l))-|Φ(s)-Φ(t)|`。両端点は `J` 内にあるため

`u-l≤c_0(J)≤2(u-l),\quad ν_Φ(J)≤c_Φ(J)≤2ν_Φ(J)`。

`R=d_0(x,y)` は全許容走査の費用の下限であり、全ての許容 `J` に対して `R≤c_0(J)≤2(u-l)`。従って幅 `ℓ=u-l≥R/2`。中心を `c=(l+u)/2` とすると

`[s-R,s+R]∩[0,1] ⊆ [c-(5/2)ℓ,c+(5/2)ℓ]∩[0,1]`。

右側は `J=B(c,ℓ/2)` の**5倍半径**の球なので、3回の倍加により

`Ω_s(R)≤D^3ν_Φ(J)≤D^3 c_Φ(J)`。

全ての許容区間について下限を取れば `d_Φ(x,y)≥D^{-3}Ω_s(R)`。上界には `c_0(J)→R` の許容区間を取り、`J⊆[s-c_0(J),s+c_0(J)]` と `c_Φ(J)≤2ν_Φ(J)` を用いる。分布関数の連続性で極限を取れば `d_Φ(x,y)≤2Ω_s(R)`。

従って、**標準走査公式と1次元倍加性を仮定すれば**

`D^{-3}Ω_s(d_0(x,y))≤d_Φ(x,y)≤2Ω_s(d_0(x,y))`

となる。距離0の同一点は別扱いしてよい。`LaaksoSweepBounds.lean` は走査区間に関する純代数部分と5倍包含の不等式を証明する。infimumと実際のLaakso商への適用は未形式化である。

## 4. 倍加性の球包含へ

`ν_Φ` は原子がなくfull supportな倍加測度であり、累積関数 `Φ` は増加同相。1次元累積分布と準対称写像の同値は公知の解析定理を用いる。\
半径 `0<r≤1/8` では、左右いずれかに `2r` の余裕がある。中心 `s` からその側へ `3r/2` 進んだ点 `y` の `r/4` 球は、`B(s,2r)\setminus B(s,r)` に含まれる。同時に `B(s,r)⊂B(y,5r/2)`。4回の倍加より

`ν_Φ(B(s,2r))≥(1+D^{-4})ν_Φ(B(s,r))`。

原子のなさとfull supportにより `Ω_s` は連続厳密増加である。第3節の上下比較と、この逆倍加（固定の2倍半径で質量が必ず一定割合増す）から、全ての中心・十分小さい半径に共通する自然数 `k=k(D)` を用いて

`B_0(x,t)⊆B_Φ(x,r),\quad B_Φ(x,2r)⊆B_0(x,2^kt)`

を満たす `t>0` を選べる。具体的には `Ω_s(t)=r/4` を選んで内側を作り、外側は `Ω_s(2^kt)≥2D^3r` になるまで逆倍加を反復する。倍率の必要回数は `1+D^{-4}` と目標比 `8D^3` から一様に制限できる。大きな `r` は `[0,1]` のコンパクト性と正の全支持測度で一様な下限を取る。

標準Laakso因子の測度は倍加的である。PR #211 のLean定理 `LaaksoBallTransfer.doubling_of_uniform_ball_sandwich` は、上記の球包含を**仮定として受け取れば**新しい距離でも倍加的であることをカーネル検証している。円周との積にも倍加性が移る。

## 5. 証明の依存関係と残件

- **紙上で示した部分**：`ρ dz` の全スケール倍加性（自己相似性と有限折線補題）、標準走査公式に基づく `D^{-3}` 径方向比較、逆倍加と球包含、商測度の倍加性の移送。
- **Leanカーネルで確認する部分**：単純な走査不等式、一般の球包含から倍加性への論理的移送、殻の有理数質量恒等式。紙上の定理全体をLeanで証明済みとは言わない。
- **未形式化／要他者検証**：無限段Laakso商の走査公式とその座標変換、`u_*` の全スケール積分議論、1次元累積分布のQS入力、連続モデルのPI反証の全量化。
- 元の `PR #208` は凍結した別反例であり、ここでは変更しない。砂山の具体的投入費用や物理学の結論は主張しない。

## 6. 許容区間族の下限とランプ平均（追補）

**Leanによる下限移送**：許容区間族 `𝒜` を空でない `ℝ×ℝ` の集合とし、全区間が始点 `s` と終点 `t` を含むとする。各区間の未校正・校正済み走査費用を `c₀(J), cΦ(J)` とし、`R=inf_{J∈𝒜}c₀(J)`、`dΦ=inf_{J∈𝒜}cΦ(J)` と定義する。1次元測度 `νΦ` の倍加性、区間質量 `νΦ([l,u])=Φ(u)-Φ(l)` と単調性の仮定で、**`νΦ(B(s,R))≤D³dΦ`**。単一区間での3回の倍加から、`c₀(J)≥R` を使って各区間の評価を得、実数下限の順序性で下限へ移す。形式化：`LaaksoSweepBounds.radial_mass_le_calibrated_infimum`。これは任意の**同一許容区間族**の走査費用の下限を扱う。実際のLaakso道距離がその下限と一致することは本命題の仮定には隠しておらず、別途同定が必要。
