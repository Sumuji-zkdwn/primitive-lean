# Laakso有限歩行の定量的ゲート費用（2026-11-23）

A案（[Draft PR #211](https://github.com/Sumuji-zkdwn/primitive-lean/pull/211)）の追加検証。今回のコードは `LaaksoGateCost.lean`。

## 目標と独立性

前段の `LaaksoFiniteGateWalk.lean` では「ビット値が変わったならゲートを訪れた」をLeanで証明したが、ゲートへの移動が必要とする**距離費用**は追跡していなかった。今回は任意の指数集合 `ι`、任意のゲート述語 `G : ι → ℝ → Prop`、任意の高さ校正 `F:ℝ→ℝ` に対して、有限の歩行を次の操作だけで生成する。

- 水平移動 `s→t`：ビットを維持し `|F(s)−F(t)|` の費用を追加。
- ゲート `G(k,s)`：同じ高さで第 `k` ビットのみを反転し、費用0。
- 停止：費用0。

ここには実数空間の単調性や、Laaksoの三進ゲートに関する特殊性は使わない。

## 定量的な必要条件

有限合法歩行 `w : x→y` の費用を `c` とする。第 `k` ビットが異なれば、実際の `k` ゲート `u` が少なくとも一つ存在して

[
c ge |F(x_1)-F(u)|+|F(u)-F(y_1)|
]

が成立する。証明は歩行の帰納法による。最初の水平移動は絶対値の三角不等式で処理し、最初のゲート移動が指定した `k` ならその点 `u=s` が証人となる。別ビットのゲートでは帰納仮定を使う。

特に `x_1=y_1=s` の往復歩行では

[
cge 2|F(s)-F(u)|.
]

## 定量的な十分条件（単一ビット）

任意の `G(k,u)` について、`s→u` の水平移動、無料の第 `k` ビット反転、`u→t` の水平移動を連結できる。したがって単一ビット反転の最短費用は、最寄りゲート `u_0` が存在すれば、

[
inf_{	ext{合法歩行 }(s,b)	o(s,boplus e_k)}c
=2|F(s)-F(u_0)|.
]

他のビットを途中で反転する迂回歩行も、この下界を改善できない。

## 意義と未証明の橋

これは、各段の観測直径 `A_m` の**下界を与える単一ビット証人**の正当化に直接使える。元の反例では右端 `s=1` と第 `m+1` 段の最寄りゲートを選ぶ。二つの模型で最寄りゲートまでの校正距離が等しいことは別途チェック済み。

ただし、この抽象的な `WeightedWalk` を、元PR #171の `ObservedQuotient.WalkCost finiteStep` と同じものだと宣言していない。後者は円周移動と `ENNReal` 費用を持ち、型の変換を伴う。無限段の道距離・全ビット同時反転の最短路公式・PI不成立の全量化も本稿の対象外である。
