# 受動的遅延ゲルの非凸拡張：静止局在・移動障壁・散逸

2026-11-23 JST。先行する [PR #183](https://github.com/Sumuji-zkdwn/primitive-lean/pull/183) の独立した続編。これは有限グラフ上の有効媒質模型であり、物理的粒子・一般相対論・Lorentz不変性の証明ではない。

## 元の不可能性定理と変更点

有限連結グラフの接続行列を `B`、ひずみを `ε=Bx`、内部変数を `h`、遅れを `δ=ε−h` とする。元の受動ゲルは `g=bδ+κδ³` と `ḣ=γg`（`b,γ>0, κ≥0`）を持ち、緩和後も正の二次弾性エネルギー `aε²/2`（`a>0`）が残る。静止平衡で `g=0` より `h=Bx`、続いて `Bᵀ(aBx)=0`。両辺に `x` を掛けると `Bx=0`。したがって一様変位以外の静止形状はない。

**変更するのは緩和則ではなく、緩和後の辺エネルギー**である。

```text
W(z)=z²(z²−1)²,            U_a(z)=W(z)+a z²/2, a≥0
E=ρ||v||²/2 + Σ_e [U_a(ε_e)+bδ_e²/2+κδ_e⁴/4]
ẋ=v;  ρv̇=−Bᵀ[U_a′(ε)+g];  ḣ=γg
```

連鎖律による厳密なエネルギー式 `Ė=−γΣ_e g_e²≤0` は維持される。全平衡条件は `v=0, h=Bx, BᵀU_a′(Bx)=0`。`W(z)≥0`、`W′(0)=W′(±1)=0`、`W″(0)=2, W″(±1)=8`。

## 3頂点の反例とHessian

`a=0` の3頂点鎖では `x=(0,1,0), h=(1,−1), v=0` がエネルギーゼロ・勾配ゼロの平衡となる。緩和後の変位Hessianは

```text
H=8 BᵀB = [[ 8, −8,  0],
           [−8, 16, −8],
           [ 0, −8,  8]],  eigenvalues = (0,8,24).
```

零モードは全体並進だけ。`b=1` の全変数 `(x,h)` Hessianは別物で、`(0,5−√17,14−2√43,5+√17,14+2√43)`。有限連結グラフ上で全辺ひずみが `0,±1` に属する状態は、いずれも並進を除けば厳密局所極小。特に1頂点だけを1にする局在状態が存在する。**これは数学的極小であり粒子ではない。**

### 4〜8頂点の基底エネルギー配置数

1頂点を0に固定して全体並進の重複を除く。`P_n` は鎖、`C_n` は環、`K_n` は完全グラフ。

| n | P_n | C_n | K_n | P_nの1頂点局在Hessianの最小正固有値 |
|---:|---:|---:|---:|---:|
|4|27|19|15|2.242753313|
|5|81|51|31|1.107182188|
|6|243|141|63|0.677041534|
|7|729|393|127|0.463552722|
|8|2187|1107|255|0.340162994|

厳密な個数公式は順に `3^(n−1)`、中央三項係数、`2^n−1`。8頂点・12辺の立方体は2通りの独立列挙で495配置。局在Hessianの最小正固有値は数値的に `4.529775789`。極小が多数あり同一エネルギーという縮退は、粒子同定をむしろ難しくする。有限系での正Hessianは無限系での一様な安定性を意味しない。

## 正の弾性係数を残した準安定局在

両端固定の3頂点鎖 `x=(0,s,0)` で `V_a(s)=2U_a(s)`。`0<a<2/3` において `d=√(1−3a/2)` とすると、

```text
s_+²=(2+d)/3       （非零の厳密局所極小）
s_-²=(2−d)/3       （平坦状態との間の障壁点）
V_a(s_+)=4(1−d)(2+d)²/27>0
ΔE_ann = V_a(s_-)−V_a(s_+)=8d³/27
```

`a=0.1` なら `s_+=0.9869066902413`、`V_a(s_+)=0.09871684757483`、`ΔE_ann=0.2321959344800`。`a=2/3` で極小と鞍点が合体して障壁は消滅する。これは**両端固定の1自由度**に限定した値であり、多頂点・自由境界へ一般化してはならない。

## 4頂点の隣接移動：厳密な最小障壁

両端固定の4頂点鎖 `x=(0,u,v,0)` のエネルギーは `F(u,v)=W(u)+W(v−u)+W(v)`。盛り上がりを `A=(1,0)` から `B=(0,1)` に連続的に動かす経路の最小最大値は

```text
M = inf_{p(0)=A,p(1)=B} max_{0≤t≤1} F(p(t))
  = 36/121 − 4√3/363
  = 0.2784347018449711...
```

**下界**：`e=(u,v−u,−v)` とすると `e₁+e₂+e₃=0`。臨界点の必要十分条件は `W′(e₁)=W′(e₂)=W′(e₃)`。`p=Σ_{i<j}e_ie_j, q=e₁e₂e₃` とおくと、`W′(z)` を `z³+pz−q` で割った剰余は `6qz²+(6p²+8p+2)z−(6p+8)q`。三つの値が異なる場合は `q=0,p∈{−1,−1/3}`。二つが等しい場合は `(r,r,−2r)` の順列で `r=0` または `33r⁴−12r²+1=0`。これで25個の臨界点を漏れなく分類する：7個のゼロ極小、6個の高さ `M` の指数1鞍点、6個の高さ `8/27` の指数1鞍点、6個の高さ `36/121+4√3/363` の極大。`F` はproper/coerciveで、`(0,M)` 内に臨界値がないため、標準的な劣位集合の変形議論で `F<M` の領域は7つの異なる極小成分を持つ。よって経路は少なくとも `M` に達する。

**上界**：`r=√((6+√3)/33)`、`S=(2r,r)`、`C=(1,1)`、`S′=(r,2r)` と置いた折れ線 `A→S→C→S′→B` が最大値 `M` を実現。`A→S` のエネルギー微分は `t(1−t)Q(t)` で、三次多項式 `Q` のBernstein係数はすべて正。`0.484<r<0.485` を用いる有理数区間評価で厳密な正の下界を与えられる。他区間は `v↦u−v` および `u↔v` の対称性で従う。Python検算は多項式等式・臨界点・有理数区間証明書を検査する。

この `M` は**両端を固定した4頂点に固有の厳密値**。

## 散逸による持続周期移動の障害と、有限の過渡移動

周期 `T>0` でエネルギーが戻るなら `0=E(T)−E(0)=−γ∫₀ᵀ||g||²dt` だから全時間で `g=0`。`b>0,κ≥0` より `δ=0`、`ḣ=0`、`Bx=h` は一定。連結グラフでは相対変形が固定され、可能なのは全体の等速並進のみ。したがって無外力受動模型には**非自明な相対形状周期軌道がない**。グラフ自己同型とともに全状態が厳密に繰り返す場合も、エネルギー不変性のもとで同様。

それでも一過性の移動は可能。4頂点の両端固定・`ρ=b=1, γ=5, κ=0` で `A` から初速度 `s(−1,1)/√2` を与え、`t=150` までDOP853積分すると、`s=0.7` (初期エネルギー `0.245<M`) はAに戻り、`s=1.4` (初期エネルギー `0.98>M`) はBへ移る。**数値初期値例であり、エネルギーが高ければ必ず移動するという定理ではない**。
