# Laakso：複数ビットのゲート走査費用を直接評価する

日付：2026-11-23。作業場所：[primitive-lean PR #211](https://github.com/Sumuji-zkdwn/primitive-lean/pull/211)（Draft）。
対象は**有限**の水平移動と無料ビット反転からなる距離模型。無限Laakso商の測地性や砂山の物理的粒数による距離を証明するものではない。

## I. 2ビット間の下界（Leanで検証済み）

任意のビット集合 `ι`、ゲート述語 `G(k,h)`、高さ変換 `Φ:ℝ→ℝ` を取る。有限歩行 `w:(s,b)→(t,b')` は次の二種類の操作により構成する。

- 水平移動 `(x,b)→(y,b)`、費用 `|Φ(x)-Φ(y)|`
- ゲート `G(k,x)` で `b_k` のみを反転、費用0

異なるラベル `i≠j` に対し `b_i≠b'_i` かつ `b_j≠b'_j` なら、各ビット用に実際に訪問したゲート `u,v` が存在して

[
G(i,u),\quad G(j,v),\quad
2|\Phi(u)-\Phi(v)|\le c+|\Phi(s)-\Phi(t)|
]

となる。**`LaaksoGateCost.two_changed_bits_span_lower` は、任意の有限歩行と任意の `Φ` に対してLeanで証明済み。** 単一ビットの迂回評価を単に最大値で結合したのでは得られないゲート間の往復費用を捕捉する。

証明は最初の操作についての帰納法：
- 水平移動なら三角不等式で残りの歩行へ帰着。
- 第 `i` ビットのゲートを通ったなら、その高さを `u` とし、残りの歩行には第 `j` ビットの変化が必ずあるため、既存の単一ビット迂回下界を使う。
- 第 `j` ビットでも対称。
- 別ビットなら両方の変化が残り、帰納仮定を適用する。

## II. ゲートが一つずつなら上界と一致

ラベル `i,j` のゲートがそれぞれ**唯一** `a<b` にあるとする。高さ変換 `Φ` が単調増加で、`a≤s≤b` のとき、二つのビットを反転して `s` に戻る最短費用の候補は

[
s\to a\ (i\mathrm{\ flip})\to b\ (j\mathrm{\ flip})\to s,\qquad
c=2(\Phi(b)-\Phi(a)).
]

下界 I で訪問ゲートは唯一なので `u=a,v=b`。始点終点の高さが同じだから、
すべての歩行で `c≥2(Φ(b)-Φ(a))`。上の具体的歩行で等号になる。

形式化候補：`LaaksoGateCost.two_gate_sweep_realizable` と
`LaaksoGateCost.exact_two_unique_gate_roundtrip_infimum`。
これらはGitHub Actionsでのカーネル確認が必要であり、このノートの存在だけで検証済みとはしない。

## III. 独立の有限計算

左右に一つずつゲート `a=1/3,b=2/3` を置いた2ビット4シートのグラフで、7つの高さ格子点全組を調べた。始点シート0について49組、XOR対称性で4つの始点シート全てを代表するため1ゲージあたり196組。標準・二乗・区分線形goodの3ゲージで合計**588順序付き点対**。Dijkstra最短路とゲート `a,b` を両方訪れる走査公式は、Python `Fraction` の有理数演算で完全一致した。

中央高さ `s=1/2` で二つとも反転させる標準ゲージの最短費用は `2/3`。
これに対し、第1ビット単独・第2ビット単独の往復費用はそれぞれ `1/3`。
従って、2ビット同時の距離は `max(単一ビット距離)` では一般には求まらない。

検算器：`docs/research/laakso_two_bit_span_probe.py`。有限2ゲート模型の結果であり、三進Laaksoの全段・全観測量に対する反例と取り違えない。
