# 遅延硬化エーテル模型・第18回：非球対称変形、四極応答、重力初期拘束

## 結論

1. **数学的に確定**：球対称の位相場と記憶場を同一の体積保存線形変形で引き伸ばす族では、二次＋Skyrme四次の静的エネルギーが球形で最小になる。これは一般の体積保存アフィン変形にもAM–GMから拡張できる。ただし任意の空間変形についての定理ではない。
2. **数値検証済み**：楕円変形に加えて、中心付近だけを歪ませる滑らかな非アフィンの四極変形を試し、全条件で物質エネルギーが増加。有限解像度（48³、72³、96³）と有限の試験方向に限る。
3. **数値検証済み**：変形に応じてエネルギー密度が変わる場合、ニュートン近似の重力結合は楕円変形の復元力を弱めるが、今回のG=0.002では復元力が勝つ。固定密度の単純な楕円変形とは重力側の符号が違う点に注意。
4. **数値検証済み**：非球対称の位相場＋記憶場を源にした、3次元の**非線形Einsteinハミルトニアン初期拘束**を解いた。計量は共形平坦、外部曲率ゼロ（時間対称）。運動量拘束は初期状態において恒等的に満たす。時間発展もTT重力波もまだ未実装。
5. **限定的な運動検査**：位相場の「楕円変形の大きさ」1自由度だけを残した有効運動方程式を導出して積分。復元振動とエネルギー保存を確認。ただし球形プロフィールを固定した集団座標模型であり、全三次元場の線形安定性・非線形安定性の証明ではない。

## 1. 出発点

第17回で使用した一般共変物質作用の平坦静的極限を採用。

- 内部場 `q(x)=(cos f(r), sin f(r) n)`、`n=x/r`。位相次数は境界条件と方向保存型変形により1。
- 記憶場 `χ(x)=cos f(r)` を初期基準とし、別の静的スナップショットでは `χ=cos f+0.06 exp(-r²/4)` のずれも試す。
- `A(χ−q⁰)=1+2 tanh²((χ−q⁰)/0.28)`。遅延を含む時間発展は**第18回の運動検査にはまだ未実装**である。
- 四次項係数 λ=0.2、ポテンシャル κ=0.9、μ=0.15。第17回のコンパクトな`f(r)`を変更せず再利用。
- 単位はすべて模型単位。重力結合`G=0.002`。

静的なエネルギー密度を、内部場の空間微分Gram行列 `C_ij=∂_i q·∂_j q` を用いて

```
ρ₂ = 1/2[A tr(C)+|∇χ|²]
ρ₄ = λ/4[(tr C)²−tr(C²)]
ρ₀ = κ/2(χ−q⁰)²+μ²/2(χ−1)²
```

とする。これらは`ρ=ρ₂+ρ₄+ρ₀≥0`を満たす。静的エネルギーは `E=∫ρd³x`。

## 2. 体積保存アフィン変形の厳密な式

`M_s=diag(exp(s),exp(−s),1)`、`q_s(x)=q₀(M_s x)`、`χ_s(x)=χ₀(M_s x)` とする。`det M_s=1`。球対称の基準場で角度積分すると、

```
E₂(s)=E₂(0) (1+2 cosh(2s))/3
E₄(s)=E₄(0) (1+2 cosh(2s))/3
E₀(s)=E₀(0)
```

これは一般の`M∈GL⁺(3), det M=1`にも拡張でき、

```
E₂(M)/E₂(I) = tr(MᵀM)/3
E₄(M)/E₄(I) = tr((cof M)ᵀ(cof M))/3
```

となる。`det M=1`より singular values の積1、AM–GMから各traceは3以上なので、体積保存アフィン変形のエネルギーは回転を除いて球形で最小。場のプロファイルを変える一般摂動の安定性までは含まない。

30,001点の半径積分で `E₂(0)=60.589153`,`E₄(0)=5.715651`,`E₀(0)=0.256522`。96³格子の三次元直接積分と厳密式の最大絶対差は1.2×10⁻⁶。

## 3. 自己重力の弱場検査

静的エネルギー密度`ρ_s(x)`の二重積分

```
U_G(s)=−G/2 ∫∫ ρ_s(x) ρ_s(x')/|x−x'| d³x d³x'
```

を、孤立境界のゼロパディングFFT畳み込み（48³・72³・96³）、セル自己積分の近似込みで計算。36の格子位置比較ではなく、3解像度で同じ基準プロフィールを用いた。96³で：

| s | E_mat(s) | U_G(s) | E_mat+U_G |
|---:|---:|---:|---:|
| 0.00 |66.561324|−2.336253|64.225071|
| 0.08 |67.128333|−2.374340|64.753992|
| 0.16 |68.843906|−2.491177|66.352729|
| 0.24 |71.752058|−2.694674|69.057384|

重力エネルギーの変化は負で、物質側の正の変化を部分的に相殺する。**理由**：今回のρ_sは変形に伴う勾配エネルギーが増え、重力源の総量そのものも変わる。固定密度を受動的に変形する場合には、逆に球状分布が最も強く結合する（体積保存の場合）。二つを混同しないこと。

非球対称源の重力四極子`Q_ii=∫ρ(3x_i²−r²)d³x`も計算。s=0.16, N=96で`Q_x≈−73.4523, Q_y≈81.6284, Q_z≈−8.1761`。r=24の外部ポテンシャルを直接数値積分すると、単極子＋四極子近似の相対誤差はx方向4.6×10⁻⁶、y方向5.6×10⁻⁶。単極子のみより約200倍近く精密となった。

このニュートン近似は一般相対論の強場極限へ直接外挿できない。

## 4. 局所的な非アフィン四極変形

`F_ε(x)=x+ε exp(−|x|²/σ²)diag(1,−1,0)x` と定義し、`q_ε=q₀∘F_ε`、`χ_ε=χ₀∘F_ε`。

ヤコビアンについて

```
||DF_ε−I||op ≤ 2 exp(−1/2)|ε|
```

が成立する。したがって |ε|<exp(1/2)/2 ≈0.82436 ならF_εは全空間で局所的に可逆かつ方向保存。無限遠では恒等変換に近づくため、位相次数1のまま変形可能。今回は|ε|≤0.2。

各点のJacobianを明示的に計算し、勾配を変換して物質エネルギーを求めた。

96³格子、ε=0.1での中央差分二階微分`[E(+ε)−2E(0)+E(−ε)]/ε²`は、σ=2.5で76.507、σ=4.5で137.412、σ=7で174.195。全て正で、48³・72³との比較でも同じ符号。

**ただし**調べたのは3種類の幅と小変形に限る。`ε→0`の厳密なHessianや無限次元摂動スペクトルではない。これらの非アフィンのエネルギー計算には重力項をまだ入れていない。

## 5. 制限された四極運動の1自由度検算

s(t)だけを自由にし、局所構造の半径方向プロフィールを固定する`q(x,t)=q₀(M_{s(t)}x)`、`χ(x,t)=χ₀(M_{s(t)}x)`を採用する。4次Skyrme作用の時間–空間混合項も含む有効慣性`I(s)`を数値積分し、

```
L_eff = 1/2 I(s) ṡ² − [E_mat(s)+U_G(s)]
I(s) s̈ + 1/2 I'(s) ṡ² + V'(s)=0
```

をDOP853で積分。

- I(0)=151.47148、Skyrme由来の慣性比率3.917%。
- 力学系の復元剛性`V''(0)≈164.977`（物質176.813、重力−11.836）。
- 微小振動の予測周期`2πsqrt(I/V'')=6.0205`。
- 初期`(s, ṡ)=(0.12,0)`、模型時間20まで実行した周期約6.0023、全エネルギー相対ドリフトの最大値9.76×10⁻¹⁰。

これは**1自由度への射影**であり、3次元の場そのものの運動を解いていない。自由な内部振動、重力波、記憶場固有の遅延、散逸は含まない。位相次数は変形族の定義で固定される。

## 6. 非球対称Einstein初期拘束（真の3次元非線形方程式）

三次元空間の計量`γ_ij=ψ⁴δ_ij`、外部曲率`K_ij=0`、内部場・記憶場の時間微分0と仮定。運動量拘束は`S_i=0`で恒等的に成立。Hamiltonian拘束の連続式は

```
Δψ = −2πG(ψ ρ₂ + ψ^(−3)ρ₄ + ψ⁵ρ₀)
```

となる。これを立方体[-15,15]³上の7点差分法とDSTにより反復求解した。外周のDirichlet値は漸近Green関数の単極子＋四極子から近似。外周を無限遠にしたわけではない。

81³格子で、

| s | ψ(center) | ADM質量推定値 | 離散方程式の相対L2残差 |
|---:|---:|---:|---:|
|0|1.05698849|68.017880|7.22×10⁻¹²|
|0.16|1.05880273|70.399588|7.15×10⁻¹²|

41³・61³格子でも質量が収束傾向。s=±0.16で質量が浮動小数点精度内で一致する対称性も確認。外周の4点で、近似Dirichlet値と直接Green積分値の差は摂動ψ−1に対して最大3.7×10⁻⁵。

**重要**：拘束残差の10⁻¹¹は反復・離散方程式の誤差であり、連続方程式を10⁻¹¹精度で解いた主張ではない。格子精度、モデル化誤差、境界近似は別。時間発展、重力波の自由度、正則な全時空解の存在は未検証。共形平坦な初期計量だけではTT自由度を自由に励起できない。

## 8. 正確な到達点と未解決項目

- **確認**：特殊な非球対称変形に対する復元エネルギー、弱重力での四極応答、共変物質理論に基づく非球対称のEinstein初期拘束。
- **未確認**：任意の非球対称変形に対する固有モードの符号／スペクトル、位相保存を伴う全三次元場の長時間時間発展、重力波、不可逆な遅延硬化、特殊相対論を仮定しない一般相対論の創発。
- **今後の最短経路**：最初に静的Einstein–Skyrme–χの**平衡解**を求める。現在の第17回の局在プロフィールは任意に与えた初期値で、平衡解ではない。そこを確定してから非球対称 ℓ=2 の線形化固有値問題（正準拘束・ゲージ除去を含む）へ進む。強い重力では非線形3+1進化の数値拘束保存も必要。
- **先行研究**：自己重力Skyrmionの動径安定性や非球対称構成は既存の分野である。1991年のHeusler/Droz/Straumannは、位相次数が保存されても重力結合が強いと不安定モードが現れることを示した。この研究でそれを再発見したと主張しない。
