# 遅延硬化エーテル模型・第11回：固定境界の局在位相電荷、内部計量との結合、遅延硬化

日時：2026-11-22（日本時間）／第10回からの継続

## 目的と結果の区別

前回の周期的な3次元空間で保存されるZ₂面フラックスは、周期境界を一周する非局所ループであった。今回は普通の有限立方体 \([-1,1]^3\) を周期化せず、外周の内部状態だけを真空値に固定して、**点状の局在構造が持つ整数の位相次数**を扱う。さらに、同じ内部状態の変化量で四面体の内部辺長を決め、非零のRegge角度欠損を実測し、履歴に依存する計量応答を加える。

**確定したもの**：(1) 境界値を固定した3次元箱の単一局在構造の位相次数が±1、二つなら±2。6³と8³の別構成では頂点・逆像・行列式を全て有理数で検査し、正規化前ベクトルが四面体内部でゼロにならないことを確かめた。(2) 変形エネルギーを辺長へ結合すると非零のRegge角度欠損が得られ、純粋な座標移動の場合にはゼロ。(3) 後述の四次エネルギーにより縮尺族の有限半径極小が得られ、格子収束傾向を検査。(4) 記憶が実際に緩和力に作用する離散更新を作り、駆動停止後のエネルギー減少と外部仕事・散逸の会計を検査。

**未達**：全変形に対する局在構造の動的安定性、自己無撞着な物質・計量連成、重力の等価原理、長距離逆二乗力の非仮定的導出、4次元ローレンツ計量・Einstein方程式。局所位相次数はSkyrme模型で知られる構造の再実装であり、重力理論の発見ではない。

## 1. 固定境界と写像次数

各格子頂点 \(x\in[-1,1]^3\) に \(q(x)\in S^3\subset\mathbb R^4\) を置く。外周では \(q=(1,0,0,0)\) とする。内側では中心 \(c\)、半径 \(R\) に対して

\[
q(x)=\left(\cos f(r),\frac{\sin f(r)}{r}(x-c)\right),\quad f(r)=\pi\max(1-r/R,0),\quad r=\|x-c\|.
\]

有限箱の外周を一点に同一視すれば定義域は位相的に \(S^3\) となる。連続かつ無特異点で、外周の値を固定する変形の間は写像次数 \(\deg(q)\in\mathbb Z\) が保存される。今回の符号規約では「Skyrme電荷」\(B=-\deg(q)\) と書く。 **この保存は境界条件から完全に独立なわけではない。周期境界は不要だが、外周を真空値に固定する条件は必要。**

一辺の格子分割が 8, 12, 16, 20 のすべてについて、単一局在構造 \(B=1\)、平行移動後 \(B=1\)、異方変形後 \(B=1\)、向き反転 \(B=-1\)、一様状態 \(B=0\)。12,16,20について離れた二局在構造の四元数積から \(B=2\)。境界値の誤差は全例0。正規化した頂点値から四面体内へ正規化アフィン補間し、選んだ正則値の符号つき逆像を数えた。これは数値的な次数計算であり、浮動小数点丸めを含む。

### 1.1 独立した有理数の有限証明書

別の頂点場を、\(a=1/2\) と有理数の中心 \(c=(1/20,-1/25,1/30)\) によって

\[
q(x)=\left(\frac{r^2-a^2}{r^2+a^2},\frac{2a(x-c)}{r^2+a^2}\right)
\]

と置き、境界頂点のみ真空値 \((1,0,0,0)\) に固定する（全頂点値が厳密に有理数で長さ1）。頂点間は \(Q(x)=\sum_i\lambda_iq_i\)、\(q(x)=Q(x)/\|Q(x)\|\) と補間する。境界は一定値になる。

6³格子1296四面体、8³格子3072四面体をそれぞれ検査し、\(q_0\) の符号が混在する200個、310個の四面体で各4頂点の値を列とする4×4行列の行列式が **全て有理数として厳密に非零**。各頂点で \(q_0\ne0\) も確認した。符号が混ざらない四面体ではその成分だけで \(Q\ne0\) が従い、混ざる四面体では行列式非零から \(Q=0\) が生じない。したがって全四面体内部で正規化が定義可能。

有理数方向 \((-1,1/7,-1/11,1/13)\) を正則値として厳密な線形方程式を解くと、どちらの格子でも逆像は1個、符号は−1。ゆえに \(\deg(q)=-1\)、Skyrme電荷 \(B=1\)。この結論は計算の丸め誤差を含まない有限証明書 `exact_degree_certificate.json` に収録。一般の連続模型に対する定理をLean形式化したわけではない。

### 1.2 限界・格子による位相のすり抜け

解析的に次数1の構造でも、半径が格子間隔より小さいと頂点サンプリングで次数0として再構成される。例えば8³格子では半径0.30で検出電荷0、20³格子では同じ半径0.30の電荷は1。これは物理的な粒子消滅ではなく**解像度不足による位相のすり抜け**。`resolution_failure.csv` に各条件を記録。実際の更新計算では正規化アフィン補間がゼロに近づくかを監視する必要がある。

## 2. 局在場から四面体の内部計量へ（仮定した構成則）

3次元の立方体をFreudenthal法で6四面体／小立方体に分割する。内部状態の差の二乗から各頂点の源 \(s_i\) を構成し、物理幅0.15のガウス平滑化を行い、最大値で正規化して \(0\le s_i\le1\) とする。**以下の結合則は仮定であり、重力方程式から導いたものではない**：

\[
\ell_{ij}=\|x_i-x_j\|\exp\left(\frac{\alpha(s_i+s_j)}2\right).
\]

この長さから各四面体のGram行列が正定値かを検査し、隣接四面体の内二面角から内部辺のRegge角度欠損

\[
\delta_e=2\pi-\sum_{t\ni e}\theta_{e,t}
\]

を計算する。これが非零なら、この分割の**内部辺長幾何**は平坦なユークリッド空間とは異なる。ただし \(\sum_e\ell_e|\delta_e|\) は便利な非負の曲率指標にすぎず、一般相対論のリッチスカラーや物質の質量を意味しない。

16³格子の \(B=1\) 構造で \(\alpha=0\) の角度欠損最大値は \(2.66\times10^{-15}\)、\(\alpha=0.04\) では最大 \(7.5227\times10^{-3}\) rad、\(\sum\ell|\delta|=2.36980\)。この間、位相次数は変わらない。8³、12³、16³の各格子で非零曲率の発生を確認したが、曲率分布そのものの厳密な収束定理は未証明。

独立の陰性対照として、外周を固定した滑らかな**座標変形のみ**を施し、新しいユークリッド座標から辺長を計算すると、16³格子で最大角度欠損 \(5.33\times10^{-15}\) に留まった。内部計量の非平坦化と、単なる座標の再配置を区別できた。

## 3. 有限半径と粗い格子の偽の崩壊

\(E_2=\tfrac12\int\sum_i|\partial_iq|^2d^3x\)、\(E_4=\tfrac12\int\sum_{i<j}|\partial_iq\wedge\partial_jq|^2d^3x\) と定義する。半径 \(R\) の前節の縮尺族では厳密に

\[
E(R)=A R+\kappa_4\frac{C}{R},\quad A=26.9540364274,\ C=75.2787024359.
\]

今回は \(\kappa_4=0.08249624119\) として縮尺族の極小を \(R_\ast=\sqrt{\kappa_4C/A}=0.48\) に設定した。これはデータへのフィッティングではなく、検算しやすい係数の選択。

中心差分による有限格子で半径を0.24から0.76まで走査した最小位置は、一辺の分割数20で0.24、40で0.40、60で0.44、80/100/120で0.48。20の格子では数値微分が小半径の高周波勾配を過小評価するため、見かけ上の崩壊が生じる。細分化で連続模型の予測に近づくが、全変形に対する安定性、非線形時間発展の安定性は**証明していない**。

## 4. 計量への時間遅れと実際の硬化フィードバック

局所構造の中心 \(c(t)\) を外部から移動させる。時刻0〜4でx座標−0.20から+0.20へ等速移動し、時刻4以降は固定する。これは自由運動を解いたわけではない。各頂点で瞬時の目標幾何を \(\sigma^\ast_i(t)=\alpha s_i(q_t)\)、実際の遅延計量を \(\sigma_i(t)\) とし、辺長は \(\ell_{ij}(t)=\|x_i-x_j\|\exp[(\sigma_i+\sigma_j)/2]\)。

記憶差 \(y_i=\sigma_i^\ast-\sigma_i\) に対して、正値で有界な接線剛性を持つポテンシャル

\[
\Phi(y)=\frac{k+\Delta}{2}y^2-\Delta a^2\log\cosh(y/a),\quad\Phi''(y)=k+\Delta\tanh^2(y/a)
\]

を使った。\(k=0.8,\Delta=3,a=0.012\)、\(0.8\le\Phi''\le3.8\)。緩和を \(\dot\sigma_i=\Phi'(y_i)/(k\tau)\) と定めたため、剛性は**単なる表示指標でなく、記憶の力学更新に入る**。目標幾何が静止している間は

\[
\frac{d}{dt}\sum_i\Phi(y_i)=-\frac1{k\tau}\sum_i(\Phi'(y_i))^2\le0.
\]

動く目標に対しては、外部仕事 \(W\) と散逸 \(D\) を別々に台帳へ記録する。明示Euler更新では、各時刻の「目標変更」「記憶緩和」を分離して実測ポテンシャル差から \(W,D\) を正確に集計した。161時点×2緩和時間、\(\tau=0.2,0.8\)、格子12³。最大硬化係数はそれぞれ0.867743、1.517510。記憶の追従が遅いほど、構造と計量の重心ずれが大きい。時刻4以降の記憶エネルギーは単調減少。離散台帳の最大会計誤差は \(2.16\times10^{-17}\)。各測定時刻に \(B=1\)、四面体Gram行列は正定値。

**ただし**：qの運動は外部駆動であり、q自身の運動方程式は解いていない。計量とqの自己無撞着な交換、全エネルギー・運動量の保存、ローレンツ共変性は未実装。「遅延幾何と位相局在を同じ有限状態に置く」代理模型である。

## 5. 監査、否定例、次の有限課題

| 論点 | 結果 | 状態 |
|---|---|---|
| 周期境界なしの整数位相電荷 | 有理数の独立計算で次数−1 | 確定（有限模型） |
| 同じ場から非零の内部曲率 | 辺長の仮定した結合で可能 | 数値確認 |
| 純粋な座標変化での曲率 | 角度欠損ほぼゼロ | 陰性対照 |
| 位相局在の有限半径 | Skyrme四次項を置けば縮尺族に極小 | 確定（制限付き） |
| 時間遅延・硬化による計量追従 | 散逸付き更新と仕事台帳を確認 | 数値確認 |
| 安定粒子の完全な自己運動 | 未構成 | 未解決 |
| アインシュタイン方程式・量子論の復元 | 未導出 | 未解決 |

次は独立に指定した構成則 \(\sigma^\ast=\alpha s(q)\) を作用の変分から得ること、qと辺長を同時に時間発展させて位相保存・双曲性・エネルギー会計が成立するかを検査する。重力側には少なくとも4次元ローレンツ計量の自由度と非線形拘束が必要。ここを導入せずに「既存物理の復元」と呼ばない。
