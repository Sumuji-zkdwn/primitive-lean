# Laakso三進ゲート：有限最短路から無限走査距離への接続（内部自己監査）

2026-11-23 / PR #211 の継続。対象は同じ三進ゲート商の**水平・ビット因子**であり、円周因子は和距離として別途加算する。物理砂山の一粒投入数を道長と同一視しない。

## 1. 有限段の定義

高さは `s,t∈[0,1]`、ビット列は `b,c∈{0,1}^ℕ` とする。三進ゲート集合は

`W_k={j/3^k: 0<j<3^k, 3∤j}` (`k≥1`)。

段 `m` では先頭 `m` ビットだけを保持する。水平方向の費用は狭義単調連続な `Φ` を使って `|Φ(s)-Φ(t)|`、ゲート `W_k` における第 `k` ビットの反転は費用0とする。

許容区間の集合を

`F_m(s,t,b,c) = { (l,u): 0≤l≤min(s,t)≤max(s,t)≤u≤1, (b_k≠c_k, k≤m) ⇒ [l,u]∩W_k≠∅ }`

とする。走査費用は

`C_Φ(l,u;s,t)=2(Φ(u)-Φ(l))-|Φ(s)-Φ(t)|`。

## 2. 有限最短路の走査公式（紙上の経路正規化）

有限グラフにおける最短路距離を `d_m` とすると、

`d_m(s,b;t,c)=min_{(l,u)∈F_m}C_Φ(l,u;s,t)`。

**下界**：任意の有限歩行の訪問高さの最小・最大値を `l,u` とする。終点までに異なるビット `k` は少なくとも奇数回反転され、その反転は `W_k` 上でのみ可能なので `[l,u]` は全必要ゲートを含む。道は `l,u` の両方を訪問する。水平座標 `Φ` 上の総変動は訪問順のどちらについても

`|Φ(s)-Φ(l)|+[Φ(u)-Φ(l)]+|Φ(u)-Φ(t)|`、
または `|Φ(s)-Φ(u)|+[Φ(u)-Φ(l)]+|Φ(l)-Φ(t)|`

以上である。二つのうち小さい方は `C_Φ(l,u;s,t)`。ゲート反転の費用は0なので最短路もこれ以上。

**上界**：許容区間 `[l,u]` を固定する。必要なビットの各々について `[l,u]∩W_k` から一つずつゲートを選ぶ。段数 `m` は有限なので、選んだゲートを高さの順序に整列できる。始点が終点以下なら `s→l→u→t`、そうでなければ `s→u→l→t` と一回だけ全区間を横断し、ゲートに来たとき必要なビットを一度反転する。水平移動費用は正確に `C_Φ(l,u;s,t)`。こうして全許容区間での最小値まで上から評価できる。

**形式化状況**：`LaaksoFiniteGateWalk.differing_bit_requires_gate` は「ビット差があれば対応ゲート訪問が必要」をLeanで証明済み。訪問高さの最小・最大値による総変動下界と、ゲート順序の整列・最短路実現は、このファイル作成時点では紙上証明。単独のPython検算 `laakso_exact_walk_sweep.py` は標準、区分線形good、二乗ゲージの深さ1〜3で有理数の完全一致を確認するが、形式証明ではない。

## 3. コンパクトな許容区間族と無限段

各 `W_k` は有限集合なので、`[l,u]∩W_k≠∅` は

`⋃_{w∈W_k}{(l,u):l≤w≤u}`

と書ける**有限個の閉集合の和集合**であり閉。したがって `F_m` はコンパクト正方形 `[0,1]²` の閉集合で、`F_{m+1}⊆F_m` である。全区間 `(l,u)=(0,1)` が全段で許容されるから非空。連続な `Φ` に対して `C_Φ` は連続であり、最小値は達成される。

`a:=sup_m d_m` は有限（全区間の費用で上界）。各段について `d_m≤a` だから `F_m` 内に費用が `a` 以下の区間がある。閉・入れ子・コンパクト性から、

`∃(l,u)∈⋂_m F_m, C_Φ(l,u;s,t)≤a`。

反対に `F_∞=⋂_m F_m` の任意の区間はすべての `F_m` に属するから、`d_m≤C_Φ` を全段で満たす。従って

`boxed: sup_m d_m = min_{(l,u)∈F_∞} C_Φ(l,u;s,t)`。

これは**有限段距離の単調上限**と**全ゲートを満たす無限走査費用の下限**の同一視である。

**形式化状況**：`LaaksoNestedGateCompactness.infinite_cost_threshold_iff` は、一般のコンパクト空間における入れ子閉集合の閾値同値をLeanで証明済み。個別の有限ゲート条件 `F_m` の閉性・単調性は `LaaksoGateConstraint.lean` で検査対象。有限最短路と走査公式の同一視がLeanでまだ接続されていないので、全体を「Lean証明済み」とはしない。

## 4. さらに別の問い：実際の曲線による道長との一致

上の等式で分かるのは、定義された `d_∞:=sup_m d_m` と走査費用の同一視である。**任意の二点間に長さ `d_∞` の実際の可長曲線が存在する**という測地性、またこの距離が商の内在的道距離と一致することには、有限曲線の整合化・一様Lipschitz再パラメータ化・コンパクト性などが別途必要である。有限の個々の経路の存在だけから自動的に結論してはいけない。

また、PI不成立を全可長曲線の上勾配として述べるためには、この道距離との対応が重要である。
