## 1. Four distinct properties

Let \((S,\cdot)\) be an associative total binary system, \(\pi:S\to Q\) a surjective readout, \(F_q=\pi^{-1}\{q\}\), and \(P\cdot R=\{xy:x\in P,y\in R\}\).

1. **Single-valued descent:** the kernel of \(\pi\) is a congruence. Then a deterministic product on \(Q\) reproduces the original readout exactly. **This case is already handled by existing Lean declarations.**
2. **Hyper-associativity:** the relation-valued product \(q\star r=\pi(F_qF_r)\), extended by union to subsets of \(Q\), obeys associativity. Necessary and sufficient:
   \[
   \pi(\sigma(F_pF_q)F_r)=\pi(F_p\sigma(F_qF_r))
   \]
   for all labels, where \(\sigma(U)=\pi^{-1}(\pi(U))\). Equality does **not** entail faithful evaluation of products.
3. **Right-streaming exactness on reachable sets:** for every nonempty word \(w\) of labels, let \(P(w)\) be the exact product of the corresponding fibers. The left-folded abstract hyper-product reports \(\pi(P(w))\) for all \(w\) if and only if
   \[
   \pi(\sigma(P(w))F_q)=\pi(P(w)F_q)
   \]
   for every reachable exact \(P(w)\) and every label \(q\). Necessity follows by extending \(w\) by \(q\); sufficiency is induction on word length. This condition **only** controls left-streaming of nonempty label words, not all abstract bracketings.
4. **Exact-set completion and contextual minimization:** retain \(P(w)\subseteq S\) as the state; setwise product is automatically associative. Let \(R\) be the subsemigroup of \(\mathcal P(S)\setminus\{\varnothing\}\) generated by the fibers. The readout \(\rho(U)=\pi(U)\) makes \(R\) an observable semigroup. Its maximal observation-preserving congruence is the two-sided contextual kernel:
   \[
   U\approx V\iff \forall L,M\in R^1,\ \rho(LUM)=\rho(LVM).
   \]
   The quotient \(R/{\approx}\) is the **minimal exact deterministic compositional representation of this generated-set semantics** (via the existing \`JoinContextualEquivalence\` general theorem). Finite bound: \(1\le |R/{\approx}|\le |R|\le 2^{|S|}-1\).

The new Lean theorem \`forwardComplete_iff_all_words\` proves the stronger **global** version of streaming completeness, with arbitrary initial uncertainty \(U\subseteq S\). In contrast, the Python census tests the strictly weaker **reachable-only** version. Do not conflate them.

## 2. Complete 4-state census: associativity vs streaming exactness

All 3,492 **labelled** associative tables on four states were generated by exhaustive backtracking with sound associativity constraint propagation. Cross-check each full table with a direct 64-triple test. Each table has 15 set partitions, for **52,380** table-partition pairs.

| Single-valued descent | Hyper-associative | Right-streaming exact | Pairs |
|---|---|---|---:|
| yes | yes | yes | 21,766 |
| no | yes | yes | 16,406 |
| no | yes | **no** | 3,408 |
| no | **no** | yes | 2,124 |
| no | **no** | **no** | 8,676 |

Thus, hyper-associativity and one-sided streaming correctness are **logically independent**, even when the concrete product is associative. Hyper-associative/nonexact examples and nonassociative/streaming-exact examples both occur.

Aggregating the first two columns gives the earlier census: 21,766 deterministic, 19,814 non-deterministic but hyper-associative, and 10,800 hyper-nonassociative.

For all 10,800 hyper-nonassociative cases, exact set closure and the maximal two-sided observational congruence were computed. The maximum generated exact set count was **13**. An elementary witness is \(S=\mathbb Z/4\mathbb Z\) with observation fibers \(\{0,1\},\{2\},\{3\}\). Both exact-set closure and contextual minimum have **13 states**.

## 3. Cyclic group C5: an associative but nonfaithful hyperoperation

Take \(S=\mathbb Z/5\mathbb Z\), readout fibers \(A=\{0,1\},B=\{2,4\},C=\{3\}\). The hyperoperation is associative, yet:

\[
  (B+B)+C=\{1,2,4\},\qquad
  \pi((B+B)+C)=\{A,B\}.
\]

But after rounding the intermediate \(B+B=\{1,3,4\}\) to complete readout fibers, all five concrete states are admitted. Hence the hyper-left-fold predicts \(\{A,B,C\}\), including the **spurious C**.

Moreover, fiber products generate **all 31 nonempty subsets of** \(S\), and every pair is contextually distinguishable. The singleton class \(C=\{3\}\) generates all five singleton translates; for distinct \(U,V\), choose \(x\in U\triangle V\) and translate by \(3-x\). Then \(3\in U+(3-x)\) differs from \(3\in V+(3-x)\); the uniquely observed class \(C\) detects the difference.

So the minimal exact deterministic uncertainty semigroup has 31 states, despite the concrete system having 5 elements and only 3 immediate observation labels. This *attains* \(2^5-1\) at this one finite size, **not** an asymptotic lower bound for arbitrary \(n\).

The generic group version of the separation argument is expressed in Lean as \`shifts_separate_subsets\`: if one \(c\) has a unique observation, equality of readouts after every right translation by singleton \(\{g\}\) forces equality of the input subsets. This does not require a finite group; use it for a generated semantics only when all those singleton shifts are actually available as contexts.

## 4. All cyclic observation partitions up to n=9

For cyclic addition \(C_n=\mathbb Z/n\mathbb Z\), exhaust every set partition (Bell number \(B_n\)), compute the generated exact-set semigroup using bitmask cyclic sumsets, then independently cross-check each maximum witness with an explicit frozenset implementation. For every maximum witness, some observation fiber is a singleton containing a generator of \(C_n\). Thus the translation-separation argument proves its exact generated subsets are all contextually distinct, making the following maxima **also maxima for the minimal contextual quotient** over these partitions.

| n | partitions tested | maximum exact/minimal states | one witness (restricted-growth partition) |
|---:|---:|---:|---|
| 3 | 5 | 7 | 0,0,1 |

For \(n=9\), the five fibers are \(\{0,1\},\{2,5\},\{3,7\},\{4,6\},\{8\}\); the singleton \(\{8\}\) is a generator since \(\gcd(8,9)=1\). From only **five labels**, multiplication generates **223** pairwise context-distinguishable uncertainty states. The *only* search claim here is over partitions of the standard cyclic groups \(C_n\), not all \(n\)-element semigroups or arbitrary group actions.

## 5. Compression is sometimes possible

Let \(S\) be the nine affine transformations of \(\mathbb F_3\), \((a,b):x\mapsto ax+b\), composed as \((a,b)\cdot(c,d)=(ac,ad+b)\). Observe only \(b\) (the output at 0). Then three observation fibers generate **seven** distinct exact subsets, but only **four** contextually distinguishable classes. This demonstrates a nontrivial exact deterministic compression: retaining every subset is safe, but not always necessary.
