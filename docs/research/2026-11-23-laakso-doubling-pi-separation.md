# 同じ全観測直径・同じ測度・両側倍加性を保ちながら弱(1,1)-PIだけを分離する構成

2026-11-23 / 研究ノート・紙上証明（Leanカーネル検証は未実施）

## 0. 定理の範囲と原稿への位置付け

以下は `primitive-lean` PR #209（A案）で未解決とされていた「同じ三進ゲート商・同じ測度・同じ `A_m` を持ち、**両者とも倍加的**なのに弱 `(1,1)`-PI の成否が異なるか」に対する**構成による肯定解**を提案し、必要な解析の紙上証明を与える。原稿PR #208の `bad` が非倍加であった限界を、新しい `bad` で解消する。

これは**砂山の物理的な操作費用についての定理ではない**。既存の正方格子砂山が作る時計・ビットの有限観測を、ゲート付き商空間の設計に使う。以下の解析の証明では砂山の群演算は不要。標準Laakso商の倍加性・弱 `(1,1)`-PIは既知の解析的入力であり、このノートで初めて証明したものとはしない。外部査読は受けていない。

### 定理（紙上証明）

標準三進ゲート `W_k={j/3^k:0<j<3^k,3∤j}` による `X_L=([0,1]×{0,1}^N)/~` を用い、円周 `T` を付ける。元の高さを `s`、固定測度を

`μ = q_#(ds ⊗ fair-bits ⊗ dθ)`

とし、長さ座標だけを増加同相 `Φ:[0,1]→[0,1]` で測る（道上の水平方向費用 `|dΦ(s)|`、円周方向費用 `|dθ|`、ゲート反転費用0）。有限段の道距離の単調上限で距離 `d_Φ` を定める。

この仕様で `Φ_good,Φ_bad` を次のように選べる。

1. `d_good` と `d_bad` は同じ集合、同じ商、同じ `μ`、同じ接頭ビット観測と円周因子を持つ。
2. **全ての m≥0 で** `A_m(good)=A_m(bad)=(5/2)3^{-(m+1)}`。
3. **両方とも `μ` は倍加的**である。
4. `good` は弱 `(1,1)`-PI を満たし、`bad` は満たさない。

二模型の全ての点対距離が一致するわけではない。`A_m` は観測ファイバーの**最大直径だけ**を残した量である。

## 1. 定義：有理数で厳密に整列する「谷」

`z_n=6^{-n}`, `s_n=3^{-n}`, `n≥1` とする。`J_n=[z_{n+1},z_n]` の幅は `ℓ_n=(5/6)6^{-n}`。そこで三角形関数

```
v_n(z) = (2/ℓ_n) min(z-z_{n+1}, z_n-z)  (z∈J_n)
```

を置く。これは両端で0、中央で1、区間平均 `1/2` の非負関数である。

長さ座標 `z∈[0,1]` 上の密度を

```
ρ(z) = 4/5 + (8/5)(2^n-1)v_n(z)     (z∈J_n, n≥1),
ρ(z) = 4/5                           (1/6≤z≤1)
```

とする。`z=0` の値は積分に影響しない。`ρ≥4/5`、`ρ` は可積分である。

`F(z)=∫_0^z ρ(u)du` とすると、各 `J_n` の質量は**厳密に**

```
∫_{J_n}ρ dz = ℓ_n (4/5 + (4/5)(2^n-1))
            = (2/3)3^{-n}.
```

したがって `F(1/6)=Σ_{n≥1}(2/3)3^{-n}=1/3`、右側の質量は `∫_{1/6}^1ρ=2/3`、`F(1)=1`。しかも

**`F(z_n)=3^{-n}=s_n` が全ての n≥1 で成立。**

`Φ_bad=F^{-1}` とする。`F` は厳密増加・連続なので逆同相が存在し、`ρ≥4/5` より `Lip(Φ_bad)≤5/4` である。

比較側を

```
Φ_good(s) = s/2                          (0≤s≤1/3),
Φ_good(s) = 1/6 + (5/4)(s-1/3)         (1/3≤s≤1)
```

とする。右半分（実際には `s≥1/3`）では `Φ_good=Φ_bad` で、どちらも傾き `5/4`、リプシッツ定数は正確に `5/4`。`good` は正の上下勾配を持ち、標準の `X_L×T` に双リプシッツ同値である。

## 2. 観測直径は全段で完全に一致する

各 m で `h=3^{-(m+1)}` とする。先頭 m ビットと高さ・角度を等しくする二点を結ぶには、高さを含む幅 h の三進セルの両端を訪れて戻る経路を使える。そのセルは第 m+1 ゲートを少なくとも片側端に持ち、より細かい全段のゲートを内部に持つ。従って

`A_m ≤ 2 Lip(Φ) h = (5/2)h`。

一方 `s=1` で第 `m+1` ビットだけ異なる点対は、最寄りの同段ゲート `s=1-h` まで必ず往復する。両 `Φ` は `[2/3,1]` 上で傾き `5/4` だから必要費用は `(5/2)h`。よって

**`A_m(good)=A_m(bad)=(5/2)3^{-(m+1)}`**。

これは有限段の距離比較と極限の一様上界から導く。有限実験の外挿ではない。

## 3. 解析補題：1次元密度 ρ(z) dz の倍加性（訂正版）

**以前の証明の誤りを訂正する。** `u(z)=2^n v_n(z)` (`z∈J_n`), `u=0` (`z≥1/6`) とおくと、`u(z)dz` は `[0,1]` 上の倍加測度**ではない**。たとえば中心 `x=1/6+3r/2`、`r>0` が十分小さい場合、半径 `r` の球の `u dz` 質量は0なのに半径 `2r` の球は `[0,1/6]` に食い込んで正の質量を持つ。したがって「`dz` と `u dz` が両方倍加的だから和も倍加的」という議論は、そのままでは成立しない。

必要なのは `ρ(z)dz` 自身の倍加性である。`ρ≥4/5` を利用し、領域を分けて示す。

1. **原点近く：** `0<z<1/6` 上では `(4/5)(1+u)≤ρ≤(8/5)(1+u)`。`u(z/6)=2u(z)` が成立し、`u` の各殻は非負の三角形波で、連続する殻の境界で両側の線形傾きの比は一定の有限値である。したがって `u(z)dz` を **相対区間 `[0,1/6]` に制限したもの**は倍加的である。詳しくは、`r≤x/8` なら中心が属する殻 `J_n` を `6^n` 倍して、有限個の区分線形な三角形波が現れるコンパクト帯 `[1/8,5/4]` 上に移す。零点の近傍でも密度は左右の傾きが一様比較可能な一次関数なので、球の積分比は一様に有界（零点での比の極限は4）となる。`r>x/8` なら原点まわりの殻の積分 `∫_0^{6^{-n}}u=(5/8)3^{-n}` と6進再標準化を用いる。半径で標準化した中心は有界な区間に入り、分母に当たる長さ `r` の区間は正の `u dz` 質量を持つ。従ってコンパクト性から同じ上界が得られる。これが**相対区間**についての主張であることが重要。
2. **右側と境界をまたぐ球：** `[1/36,1]` 上で `4/5≤ρ≤12/5`（最初の殻は高さ `H_1=8/5`、第二殻の端点は `1/36`）。この区間に含まれる半径2倍の球では、積分比は定数で制御できる。中心または半径がこのコンパクト部分を跨ぐ場合でも、半径が固定の正数以上なら、分母は `ρ≥4/5` による一様正下界を持ち、分子は全質量1以下である。
3. **両者の結合：** 十分小さい球で `[0,1/36]` の近くにあるものは、1で得た相対的な `u dz` の倍加性と、Lebesgue測度 `dz` の倍加性を `(1+u)dz` に適用する。半径を2倍にして `[1/6,1]` に出るような球は2の固定コンパクト領域で扱う。

従って `[0,1]` 全体について `ρ(z)dz` は倍加的である。上で用いた「有限個の区分線形三角形波のコンパクト帯における一様積分比」の詳細な定数評価はLean未形式化であり、商空間の倍加性は次節の追加仮定を要する。**有限標本の球比だけでこの結論を認証したとは主張しない。**

## 4. 倍加性の商への持ち上げ

`d_0` を `s` で測った標準Laakso因子の道距離とし、`ν_Φ([a,b])=Φ(b)-Φ(a)` という Stieltjes 測度を置く。1次元の標準事実「正の倍加測度の累積関数は quasisymmetric（QS）」から、`F` はQS、`Φ_bad=F^{-1}` もQS。従って `ν_Φ` は `s` 上で倍加的である。`Φ_good` は双リプシッツなので同様。標準事実の参考文献：Christopher J. Bishop, *Quasiconformal mappings which increase dimension* (1999), §2, 式(2.3)（https://www.acadsci.fi/mathematica/Vol24/bishop.pdf）。**PDFに記載される正式な題名に修正した**。この節が示すのは一次元累積写像のQS性であり、Laakso商の倍加性をそれだけで保証するものではない。

任意の二点 x,y（高さ s,t）について、`r_0=d_0(x,y)`、`Ω_s(r)=ν_Φ([s-r,s+r]∩[0,1])` と置く。`ν_Φ` の倍加定数だけによる `c>0` が存在して

**`c Ω_s(r_0) ≤ d_Φ(x,y) ≤ 2 Ω_s(r_0)`**

が成立する（円周を除いたLaakso因子）。

上界：有限段の標準道で必要ビットのゲートを訪れる高さ区間 J の幅は `≤r_0` に選べる。Jを最短に訪れて戻るのに必要な費用は高々 `2 ν_Φ(J)` であり、`J⊂[s-r_0,s+r_0]`。有限段から単調極限へ移す。

下界：任意の道の高さの最小・最大が定める区間 J の長さを ℓ とする。各必要ゲートはJ内にあるので、標準道の短縮で `d_0(x,y)≤2ℓ`。したがって `J` はsを含む長さ≥r_0/2の区間。`[s-r_0,s+r_0]` はJの中点を中心とする半径 `≤3ℓ` の区間に入り、`ν_Φ` の倍加性より `Ω_s(r_0)≤Cν_Φ(J)`。実際の `d_Φ` 道はJ全体の高さを訪れるので長さ≥ν_Φ(J)。有限段で一様な不等式を証明して極限へ移す。

さらに full support で原子のない倍加測度 `ν_Φ` には、固定した倍率の増加に必要な半径倍率が一様に有界という reverse-doubling が成立する。これは本例では次のように直接示せる。区間上の `ν_Φ` の倍加定数を `D` とし、`0<r≤1/8` とする。中心 `s` から長さ `3r/2` だけ区間内に進んだ点 `y` を、余裕のある側に選ぶと、`B(y,r/4)⊂B(s,2r)\B(s,r)` かつ `B(s,r)⊂B(y,5r/2)`。半径比10は4回の2倍以内なので `ν_Φ(B(y,r/4))≥D^{-4}ν_Φ(B(s,r))`。したがって

**`ν_Φ(B(s,2r))≥(1+D^{-4})ν_Φ(B(s,r))`**。

これを反復すると、`Ω_s(t)` の大きさを固定倍率だけ増やすのに必要な引数 `t` の倍率も、中心 `s` と尺度によらず一様に制御できる（大半径はコンパクト性で別処理）。`cΩ_s(d_0)≤d_Φ≤2Ω_s(d_0)` と組み合わせ、`d_Φ` 半径rの球の内側にある標準 `d_0` 球と、`d_Φ` 半径2rの球を覆う標準球とで、二つの標準半径の比は一様に有界。標準Laakso測度 `μ_0` はAhlfors正則、特に倍加的だから、`μ_0` は `d_Φ` についても倍加的。

円周方向の距離は和距離 `d_Φ^L+d_T`、測度は `μ_0⊗dθ`。円周は倍加的で、倍加空間の積は最大距離で倍加的、和距離は最大距離に双リプシッツ同値。以上から**二模型とも商空間全体で倍加性**を得る。

この段階で使用したのは、1次元QSの標準定理、標準LaaksoのAhlfors正則性、および上のゲート経路比較である。Leanでの完全形式化は別作業。


**追加の独立した紙上監査**：[`2026-11-23-laakso-doubling-proof-audit.md`](2026-11-23-laakso-doubling-proof-audit.md) に、相対区間での三角形密度の全尺度倍加性、全区間への貼り合わせ、倍加定数 `D` による **`D^{-3} Ω_s(d_0) ≤ d_Φ ≤ 2 Ω_s(d_0)`** の明示的な導出、逆倍加からの球包含を分けて記述した。対応する有限走査不等式は `LaaksoSweepBounds.lean` で検査する。これらは原稿を補強する紙上証明であり、Laakso商の全量化されたLean定理ではない。

## 5. bad の弱(1,1)-PI不成立：任意の定数への反例

固定した任意の拡大率 `λ≥1` に対し `κ=1/(16λ)`、`R_n=κ z_n` とする（nは十分大きく取る）。中心 `x_n` は高さ `s_n=3^{-n}`、全ビット0、角度0とする。`B_n=B_{d_bad}(x_n,R_n)`。

`z_n` の左と右では `ρ` がそれぞれ**正確に線形**なので、`t≤ℓ_n/2` に対し

```
F(z_n)-F(z_n-t) = (4/5)t + (H_n/ℓ_n)t²,
F(z_n+t)-F(z_n) = (4/5)t + (H_{n-1}/ℓ_{n-1})t²,
H_j=(8/5)(2^j-1).
```

これを `s_n=3^{-n}`, `z_n=6^{-n}` で割ると、二次係数は左で `(48/25)(1-2^{-n})`、右で `(4/25)(1-2^{1-n})`、一次項は `(4/5)κ2^{-n}`。したがってnが大きいと `B_n` 内の高さsの範囲は幅 `≤4κ²s_n`。拡大球 `λB_n` でもsは `s_n` の `1/20` 以内にある。近傍には `n−1` 段以前のゲートが存在しないので、拡大球の**先頭 n−1 ビットは固定**される。

**球内の左右に正の割合の質量がある**：zの左帯 `[z_n−R_n/3,z_n−R_n/6]` と右帯 `[z_n+R_n/6,z_n+R_n/3]` を考える。各帯のs像の幅は `≥κ²s_n/100`（n≥3、上の二次式から直ちに従う）。`K=K(λ)` を `3^{-K}≤κ²/400` となる最小の整数とすれば、各帯には少なくとも一つ、深さ `m=n+K` の完全な三進セルが入る。そのセルの両端を訪れる水平路は、セル内の全ての深さ `>m` のビットを所望どおり無料反転できる。始点からセル両端を訪れた後の水平路費用は `≤2R_n/3`、角度 `|θ|≤R_n/6` を足しても `≤5R_n/6<R_n`。ゆえに各側には

`μ(B_n∩{z<z_n-R_n/6}) , μ(B_n∩{z>z_n+R_n/6}) ≥ 2^{-m}3^{-m}(R_n/3)`

という**正の下界**がある。

一方、高さ範囲・固定された先頭n−1ビット・円周距離から

`μ(B_n)≤ 8κ² 2^{-(n-1)}s_n R_n`。

したがって左右それぞれの相対質量は下から `p_λ=6^{-K}/(48κ²)>0` で抑えられる。

`δ_n=z_n/4^n` とし、z座標に関して `[z_n−δ_n,z_n+δ_n]` で0から1へ線形に増えるランプ `f_n` を取り、外では左0・右1にする。上勾配として

`g_n=(2δ_n)^{-1} 1_{|z-z_n|≤δ_n}`

を選べる。z射影は道について1-Lipschitzなので、これは全ての可長曲線に対する上勾配である。nが十分大きければ `δ_n<R_n/6` なので先ほどの左右集合ではfが正確に0/1となり、平均振動は

**`avg_{B_n}|f_n-(f_n)_{B_n}| ≥ p_λ/2 >0`**。

他方、右側と左側の上の二次積分を使うと

`E_n=∫_{[0,1]}(2δ_n)^{-1}1_{|z-z_n|≤δ_n}ρ(z)dz <3`

がn≥3で成り立つ。拡大球内でも先頭n−1ビット固定、角度の幅は≤2λR_nなので

`∫_{λ B_n}g_n dμ ≤ 6λR_n 2^{-(n-1)}`。

分母は、球内の左右いずれかのセルから `μ(λ B_n)≥2^{-m}3^{-m}R_n/3`。従って

**`R_n avg_{λ B_n}g_n ≤36λ6^K κ 2^{-n} →0`**。

任意の固定 `C_PI, λ` に対して、左辺の振動が正定数から落ちないのに右辺がゼロに収束する。ゆえに `bad` は弱 `(1,1)`-PIを満たさない。この証明は**倍加性の否定に依存しない**。

## 6. 既存の結果から何が変わるか

前のPR #208：同じ `A_m`、good = 倍加＋PI、bad = 非倍加＋非PI。このため倍加クラス内の問題は未解決だった。

本構成（紙上証明）：同じ `A_m`、good = 倍加＋PI、**bad = 倍加＋非PI**。したがって、少なくともこの校正三進Laakso族では、**倍加性を仮定しても各段の最大観測直径列だけではPIの成否を決められない**。

この主張は `A_m` の一致についてである。**位置付き**の全セル長 `Δ_{k,j}` は `Φ` 自体を決めるため、両者の局所距離は異なり、当然ながら識別できる。
