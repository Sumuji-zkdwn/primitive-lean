# 一点の前進軌道が平面上の全多項式を決める

実平面の点を $z=(u,v)$ と書き、センサーの出力を最初の座標 $u$ に固定する。
使用する写像は `Research.SiphonPolynomialE` の $E$ と `OrbitTrace.linearE` の
$L(u,v)=(v,v-u)$。$r=I(u,v)=v+u^3$ とおくと、
$(u,r)$ 座標で $E(u,r)=(u+r^2,r)$ となる。
同じ操作列を二つの初期状態に施し、どの有限列の後でも位置の読みが一致するとき、その二状態を観測で同値とする。空の操作列も含める。

## 非零の一点から平面の多項式を決定できる

原点以外の任意の初期状態 $z$ を選ぶ。$E,L$ の有限列で $z$ から到達するすべての点で実二変数多項式 $P,Q$ の値が一致すれば、$P=Q$ が多項式環で成り立つ。これは前進軌道のザリスキー稠密性である。原点は二写像の共通不動点なので、例えばそこでの観測だけでは多項式 $u$ と零多項式が一致する。

$z=(0,1)$ は具体例になる。到達点はすべて整数格子の上にあり、開いた帯 $0<u<1$ にはどの操作列でも入れない。それでも、この軌道に沿った多項式の値は、その帯の内部での値まで決める。

証明に必要な操作列は短い形をしている。

1. $r=I(z)≠0$ なら、$E$ の $n$ 回反復で位置は $u+n r^2$ を走る。ある多項式がこの無限列上で消えると、曲線 $(x,r-x^3)$ への制限も一変数多項式なので、この曲線全体で消える。
2. この曲線上の点に $L$ を施したあとの $I$ の値は $F_r(x)=r-x^3-x+(r-x^3)^3$ である。これは $x$ について狭義減少なので、初期軌道の各点から異なるレベルへ移り、そのうちゼロは高々一つしかない。各非零レベルでさらに $E$ を反復し、手順 1 を適用する。
3. $u$ を固定して縦線を見ると、差 $P-Q$ は無限に多くの $v$ で消えるため、この縦線全体で消える。$u$ は任意だった。
4. 初期値が $r=0$ でも $z≠(0,0)$ なら、最初に $L$ を一度施すと $I(Lz)=-u(u^8+u^2+1)≠0$ となる。

Lean では操作列全体についての結論が `SiphonCommonInvariant.polynomial_eq_of_agree_on_orbit`、必要な操作を $E^m L E^n$ と必要に応じた最初の $L$ に絞った結論が `polynomial_zero_of_nonzero_orbit` である。ここで積は右から作用する。

必要な $L$ の回数には初期状態による違いがある。$I(z)≠0$ なら $L$ を一度も使わない軌道上では非零多項式 $I-I(z)$ が消える。$I(z)=0$ の非原点では、$L$ を高々一度しか使わない操作列の到達点は、$I=0$ と $I=I(Lz)$ の二曲線に含まれる。その全点で非零多項式 $I(I-I(Lz))$ が消える (`one_turn_insufficient_on_zero_fibre`)。したがって、稠密性に必要な $L$ の最大使用回数の最小値は、それぞれ 1 と 2 である。

## 同じ位置センサーで、どの状態まで見えるか

| 許す操作 | 観測で同値になる条件 | Lean の定理（`OperationalWorldGeneration`） |
| --- | --- | --- |
| $E$ | $u$ と $r^2$ が一致する | `passive_iff_signature` |
| $E,L^3$ | $u$ と $r^2$ が一致する | `halfTurn_wordEq_iff` |
| $E,L$ | 元の点 $(u,v)$ が一致する | `linear_wordEq_iff`, `two_reads_recover` |

最初の二行では、時刻 0 と 1 の位置の差が $r^2$ に等しい。観測される状態全体は
$(u,s)\in\mathbb R\times[0,\infty)$。$s>0$ の各点には $r=\pm\sqrt{s}$ の二つの原像、
$s=0$ の各点には一つの原像がある。符号反転は元の座標で $J(u,v)=(u,-v-2u^3)$ と書ける。
この折り畳みの前後で次元はいずれも 2 である。`signature_range`、`signature_eq_iff_mirror`、
`mirror_commutes` が対応する。

### 巻き戻せても見えない一対

$H=L^3$ は $H(u,v)=(-u,-v)$ で、$HEH=E^{-1}$ を満たす (`halfTurn_reverses_step`)。
観測される座標では $H(u,s)=(-u,s)$ なので、途中で何回巻き戻しても符号の識別力は増えない。
例えば $(1,0)$ と $(1,-2)$ は $I=1,-1$ を持ち、$E$ だけならどちらも位置列 $1,2,3,\ldots$ を返す。
一方、$L$ を一度施すと位置の読みはそれぞれ $0,-2$ になる。一般にも、操作前後の二つの読みがそのまま $(u,v)$ になる。

$E$ を連続適用したときの位置を $u_n$ とする。$r\ne0$ なら $n=(u_n-u_0)/(u_1-u_0)$ で反復回数を復元できる (`recover_elapsed_from_reads`)。
$r=0$ の各点ではすべての $E$ 反復がその点を固定する (`zero_fibre_fixed`)。

### 二つの写像に共通する保存量

$E$ は $I$ を、$L$ は $Q(u,v)=u^2-uv+v^2$ を保存する。
両方が保存する任意の実二変数多項式 $P$ について、多項式環の等式 $P=P(0,1)$ が成り立つ (`SiphonCommonInvariant.common_polynomial_eq_C`)。
共通保存量は $(0,1)$ の前進軌道全体で一定であり、この軌道での値が多項式を一意に決めるからである。
二写像はともに全単射で原点を固定するので、任意関数まで許すと原点の指示関数は非定数の共通保存量となる。

### 検証方法

Lean と mathlib は PR #140 のピンを用いる。リポジトリ直下から次を実行する。

```sh
python3 -B tools/verify_toolchain_modules.py --module Research.OperationalWorldGeneration --module Research.SiphonCommonInvariant
python3 -B -m unittest discover -s tests -p 'test_siphon_*.py' -v
```

Python 検査は元の $(u,v)$ 座標の遷移表から観測による分割を求め、分割が変わらなくなるまで細分する。
$p=2,3,5,7,11,13,17$ の各有限体で全点を調べ、$E$ 単独と各 $k=0,\ldots,5$ の組 $\{E,L^k\}$ を比較する。
例えば $p=7$ では全 49 点が $\{E,L^3\}$ で 28 類、$\{E,L\}$ で 49 類になる。標数 2 では符号の二択が消え、どちらも 4 類になる。

別の検査では、三つの非零整数初期値と原点を選び、前進軌道上で総次数 5 以下の単項式 21 個を評価する。法 1009 での行列の階数は各非零例で 21、原点で 1 となる。非零の小行列式は整数上でも非零なので、これら三例で得た有限個の測定だけで、総次数 5 以下の実多項式を決定できる。
