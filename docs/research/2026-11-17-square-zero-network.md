# Square-zero network: 局所消滅・経路増殖・観測圧縮

## 位置づけと由来

2026-11-16の会話「2回使うと必ず死ぬ操作を交互に使うと増殖する」を有限有向グラフに拡張する。既存の primitive-lean の nilpotence / future-observation / void-hypercompletion 研究への接続候補。**本モデルは既知の quiver/path-algebra の有限表現の具体例であり、数学史上の新定理を主張しない。** 参照: https://www.maths.lancs.ac.uk/~grabowsj/rtaca/Ch5.S3.html （quiver の経路代数、閉路と有限次元性）。PR #141/#142 の多価観測とは異なる独立な線形経路模型で、それらの定義の再利用は今回まだ実装していない。

## 定義

頂点 0,...,n-1、整数値列ベクトル v、有向辺 e=(s,t) と整数重み w について、

(T_{s,t,w} v)_j = w v_s  if j=t, otherwise 0.

src != dst なら T_e²=0。辺 e=(a,b,p) と f=(c,d,q) の順次適用は、b=c のとき T_f T_e=T_{a,d,qp}、それ以外では零写像。したがって単一の演算列は「端点が一致する有向経路」の符号つき重み積を計算する。

## 異なる二種類の増殖

**軌道上の増幅**：頂点 0 -> 1 -> 0 の辺重みを a,b とすると、単位基底 e₀ に対し (T_{1,0,b} T_{0,1,a})^k e₀=(ab)^k e₀。特に a=b=2 なら 4^k e₀。一つの履歴それ自体が増える。ab=0 なら消滅し、ab=±1 なら絶対値は増えない。一般の実数重みに対しては |ab|<1 なら減衰するが、このLeanファイルの係数は整数に限定している。

**履歴数の増殖**：頂点3個の完全有向グラフからループを除いた6辺を、すべて w=1 とする。各 T_e²=0 だが、その和 S=ΣT_e は S(v)_j=Σ_{i≠j}v_i。非負の初期状態 e₀ を使うと各時刻の合計は Σ(S^k e₀)=2^k。一つの有効な経路上の重み積は常に 1 であり、**2^k は履歴の個数であって一軌道の利得ではない**。

3つの終端状態に合流する履歴の数 N_j(k)=(S^k e₀)_j は、

- 3N₀(k)=2^k+2(-1)^k
- 3N₁(k)=3N₂(k)=2^k-(-1)^k

となる。例: k=10 で (N₀,N₁,N₂)=(342,341,341)。観測 π(history)=current vertex には3値しかないが、歴史の個数は1,024。ここでは情報量・エントロピーを同一視せず、履歴集合の濃度と現在状態の濃度を区別する。

## 論理的境界

1. DAG iff A^n=0 は、**単位・非負辺重み**の有向グラフについての関係。ゼロ重みや符号付き和でのキャンセルがあるなら同じ判定をそのまま使えない。Leanでの普遍命題（任意の有限 n・グラフ）はまだ未形式化。
2. S は同時にすべての分岐を加算する線形作用素。操作を一つだけ選ぶ決定論とは異なる。全履歴を物理的にコピーして資源が増えるという主張ではない。
3. 現在状態が3値でも、上記の数 N_j(k) を知るには時刻や履歴分布が必要。時刻を持たない観測者が 2^k を読み取れるとは主張しない。
4. Quiver の経路代数は一般に無限次元だが、ここでの n×n 行列表現は閉路があっても有限次元。経路代数が無限次元であることと行列代数が無限次元であることを混同しない。
