型は `K : α → α`、`S : α → I → α`、`C : (I → α) → α`。Aは `C(S x)=x`、Bは `S(K x)i=K(S x i)`、更新は `T x=K(C(liftK K (S x)))` と定義する。A・Bはそれぞれ必要な定理だけの追加仮定である。

主な結論は次のとおり。

- Kの冪等性から像と固定点集合が一致し、実際のファイバーへの全単射で基礎集合を分解する。
- Bのもとで `T=KCSK`、`TK=T`。空でないIに対し、Kx=Kyと「すべてのB適合Sで、成分ごとにKを適用した出力が一致」が同値。生のSの出力の一致は要求しない。
- **A+BならT=K**。非縮退T≠KならAまたはBが不成立。逆向きの推論ができない具体例も証明する。
- A・Bを仮定しなくても、最初の更新以降はFix(K)に入る。有限集合では相異なるp点からなる周期はp≤|Fix(K)|、軌道は最終的に周期的になる。
- 固定した有限冪等Kのファイバーサイズをm_a、出力成分数をdとすると、実際の適合写像Sの個数は `∏a (∑b m_b^(m_a−1))^d`。代表点の行き先と残りの点の行き先を選ぶデータとの**全単射を構成して**証明した。Cとの組、単射なS、異なるTの個数を数えた式ではない。
- ラベル付きN点集合上のランクrの冪等写像数は `choose(N,r) * r^(N−r)`。ランク別の和から7点で6,322、8点で41,393をLean内で計算した。形式上の和はr=0も含み、空集合にも対応する。
- 二塊合流は総量を保ち塊数を1減らす。非空の正整数多重集合は必ず単一塊へ到達し、長さは初期塊数−1。N個の1から(N)へはN−1回。正の長さの閉路はない。

`branchZeroK` / `branchPiK` は既存 `BranchFibers.inc` の代表元をそのまま使う。`branchZero_kernel` / `branchPi_kernel` がKの核と余弦候補の等値関係の一致を証明し、`branchZero_A_B_collapse` / `branchPi_A_B_collapse` がこの具体的Kへ合成定理を適用する。任意の型グラフの辺をS・Cで実現する定理とは区別する。

本文は [第8.15節](../../原始の形式化.md)、各宣言の正確な型・行番号・公理・ハッシュは [導出台帳](../../sources/f0_formalization_2026-10-30.json) を参照。
