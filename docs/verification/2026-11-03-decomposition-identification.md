# 分解書換え系・標準形・最小識別作用素（2026-11-03）

研究PR: https://github.com/Sumuji-zkdwn/primitive-lean/pull/38

このノートは Lean 形式化の**主張・仮定・非主張**を分離して記録する。
コード: `linear_input/lean_check/DecompositionIdentification.inc`,
`linear_input/lean_check/DecompositionF0Bridge.inc`。
既存の `F0MergeChains.inc` や `FiniteObservationSeparation.inc` は変更しない。

## A. 基本模型

`R : α → α → Prop` を1段の書換え関係、`Steps R x y` を有限回の書換え、
`Terminal R x := ∀ y, ¬ R x y` を終端条件、`value : α → β` を評価とする。

1. 各ステップが値を保存するなら、全有限経路は値を保存する。
2. `rank : α → ℕ` が存在し `R x y → rank y < rank x` を満たせば、任意の初期状態から何らかの終端状態へ到達する（自然数の強帰納法）。
3. `TerminalValueInjective R value`（評価が終端集合上で単射）が成り立つなら、一つの出発点から到達する任意の二つの終端状態は等しい。
4. 終端一意性から「評価が全ての終端を識別する」ことを逆に結論するには、**同じ値を持つ任意の二つの終端が共通祖先から到達可能**という追加仮定を明示する。

これにより**停止性・合流的標準形・評価値の識別性は別の命題**であることが明確になる。

## B. 追加観測

`probe : α → γ` に対し、終端上で `(value, probe)` が単射となる条件を
`IdentifiesTerminals` と定義する。これは既存の `LinearInputFiniteObservation.joint`
の終端集合への制限と同値。

さらに各書換えで評価と観測の**両方**が保存されるとき、初期観測が一致する二つの状態の終端は等しい。
観測が書換え不変でなければ、この結論は出ない。

許容する観測族 `probe : ι → α → γ` と有限選択 `chosen : Finset ι` に対し、
`IdentifiesWith` を定義する。

- 観測を増やしても識別能力は減らない（`identifies_with_mono`）。
- 追加観測なしの場合は、終端上で元の評価が単射であることと同値（`zero_extra_probes_iff`）。

3状態の分岐 `0 → 1`, `0 → 2` では `rank(0)=1`, `rank(1)=rank(2)=0`、
`value(x)=36` とする。停止性は成立し、終端1と2は異なるため合流性は成立しない。
許容する追加観測 `P(x) = [x=2]` のもとでは、**0個では不足、1個なら十分**。
これは「観測による枝の識別」と「分解経路の合流」を区別する反例でもある。

## C. F0 の実際の演算への接続

既存の `LinearInputF0Merge.Merge` では、正整数 `a,b` を `a+b` に併合する。

- `Multiset.sum` は1段の併合で保存される。
- `Multiset.card` は1ずつ減少するので停止する。
- 既存の `reaches_singleton` を一般の `Steps` に移す（`chain_is_path`）。
- 非空かつ全要素正の多重集合 `p` から、どの併合順序で終端 `q` に到達しても
  `q = {p.sum}`。ここでは元の評価値（総和）だけで終端を識別可能。

この定理は「任意の乗法的因数分解が一意」だとは主張しない。
F0併合は**加法的な合流・停止の実例**である。

## D. 可換積の反例

`Fin 3` の生成子をそれぞれ整数4,6,9とし、生成子の `Multiset` を
通常の可換乗算で評価する `evaluateFactors` を定める。

- `[4,9]` と `[6,6]` は別の生成子多重集合。
- 双方の評価は36。
- 4という生成子の個数 `countFour` は両者を区別する。

これが示すのは**可換積一つという演算種類だけでは、生成子分解の一意性を保証しない**こと。
生成子4,6,9が通常の整数における素数であるとは主張しない。
この例から全ての元の分解が一意でない可換モノイド一般の結果を勝手に導出しない。
