# 光記憶プリズムの最小Lean模型（2026-11-07）

## 目的

N-BASF64光記憶プリズムの以前の案（光学分岐 + 外部帰還 / 流体ヒステリシス）と、
`DarkBrightObservation.lean`（PR #86）を接続し、
「二つの状態が通常の観測では同一に見えるが、光学操作を挟んで区別できる」
という最小の読出し問題を形式化する。

本PRはPR #86に依存する**積み重ねPR**である。mainだけでは直接コンパイルできない。

## 記述されたもの

- 二つのモード `B, D` を複素振幅（4実数）として解釈する。実体粒子の二種類ではない。
- 観測 `Q = B conjugate D` と合計強度 `N = |B|² + |D|²`。
- 混合パルス `(B,D) ↦ (3 B/5 - 4 i D/5, 3 D/5 - 4 i B/5)`。
- 観測器の読みを、規格化前の `|B+iD|²-|B-iD|²` とする（通常の50:50合波器では係数1/2が掛かる）。
- `(B,D)=(1,2)` と `(2,1)` は初期 `Q=2,N=5` で同じだが、
  読出パルス後の平衡検出器出力は厳密に `-144/25, +144/25` となる。
- 一般の入力について、初期とパルス後の二つの平衡検出器読みから
  `delta = (25 d_after + 7 d_before)/48` を復元できる。
- `(3/5,-4/5)` の逆パルスは理想的な混合写像を厳密に元へ戻す。
- 別の理想的二状態ヒステロンは、`u ≥ 1` ならtrue、`u ≤ -1`ならfalse、
  中間では前状態保持という明示した規則によって書き込みと保持を提供する。
- 同じ中立入力 `u=0` のもとでも異なる書込履歴が残る。
  通常観測 `Q` では区別不可だが、一回の平衡検出で区別可能。

## 重要な境界

1. 履歴保持ビットは別のヒステリシス要素。ガラスN-BASF64単体の光メモリは示していない。
2. 「読み出し・逆操作で状態が戻る」は**古典的な振幅写像の恒等式**。
   実測による吸収・散乱・光路への反作用・量子測定の擾乱をモデル化していない。
3. 流体の表面張力、粘性、温度、緩和時間、閾値の単位、プリズム角、
   Fresnel係数、波長分散、装置幾何は別途較正が必要。
4. 記号 `B,D` は暗子・輝子という実在の粒子を意味しない。
5. 初期の光の「不可視」状態は、指定した観測 `Q,N` に対して不可視という意味。
   他の観測（モード別の直接強度測定など）が利用できれば当初から区別できる。
6. 二つの振幅を外部参照位相と干渉させる光学的構成が必要で、
   プリズムだけで読み取れるとは限らない。

## 次の物理課題

流体界面変位`h`が二つのモードの混合係数・位相差をどのように変えるか、
流体の微分方程式とFresnel反射率から定量化する。
特に、中立読出光でビット反転が起こらない条件と、
信号雑音比から必要光量の範囲を求める。
