# 記述エラスティカ：接合の下での観測同値（2026-11-06）

## 目的と既存成果との差分

既存の `FutureObservations.inc` と `OperatorWordObservations.inc` は、
1つの更新または有限の書換え語の下で区別できる状態を最小化する。
今回の `JoinContextualEquivalence.inc` はさらに **二項の接合** を明示的に許す。
これは「操作語だけに関して正しい圧縮を、他の記述と接いでも使えるか」という未解決だった境界条件を切り出した追補である。

## 対象と仮定

* 棒の状態 `α`、観測 `K : α → ω`、書換え `step : ι → α → α`、
  接合 `join : α → α → α` はすべて全域的・決定的。
* 合法な文脈は、ちょうど1つの穴に対する「書換え」「固定した棒との左接合」「右接合」
  の有限回の組み合わせ。
* 合法性、境界の型、確率、連続時間、エネルギー、曲率は現模型では表現していない。
* 接合の結合律・交換律・力学的保存則は仮定しない。

## 命題の対応

| Lean宣言 | 内容 |

| `plug_compose`, `context_plug` | 文脈への代入と文脈追加の整合 |

| `ex_word_equal`, `ex_context_separates` | 書換え語では同じ二状態が接合で識別される反例 |

## 最小反例と独立の有限検算

4状態 `(a,b) ∈ Bool × Bool`、観測 `K(a,b)=a`、書換えは恒等とする。
接合は相手の第1ビットが立っている場合、自分の第2ビットをゲートとして第1ビットを反転する：

`join((a,b),(c,d))=(a XOR (b AND c),b)`

`(0,0)` と `(0,1)` は書換え語だけでは同値だが、
右に `(1,0)` を接げば観測値が 0 と 1 に分かれる。

独立Pythonテスト `tests/test_join_contextual_equivalence.py` は全4状態、
全256組の二項合同性条件を検査し、旧操作語商2類、接合込み4類を照合する。
別の `join((a,b),(c,d))=(a XOR c,b XOR d)` では
旧操作語商2類がそのまま接合と両立する対照例も確認する。

## 論理的境界

`ContextEq` は指定した全域操作の下での構文的な*全*有限文脈に対する観測同値。
任意の物理系に実装可能な操作、任意の高階自己書換え、部分演算の合法性、
ユーザーの物理エラスティカエネルギーとの一致までは証明しない。

Lean検査は、当該コミットでの `python -B -X utf8 tools/verify.py --integration-only`
（GitHub Actionsの固定依存・`--trust=0`・公理監査）によって判定する。
成功記録がない段階では、この原稿をLean検証済みとは表示しない。
