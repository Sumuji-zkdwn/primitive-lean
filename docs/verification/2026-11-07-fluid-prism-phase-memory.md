# 流体ヒステリシス × 光学位相 × 読み出し（2026-11-07）

## 範囲

N-BASF64プリズムと帰還光路の旧デモ、二複素振幅モデルPR #86、光学読み出しPR #89を接続する**現象論的最小模型**。

実際のプリズム固有の物性を導出するものではない。実際の流体表面張力・接触角履歴からエネルギーを逆算したものでもない。

## 三層

1. **記憶層**：規格化変位 `h=±1`、外部入力 `u`。
   有効エネルギー `E(h,u)=(h²−1)²/4−u h` を**仮定**。
   `u=0` で `E(±1)=0`、`E(0)=1/4`、`E≥0`、安定性を示す曲率 `E''(±1)=2>0`、
   中央 `E''(0)=-1` を代数的に計算する。書込閾値は別の理想ラッチPR #89から流用し、
   エネルギーの障壁越えを力学的に導出したとは主張しない。
2. **位相層**：単一通過の余分な光路により
   `phi=2*pi*deltaN*path/lambda`。
   規格化 `path=a*(h+1)`、`4*deltaN*a=lambda` の**校正条件**なら
   `phi=pi*(h+1)/2` が成立。これは群速度・屈折・全反射・伝搬行列を導出した式ではない。
3. **観測層**：理想的な二経路干渉の一方の出力 `T=(1+cos(phi))/2`。
   `T(-1)=1, T(+1)=0`、Bool二状態上単射。
   PR #89で検証された二振幅の強度差 `readSignal` と、これら二つの校正済み状態に限り
   `readSignal = (144/25)*(1−2*T)` が成り立つ。
   この対応は二振幅物理モデルと流体モデルの独立した出力を**整合するように符号化**したものであり、
   流体から混合演算子が導かれたわけではない。

## 新しい物理的に重要な制約

- `T(h+4)=T(h)`。一波長・一象限の余弦読み出しは任意の高さに対して単射にはならない。
- 正規化した二状態の出力間隔は1なので、雑音が各測定で絶対値1/2未満なら、
  中間値1/2による分類が間違わない。ただし光子ショットノイズや検出効率は扱わない。
- 別々に読み出せるn個の理想セルは2^n個の記憶語を持ち、全ポートを測る写像は単射。
  これはセルの密度・光路の物理的独立・漏話防止・信号量を保証しない。
- 読み出しが書込みを変えないことは `write h 0=h` という規則の結果に過ぎない。
  実装には読み出しによる加熱・光圧・接触角解除を避ける必要がある。

## 独立した先例との対応

Gao, Gaur, Almutairi, Rubin and Fainman, *Optofluidic memory and self-induced
nonlinear optical phase change for reservoir computing in silicon photonics*,
Nature Communications **14**, 4421 (2023).
https://doi.org/10.1038/s41467-023-40127-x

実験では、Si導波路と薄いシリコーンオイルを組み合わせ、熱毛細管による変形を
Young干渉計やMZIの出力として読み出した。入力増減でヒステリシスも観察した。
ただし主たるリザバー計算の短期記憶は液膜の緩和時間による。
本模型の保持可能な二重井戸を実験で証明したものではない。
