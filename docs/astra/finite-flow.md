# 有限 Kerr 系の大域解と分割反復

初回導入の材料則と有限更新に、解の存在・一意性と反復の収束を接続する。対象は固定した有限実行列 Q と、全成分に共通する Kerr 材料逆関数 g である。

```text
g(D) = 2 sinh(asinh(3D/2) / 3)
D' = −QH
H' = −Q g(D)
```

g は成分ごとに作用する。初回に証明した材料逆関数の全域 1-Lipschitz 性と g(0)=0 を使う。ここでの存在・一意性や反復収束には Q の反対称性を必要としない。物理エネルギーの保存では反対称性が必要になる。

## 実際の有限系への接続

有限添字集合に対する実 EuclideanSpace と、その二成分の L2 直積を使う。Q から連続線形作用素を作り、前回の `ExactShear.State` にある D,H の成分値を、そのまま L2 空間へ写す。尺度や座標を初期値ごとに作り直す構成ではない。

状態のノルムと作用素ノルムを

```text
||z||₂² = Σᵢ (Dᵢ² + Hᵢ²)
q = ||Q||₂→₂
```

とする。成分の材料逆関数から有限ベクトル上の非拡大型写像を作るので、ベクトル場 `F(D,H) = (−QH, −Qg(D))` は q-Lipschitz になる。完全空間における実際の ODE 存在定理に適用し、各初期値 z に対する全実時間の解 Φₜ(z) とその一意性を得る。

数学的な流れ Φ は、証明した存在定理から選んだ解である。Lean の `noncomputable` な定義を、有限回の演算で評価できる閉じた式と読み替えない。初期値から計算する更新は、次の明示的な分割式である。

## 同じ明示更新の反復と誤差

前回の二つの部分流を同じ順序で合成する。

```text
D₊ = D − h QH
H₊ = H − h Qg(D₊)
Sₕ(D,H) = (D₊, H₊)
```

各ステップでは固定した行列 Q と同じ g を使う。`ExactShear.lieStep` の式との一致を証明してから、解析側の安定性・局所誤差・反復誤差をこの更新へ移す。

固定した T≥0、整数 n>0 に対し、到達時刻 T の誤差は

```text
||S_(T/n)^n(z) − Φ_T(z)||₂
  ≤ (3/2) q² T² ||z||₂ exp(qT) / n
```

で抑えられる。右辺は実際の行列、初期値、到達時刻、分割数から定まる。厳密解の途中の値を入力として要求しない。n を増やすと右辺がゼロへ収束し、同じ有限更新の反復が実際の物理時間の解に収束する。

この結論は、一回の有限ステップを厳密な連成解と呼ぶものではない。初回の非ゼロ残差の定理と両立し、反復を細かくする極限についての結論を追加する。

## 物理的な電場への復元

`restore(D,H) = (g(D),H)` は1-Lipschitzである。そのため、物理的な E,H を復元した後の誤差も、上記と同じ右辺で抑えられる。右辺の初期ノルムは引き続き **D,H のノルム**であり、E,H のノルムへ無条件に置き換えない。線形な `decode` は配列と EuclideanSpace の表現を対応させる写像であり、非線形な `restore` と区別する。

復元の微分を実際に計算し、構成した解が

```text
Eᵢ' = −(QH)ᵢ / (1 + Eᵢ²)
Hᵢ' = −(QE)ᵢ
```

を満たすことを証明した。その後で初回の `FiniteEnergy.energy_conserved` を適用し、反対称なQについて `Σᵢ(Hᵢ²/2 + Eᵢ²/2 + Eᵢ⁴/4)` の保存を得る。存在するか分からない軌道に ODE を仮定しただけの保存則から、実際に構成した軌道の保存則へ接続した。

原本・新規接続・登録順序・ハッシュは [出典台帳](manifest.json) に、実行した検査は [有限系導入の検証記録](verification-finite-flow.md) にまとめる。[初回導入の検証記録](verification.md)は対象コミットを固定した過去の記録として保持する。

## 有限系から先の境界

誤差定数は q に依存する。空間分割数や Fourier cutoff を増やすと q が増大する場合、この評価だけでは空間極限について一様な収束を得ない。連続体 PDE への移行は、空間正則性、復元、極限同定を別途検証して進める。

保存量から初期波形を復元する定理や、一般の周期非線形 PDE を有限の閉じた式で解く定理も追加していない。今回の計算に入力するのは、有限系の初期状態そのものである。
