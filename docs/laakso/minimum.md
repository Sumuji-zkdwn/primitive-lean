# 第一近似の最小エネルギー

Laakso 第一近似の六頂点に実数の二成分状態を置き、外部入力を零、係数を λ = κ = 1 とする。中央の二本の平行辺だけを見れば、六辺の符号配置すべてについて最小値が分かる。[エネルギーの定義](signed.md) · [符号の分類](switching.md)

| 中央の二辺 | 配置数 | 総費用の最小値 | 達成状態 |
|---|---:|---:|---|
| 同符号 | 32 | 0 | 全辺正の定数井戸状態を、その配置の頂点ラベルへ戻せばよい |
| 異符号 | 32 | 3/2 | 六頂点すべてで二成分が零になる状態だけ |

零状態では辺の費用が消え、局所ポテンシャルは各頂点で 1/4 になるので、総費用は 6 × 1/4 = 3/2 である。局所ポテンシャルだけを見れば、零から井戸へ動いたほうが安い。異符号の場合に、それでも総費用を下げられないことを次の分解で示す。

### 四つの非負項への分解

頂点ラベルを切り替えて、辺3だけが負である代表を選ぶ。中央の平行辺は同じ二頂点を結び、一方が成分の差、もう一方が和の二乗を与える。足すと交差項が消え、中央頂点4と5の費用を別々に扱える。頂点4には外側の0と1、頂点5には外側の2と3が接している。

各外側頂点の状態を p = (x,y)、隣の中央頂点の状態を c = (a,b) とする。中央頂点の負担を隣り合う二つの外側頂点に半分ずつ割り当てると、定数項を除いた各組の費用は次式になる。

```text
B(p,c) = x⁴/4 + a⁴/8
       + (x − √2 y/2 − a/2)²
       + (y − √2 a/2 − b)²/2
       + 3(a − 2√2 b/3)²/4 + b²/12.
```

総費用は 3/2 に四組の B を足した値である。各 B は非負で、零なら四乗項と最後の二乗項から x = a = b = 0、さらに y = 0 を得る。四組が六頂点をすべて覆うため、等号は零状態に限る。頂点ラベルの切り替えは費用を保ち、零状態を零状態へ移すので、同じ結論が異符号の全配置に及ぶ。

### 定理と再実行

| 内容 | `LinearInputLaaksoSignedMinimum` の宣言 |
|---|---|
| 各組の費用とその零点 | `leafExcess`, `leafExcess_nonneg`, `leafExcess_eq_zero` |
| 四組の和と代表接続の等号条件 | `flipped_energy_decomposition`, `flipped_minimum_iff` |
| 異符号の任意の配置における最小値と一意性 | `odd_minimum`, `odd_minimum_iff` |
| 全64配置の達成される最小値 | `least_energy` |

Lean の等式と不等式は任意の実数状態に適用できる。独立の検算は y = √2 z と置き、エネルギーの多項式から定数項と四乗項を取り出す。残る十二変数の二次形式を有理数で対称消去すると、異符号の32配置で十二個のピボットがすべて正になる。`python -B -X utf8 tools/check_laakso_minimum.py` で再現できる。[Lean 原稿](../../linear_input/lean_check/LaaksoSignedMinimum.inc) · [有理数検算](../../tools/check_laakso_minimum.py) · [出典台帳](provenance-minimum.json)

追加原稿（1定義・10定理）は Lean 4.30.0-rc2 の `--trust=0` で検証した。11宣言の公理出力はすべて `propext`、`Classical.choice`、`Quot.sound` の範囲に収まった。有理数検算では全32配置で行列式が 1024 になった。両方を含む統合検証はリポジトリ直下で `python -B -X utf8 tools/verify.py --integration-only` を実行する。
