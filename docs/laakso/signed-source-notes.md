## 三種類の同一視を分ける

原本28–35行の二重被覆は、各基底辺 `e : i—j` と sheet `a` について

```text
(i,a) — (j,a xor tau_e)
```

という辺を置く。原文は「辺で接続する」という意味であり、「異なる頂点を同一視する同値関係ではない」と明記している。六頂点六辺の基底からは、符号によらず十二頂点十二辺が得られる。

これは Laakso の三分割・二枚化で新しい分点を同一視する操作とは異なる。また、原本166–178行が扱う観測 `Pi` の fiber と、その上で次の観測が一定かという更新の降下問題とも異なる。二重被覆の sheet、幾何的 bonding map の逆像、観測が忘れる状態差を混同しない。

原本49–68行は、頂点状態と全入射辺を同時に変える switching と、状態を保持して辺一本だけを反転する操作も区別する。本追加の比較は後者である。符号一本の反転が全てのグラフで成分数を変えるわけではない。今回選ぶ辺は第一近似の中央閉路に属する。

## 実際の Laakso 第一近似への対応

頂点は `L0,L1,R0,R1,W1,W2` の順に `0,...,5`、辺は次の順に `e0,...,e5` とする。

```text
e0: 0—4     e1: 1—4     e2: 4—5
e3: 4—5     e4: 5—2     e5: 5—3
```

`e2` と `e3` は同じ端点を持つ異なる辺であり、この二本で基本閉路ができる。全辺正の署名と、`e3` だけを負にした署名を比較する。前者の二重被覆は六頂点ずつの二成分、後者は十二頂点の一成分となり、始点 `(0,0)` の到達数は6から12へ変わる。これは有限グラフの到達可能頂点数であり、物理的な資源や体積の倍増ではない。

独立 checker は既存の `check_laakso_finite.refine` からグラフを生成する。この builder の sheet ごとの辺順を、`[0,3,1,4,2,5]` の明示的な順列で既存 `firstGraph` の辺ラベルへ合わせる。元の辺を端点対だけで重複除去しない。

## 採用する費用と有限検査

原本70–105行の二成分費用を、今回 `lambda=kappa=1` に固定する。有理数の独立検査では

```text
q_i = (x_i, sqrt(2)*z_i)
local(i) = (x_i^2-1)^2/4 + (z_i-x_i)^2
coupling(e) = ((x_i-sigma_e*x_j)^2 + 2*(z_i-sigma_e*z_j)^2)/2
F = sum_i local(i) + sum_e coupling(e)
```

として、`x_i,z_i` を `Fraction` で保持する。`sqrt(2)` の浮動小数点近似は使わない。`e3` だけ負の費用は次の証明書と照合する。

```text
F_negative = 1/2
  + sum_{i=4,5} [x_i^4/4 + x_i^2/2 + (z_i-x_i)^2 + 2*z_i^2]
  + sum_{i=0..3} local(i)
  + sum_{e in {0,1,4,5}} coupling(e)
```

右辺の定数以外は非負の項である。これはこのグラフ、この署名、固定係数に対する `1/2` の下界であり、鋭い下界、全グラフ・全係数に共通の下界、最小値の達成を意味しない。固定状態での反転差も原本62–68行に従い、`F_negative-F_positive = 2*q4·q5` として照合する。費用差は正にも負にもなる。

[check_laakso_signed.py](../../tools/check_laakso_signed.py) は、64署名と各64 spin 割当を全列挙する。平衡32署名では各2個の整合 spin、不平衡32署名では0個となることを、被覆の成分数と中央閉路の偶奇に照合する。各 spin を局所井戸に置いた4,096状態・署名の費用も計算するが、その有限集合での最小値を連続状態全体の最小値とは呼ばない。

エネルギーについては、12変数の疎多項式の係数を有理数で照合し、上の証明書と反転差の残差が零であることを検査する。さらに69件の有理数状態標本で非負項・下界・反転差を評価する。有限標本の成功を全実数の形式証明として扱わず、係数照合の計算記録と Lean の検証記録も分ける。

四つの変異対照は、平行辺の重複除去、被覆の辺を頂点同一視へ変更、符号反転後も旧接続を使う処理、結合費用の `1/2` の欠落である。標準ライブラリのみで再実行できる。

```console
python -B -X utf8 tools/check_laakso_signed.py --output verification/laakso-signed.json
```

JSON には全署名の結果、選んだ二署名、証明書の係数検査、費用増加・減少例、変異結果、checker・共有 builder・保存原文の SHA-256 を保存する。

## 先行する別模型との区別

Research の `04_History/Recent_2026-10-25/local_snapshots/context_review_2026-10-21/void_connection_checks.json` にある `15/16` の証明書は、三頂点の符号付き三角形と別の一成分ポテンシャルに対する保存結果である。今回の六頂点・中央平行辺・二成分費用の `1/2` と同じ命題ではない。

同じ保存記録の occurrence ID を持つ語の例は、表示語が戻っても内部の個体順序が戻らないという履歴の例である。それは本追加の二重被覆の sheet や辺署名ではない。また、三角形に面を付けて閉路を消す議論を、語の操作が恒等写像になる証明として使わない。

今回の対象に数値 ODE、緩和の収束、大域最小化、幾何的逆極限上の符号付き状態場、測度、Poincare 不等式、規則の自己変更は含まれない。原資料の一般論や過去の保存結果を、今回の具体的な接続で新たに検証した範囲へ拡張しない。
