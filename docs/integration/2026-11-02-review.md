## Review corrections

- PR #21 had a reproducible `Unknown identifier m` error after pattern matching
  substituted that identifier away. Its adapter retains the equation and
  substitutes the intended variable. Two strict lint warnings were also fixed.
- PR #16's integrated proof reproduced three unsolved goals as well as the
  unused-simp warnings reported by its prior CI. Default simplification changed
  `a.val = 0` into `a = 0`, preventing the supplied disjunction hypothesis from
  matching. Explicit `simp only` with the branch conditions repairs the proof
  without changing its statement. Exact corrections/hashes are in the manifest.
- PR #27 omitted its descriptive scope from the shared registry. The integrated
  source audit checks every retained supplement has a unique registration,
  namespace, provenance record and scope.
- F16 block decomposition uses independent row and column permutations. It is
  matrix equivalence; the integration does not infer similarity or spectrum
  preservation from it.
- The F0 no-two-cycle theorem requires idempotence, reconstruction and
  compatibility. A genuine two-cycle must violate at least one assumption.
  Extra history is a possible modification, not a proved necessity.
- Older PR-triggered workflows used implicit checkout of GitHub's synthesized
  merge commit. The new workflow checks out the proposed head explicitly and
  records proposed head, event SHA and actual checkout separately. Previous
  runs remain evidence for their actual sources, not retroactive evidence for
  this integration.

## New formal connections

`F0FutureMinimality.inc` adds six theorems. For idempotent `K`, update descent is
equivalent to `FutureEq K U x y ↔ K x = K y` for every pair of states. Thus the
current forgotten observation is a complete deterministic predictive
representation exactly when the update respects its fibers. The retained
three-state counterexample demonstrates failure at the next observation.

`ObservationRetractionPolarity.inc` adds 16 theorems and two definitions.
An exact encoder/decoder pair induces `P = encode ∘ decode` on the data space.
The proof identifies this F0 retraction's fixed points with realizable data,
its fibers with decoder fibers, and its Stops/Galois closure with the compatible
data fixed set under explicit nonempty/properness hypotheses. For the actual
complementary matrix decoder, opposite data `(w,-w)` give a concrete
incompatibility witness when `w ≠ 0`.

`RepresentationBridges.inc` adds seven theorems identifying the actual F16 real
and integer matrices, row/column maps, and the two retained polynomial energy
maps. It transfers the constructive F16 decoder to the alternative matrix API.
These are equalities of definitions and a theorem application, not conclusions
from matching finite examples.

## Reproduction and evidence boundary

```sh
python -m pip install pytest==9.2.0 numpy==2.5.4
cd lean
lake exe cache get
cd ..
python -B -X utf8 tools/verify.py --integration-only
```

The integrated entry point runs the source audit, repository tests, 15 exact or
finite Python checkers, offline ARC tests, and fresh joint/supplemental Lean
checks with `--trust=0` and all-declaration axiom audit. The allowed axioms remain
`propext`, `Classical.choice`, and `Quot.sound`. It does not suppress warnings or
permit `sorry`, `admit`, added axioms, `unsafe`, or `native_decide`.

Generated `verification/pr-integration.json` records the actual commit, dirty
state, individual commands and exit codes; `proof-only.json`, `main-result.json`
and their logs record actual proof totals, hashes and dependency revisions.
Successful execution must be established from those reports and the matching
Actions run. Source inclusion or isolated probes do not establish whole-tree
success.

The two historical Kaggle handoffs keep their original expected counts and
fixed source snapshots. Their workflows are manual and check out those
historical commits. The expanded tree is not mislabeled as either historical
package. No new Kaggle Saved Version, competition submission or public game
evaluation is performed by this integration. Historical delivery/rendering,
infinite-fractal theorems, physical dynamics, and unknown-game performance are
outside the verified claims.
