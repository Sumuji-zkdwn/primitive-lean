# 初期層からの導出可能性：何が問えるか（2026-11-07）

## 前提

- Lean が受理した定理は、どれも mathlib と自身の定義だけから証明されている。新しい定義の追加は保存的拡大なので、論理の意味での「初期 465 定理から導けるか」は、すべての定理について自明に成り立ち、何も区別しない。
- そこで次の 2 軸で分ける。
  1. **命題の語彙**：命題と定義をたどって、初期の対象に行き着くか。初期層に一度も触れずに mathlib だけから定義されたプロジェクトの定義を「新しい原始的対象」と呼ぶ。
  2. **証明の経路**：証明項の連鎖が、初期の定理を実際に経由しているか。
- 新しい対象だけで書かれた定理は 2 つに分ける。`new_objects_bridged` は、その新しい対象がどれも、別の定理の命題の中で初期の対象と（推移的に）一緒に現れるもの。一緒に現れることは等式を意味せず、定理によって関係づけられていることだけを示す。`new_objects_unbridged` は、そうした関係が一つもない対象を含むもの。
- `new_objects_unbridged` と `mathlib_only` の定理は、初期の対象について何も述べておらず、初期の対象との関係を示す定理もないので、「初期定理から導けるか」という問い自体が成り立たない。
- 語彙が `initial_only` で証明が初期定理を経由しない定理が、「初期定理から導けるかもしれないが示されていない」候補である。
- 名前の違う定数は、定義として等しくても別物として数える（初期の対象を作り直した写しは「新しい対象」に入る）。
