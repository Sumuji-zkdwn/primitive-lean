## Scope and exclusions

No gameplay action, time or RESET cap was introduced by this work. Validation-loop bounds
and GitHub job timeouts apply only to tests/builds, not to the submitted game runner.

The research 733 theorems were not rebuilt or bundled into this standard-library-only
recorded-graph runtime. A finite recorded-model proof is not a proof of unknown-game success.
This work did not execute the complete notebook on Kaggle, attach a dataset to a notebook,
make an official competition submission, or obtain an official score.
The v4 packaging cell has local unit-test coverage; the complete v4 notebook was not rerun
in this GitHub integration job. The job verifies the byte-identical three learning modules
with the actual packaged runtime, not every notebook cell.
