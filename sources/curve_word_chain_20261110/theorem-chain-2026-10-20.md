# クソ玉定理チェイン：到達点と停止境界

2026-10-20。対象ファイル：`原始の形式化.html` および `線形入力の使い方 (2).html`。

**範囲の注意**：原ファイルからの直接の帰結は【原文】、ここで追加した定義から証明した結果は【導出】、古典的な既知定理を使う箇所は【既知接続】と表示する。以下の円弧を文字として任意に接ぐ例は、一般には継ぎ目で曲率が跳ぶため、原文の `C^1` 接線角（曲率連続）という許容クラスから、**区分的滑らかな単位速度曲線**へ拡張した補助模型である。滑らかな継ぎ目を持つ曲線片も選べるが、円弧の具体的な有理係数は一般に変わる。証明が原文の境界値問題全体を解くことは意味しない。

## チェインの概略

1. 【原文】接線角 θ(s)、曲率 κ=θ′、曲線 γ(s)=∫e^{iθ(s)}ds、費用 F=∫ε(κ)ds。
2. 【原文】区間分割で曲線変位と費用が加算され、曲率の全関数＋初期情報から曲線を再構成する。
3. 【導出】曲線片の十分状態 S=(z,α,F) と接合積 ⋆ を定義する。
4. 【導出・既知接続】積は結合的で非可換。SE(2) の半直積に付随する費用加算である。
5. 【導出】AB−BA の終点差は一般に非零で、前後への接合で大きさを保つ。
6. 【原文＋導出】一方向の線形観測では不可視の語順差が、向き π/2 の接頭辞で再び可視になる。
7. 【導出】接頭辞を2種類使った文脈観測は S の等価性を完全判定する。
8. 【導出】語長 n の終点・費用・向きは再帰式で計算でき、単一文字の反復には厳密な等比級数公式がある。
9. 【導出】総回転角が有限巡回群に入ると、線形終点入力の最小化は有限状態の min-plus 行列積になる。
10. 【導出＋既知接続】長い語の費用/文字の極限は有限グラフの最小平均閉路に一致する。
11. 【導出】2円弧の明示例では 4 状態で最適周期語が転移し、閾値を厳密に出せる。
12. 【原文＋導出＋既知接続】最小値の入力依存だけを保持すると凸包しか残らない。3A3B の20語の場合に厳密な矩形凸包を計算する。
13. 【導出＋既知接続】log-sum-exp／分配関数に変更すると有限個の終点の分布と多重度まで復元できる。長い語では通常の行列のスペクトル半径へ接続する。
14. 【導出】到達できる絶対的な停止境界は S が同じ二語。任意の前後への同じ局所接合と線形終点観測では識別不能。内部形状を測る新しい作用が必要である。

## 定理A：非可換な曲線文字積

単位速度の各片 γ は、初期接線を水平に正規化して、複素数での変位 `z=∫exp(iθ(s)) ds`、実数の総接線角変化 `α=θ(L)−θ(0)`、曲率費用 `F=∫ε(κ(s))ds` を持つ。これを `S(γ)=(z,α,F)` とする。長さを管理したいときは L を付加すればよい。

```
(z,α,F) ⋆ (w,β,G) = (z+e^{iα}w, α+β, F+G).
```

結合律は、`(z+e^{iα}w)+e^{i(α+β)}v=z+e^{iα}(w+e^{iβ}v)` から従う。SE(2)=R²⋊SO(2) の群積と同じ幾何であり、α を実数値で保つのは回転角の持ち上げである。`F` は加法的であるが、これが全曲線の極小性を保証するものではない。円弧のように曲率が不連続な接合には区分的に滑らかなクラスを明記する。

**交換差**：

```
D(A,B) = z(AB)−z(BA)
       = (1−e^{iβ})z_A − (1−e^{iα})z_B.

z(PABS)−z(PBAS)=e^{iα(P)}D(A,B).
```

したがって差のノルムは前後の文脈によらず一定である。

## 定理B：費用も総回転角も等しく、語順だけで終点が違う

長さ h の定曲率左回り円弧 A（総角 π/2）、B（総角 3π/2）を選ぶ。

```
z_A = 2h(1+i)/π,       α_A=π/2,   c_A=π²/(8h),
z_B = 2h(−1+i)/(3π),  α_B=3π/2,  c_B=9π²/(8h).
```

費用はここでは古典二次密度 `ε(κ)=κ²/2`。

```
z_AB = 4h(1+i)/(3π),
z_BA = 4h(1−i)/(3π),
z_AB−z_BA = 8hi/(3π),
F_AB=F_BA=5π²/(4h),
α_AB=α_BA=2π.
```

定曲率の二片の接合では接線は連続だが曲率は跳ぶ。滑らかな版が必要なら、同じ積分角を持ち、端点ですべての導関数が0となる対称な曲率バンプを二つ選べばよい。θ_a(h−s)=a−θ_a(s) により z_a=e^{ia/2}ρ_a（ρ_a∈R）となる。a=π/2、b=3π/2 のとき交換差は `i√2(ρ_A−ρ_B)`。定曲率円弧への十分近い滑らかなバンプ近似なら ρ_A≠ρ_B のままで、交換差が厳密に虚数かつ非零、滑らかな接合を同時に満たす。ただしその正確な係数は円弧と異なる。

## 定理C：見えなくなった語順差が接頭辞で復活する

一方向の観測を `O(w)=(F_w, α_w, Re z_w)` とする。B の例から

```
O(AB)=O(BA),
Re[z(AAB)−z(ABA)] = −8h/(3π) ≠0.
```

【原文】入力差分は同じ状態で `E_u−E_v=(v−u)x`。したがって同じ線形入力の方向で `AAB` と `ABA` を測れば区別できる。ただし、入力の変更によって状態自体を動かした測定に原文の式をそのまま使ってはいけない。

**文脈完全性**：任意の語 v,w について `O(v)=O(w)` と `O(Av)=O(Aw)` が成り立つ必要十分条件は `S(v)=S(w)`。証明：最初の等式から F、α、Re z は一致。二つ目の等式の実部差は `Re(i(z_v−z_w))=−Im(z_v−z_w)` なので虚部も一致。逆向きは積の準同型性から従う。これはこの観測のもとでの「文脈等価性」の完全判定である。

## 定理D：長い語と有限状態化

`w=a_1...a_n` の場合、`α_0=0, z_0=0, F_0=0` から

```
z_{k+1}=z_k+e^{iα_k}z_{a_{k+1}},
α_{k+1}=α_k+α_{a_{k+1}},
F_{k+1}=F_k+c_{a_{k+1}}.
```

特に同じ文字 A の n 反復で、`e^{iα_A}≠1` なら

```
z(A^n)=z_A (1−e^{inα_A})/(1−e^{iα_A}).
```

総回転角が2πの整数倍ではない限り、反復語の終点は n によらず有界でありうる（長さと正の曲率費用は n 倍）。α_A/(2π) が有理なら反復の一部が閉じ、無理なら方向の集合は円上で稠密となる（ただし単純曲線性や平衡状態を意味しない）。

各文字の α が 2π/q の整数倍なら向き `j∈Z/qZ` の有限状態を持つ。入力 `u∈R²` の線形終点費用を `J_u(w)=F_w−u·z(w)` と定義すると、一文字の重みは

```
c_a−u·(R_(2πj/q) z_a),   j→j+k_a (mod q).
```

最適 n 文字はこの重みによる min-plus 行列の n 乗で厳密に得られる。非線形な終点費用や自己回避制約では通常 z や通過履歴も状態に必要であり、この4状態削減は適用できない。

## 定理E：具体的な4状態模型の最適周期と切替点

上記の円弧 A,B は位相変化が j→j+1 と j→j−1 (mod 4)。入力は x 方向の u とする。1文字の重みは `c_a−u Re(i^j z_a)`。全状態が到達可能である。

単純有向閉路は、4文字の全A、4文字の全B、および隣接状態の AB/BA の2文字閉路しかない。1文字当たり費用はそれぞれ

```
A閉路：       π²/(8h),
B閉路：       9π²/(8h),
最良のAB閉路： 5π²/(8h) − 2h|u|/(3π).
```

任意の長い経路は有限個の閉路と長さ高々3の単純路へ分解できるため、最小1文字平均費用は最小閉路平均へ収束する（Karp の最小平均閉路問題）。従って

```
μ(u)=lim_{n→∞} (1/n) min_{|w|=n}J_u(w)
    = min{π²/(8h), 5π²/(8h)−2h|u|/(3π)}.
```

切替閾値は

```
|u| = u_* = 3π³/(4h²).
```

`|u|<u_*` では純 A の4周期が最良、`|u|>u_*` では適切な向きの AB/BA の2周期が最良（長語の平均費用の意味）。閾値では両者が同率。この明示式と曲線入力の実際の最適化は区分的に滑らかな補助模型についての結果である。動的ヒステリシスを主張しない。

## 定理F：最小値だけを観測すると凸包に忘却される

【原文】四次 V(x)=λx⁴/4+rx²/2 の `m(u)=min_x[V(x)−ux]` は `−V*(u)` である。r<0 なら `a=√(−r/λ)` とおいて

```
V**(x)=−r²/(4λ)             if |x|≤a,
       V(x)                 if |x|≥a.
```

すなわち中央障壁は全入力 u の最小値 m(u) から復元できない。これは Fenchel–Moreau の凸二重共役の具体例。u=0 では大域最小値選択が±aで切り替わるが、局所停留枝の消失は別の値 `±2(−r)^(3/2)/(3√(3λ))` である。後者に実際のヒステリシスを対応させるには枝追跡規則が必要。

【導出】費用の同じ固定多重集合の語を考え、終点集合 X と K=conv(X) を置く。全方向の入力による最小値は厳密に

```
m(u)=F_fixed − max_{z∈X}u·z = F_fixed−h_K(u).
```

したがって全 u を知っても K までしか復元できず、内点・個数・語順は残らない。

**完全列挙による強い例**：A を3つ、Bを3つ使う20語について、`ξ=2h/(3π)` で割った終点は12種類（複数語が同じ終点に到着する）。4隅は `(-2,-6),(-2,6),(6,-6),(6,6)`、凸包は `[-2,6]×[-6,6]`。総曲率費用は `F=15π²/(4h)` で全20語同じだから

```
m_{3A3B}(u_x,u_y)
 = 15π²/(4h) − (2h/(3π))(2u_x+4|u_x|+6|u_y|).
```

全入力の最小値関数を知っても、4隅以外の点が何個あるかは分からない。実際の12種類と重複は付属検算コードで列挙。

## 定理G：有限温度で復元される情報、極限で再び失われる情報

固定語集合 W_n に対し β>0 で

```
Z_n(u,β) = Σ_{w∈W_n} exp(−β[F_w−u·z_w]),
q_n(u,β)=−(1/β)log Z_n(u,β).
```

語が N 個のとき

```
m_n(u)−(log N)/β ≤ q_n(u,β) ≤ m_n(u).
```

固定 β で全実数方向の u にわたる Z_n を厳密に知れば、有限測度 `μ=Σ_w exp(−βF_w)δ_(z_w)` の多変数ラプラス変換を知ることになり、測度の一意性より **終点と重複の重み** を復元できる。しかし全く同じ (z,F) の語ラベルは区別できない。有限温度化はラベルの完全復元ではない。

上の4状態模型なら、非負行列

```
M_β(u)[j,k] = Σ_{a: j+k_a=k} exp{−β[c_a−u·R_jz_a]}
```

について `Z_n=e_0ᵀ M_β(u)^n 1` と計算でき、生成関数 `Σ_n t^n Z_n=e_0ᵀ(I−t M_β(u))^(−1)1` は t の有理関数である。有限グラフが強連結なので、Perron–Frobenius より

```
f_β(u)=lim_{n→∞} q_n(u,β)/n=−(1/β)log ρ(M_β(u)).
```

一方 `W_n={A,B}^n` は N=2^n。前記の誤差評価を n で割ると

```
μ(u)−(log2)/β ≤ f_β(u) ≤ μ(u),
lim_{β→∞} f_β(u)=μ(u).
```

有限温度の通常の行列スペクトル半径が、零温度の min-plus 閉路平均へ連続的につながった。これは重み付きオートマトン・統計力学・トロピカル計算を結ぶ既知の枠組みへの具体的な導出であり、新しい一般定理の優先権を意味しない。

`ξ=2h/(3π)` と `c₀=π²/(8h)` を単位にすると円弧 A の端点増分は `3+3i`、B の端点増分は `−1+i`、費用はそれぞれ `1,9`。位相は4種類だから、各遷移に `X^(Δx/ξ)Y^(Δy/ξ)Q^(c/c₀)` の単項式を与えた4×4 Laurent 多項式行列 `W(X,Y,Q)` で、`e₀ᵀ(I−tW)^(−1)1` は**全語長の終点・費用の正確な多変数有理母関数**になる。

## 停止境界と未解決の課題

**厳密な停止境界1：** 二つの語 w,v で S(w)=S(v) なら、すべての同一接頭辞 P・接尾辞 Q に対し `S(PwQ)=S(PvQ)`。したがって終点、接線総回転、曲率の加法費用とそれらへの線形入力だけでは区別できない。実際、3A3B の20語には同じ S の異なる語が複数存在する。語の途中を測る、自己交差、空間との相互作用、非局所的エネルギー等を新たに追加しなければこの差は検出できない。

**停止境界2：** `α/(2π)` が有理でない文字があると、一般には有限個の向き状態に閉じず、4×4 行列への削減は成立しない。近似、特殊対称性、無限状態演算子が必要。

**停止境界3：** エネルギーから動的安定性・ヒステリシス・記憶更新・自己増殖を一意に導けない。動力学／履歴を定義する必要がある。

**停止境界4：** 区分的円弧模型の厳密式を、そのまま滑らかな古典エラスティカの拘束付き停留解へ移植できない。曲率の継ぎ目、第一・第二変分、端点拘束、同じ E-L 方程式の成立が別途必要。

**停止境界5：** 各命題は既知の SE(2)、凸共役、重み付きオートマトン、閉路平均、ラプラス変換と整合する。これらの接続を一つの具体例に合成したことと、数学的に新しい一般定理を証明したことは区別する。

## 追加チェインH：面積は曲線文字の2-コサイクルになる

【原文】`線形入力の使い方 (2).html` 第8.5–8.8節は符号付き面積

```
A[γ]= 1/2∫(x dy − y dx)
```

を導入し、曲げエネルギー `k/2 ∫κ²ds + p A` の停留性から

```
kκ″+(k/2)κ³−σκ=p,
λ=1/2,  r=−σ/k, u=p/k
```

を導く。この面積は原始の最初の公理に必ず含まれるわけではなく、追加された幾何学的汎関数である。

【導出】始点を原点にそろえ、前節の文字状態に符号付き面積 A を加えると、接合則は

```
(z,α,F,A)⋆(w,β,G,B)
 = (z+e^{iα}w, α+β, F+G,
    A+B+(1/2)Im(conj(z)e^{iα}w)).
```

最後の追加項 `Ω(g,h)=1/2 det(z,R_α w)` は2-コサイクルである。理由は面積積分で平行移動した曲線片には、始点変位とその片の変位の外積の半分が余分に加わるため。`Ω(g,h)+Ω(gh,k)=Ω(h,k)+Ω(g,hk)` は回転が外積を保存することから従い、接合の結合法則が面積を付加しても保たれる。SE(2) の幾何への Heisenberg 型中心拡張として理解できる。これは単なる「費用 F をもう一個足す」とは違い、接合時に非自明な交差項が生じる。

## 追加チェインI：第1階層の衝突が第2階層で解ける

円弧模型で、各文字の面積の内在的寄与は同じ個数なら同じであり、順序に依存する差は上記の Ω だけで決まる。`ξ=2h/(3π)` とし、二倍の順序依存面積を `D=2(A−∑A_文字)/ξ²` とすると D は整数になる。接合ごとに

```
D_{n+1}=D_n+det(z_n/ξ, i^{j_n}z_{次文字}/ξ)
```

と更新する。20個の `3A3B` 語は第1階層 `(z,α,F)` では12状態に衝突するが、第2階層 `(z,α,F,A)` では20状態すべて異なる（プログラムで整数全列挙）。具体的には

```
S(AABBBA)=S(BAAABB),
D(AABBBA)=8,
D(BAAABB)=24,
A(BAAABB)−A(AABBBA)=8 ξ²=32 h²/(9π²).
```

つまり、先ほど「全ての文脈で見えない」と判断した2語が、面積観測を一つ加えただけで識別可能になる。これは定理Cと矛盾しない。定理Cの完全性は、終点・総回転角・局所費用の観測と接合に関するものだったからである。

## 追加チェインJ：第2階層も衝突し、第3階層で分かれる

`4A4B` の長さ8の語は70個あり、上の面積までの状態では50種類にとどまる。具体的に

```
w=AAAABBBB,      v=AAABBBBA
z_w=z_v=0,
α_w=α_v=8π,
F_w=F_v=5π²/h,
A_w=A_v=16h²/(3π).
```

2本は閉曲線である。どちらもAの円を1周、Bの円を3周するが、Bの円を挿入する位置が違う。A円の半径 `R_A=2h/π`、B円の半径 `R_B=2h/(3π)` とする。

- w のB円は始点0で接線右向き、円の中心のx座標は0。
- v のB円は A を3本接いだ位置 `R_A(−1+i)` で接線下向き、円の中心のx座標は `−R_A+R_B=−2R_B`。

A円の軌跡は両者同じなので、三次の線積分 `I_3(γ)=∮x²dy` の差は、B円の面積3πR_B²の一次モーメント差である。Green の公式 `∮ x² dy=2∬x dA` から

```
I_3(v)−I_3(w)
=2(3π R_B²)(−2R_B)
=−32h³/(9π²) ≠0.
```

**終点・角度・曲率費用・符号付き面積の全部が同じでも、三次の曲線観測で文字列の差が復活する**。これは直接の厳密計算であり、第三階層の必要性を具体例が保証している。

## 追加チェインK：Chenの反復積分とpath signature

曲線の移動量 dγ=(dx,dy) を使い、`S_1(γ)=∫dγ=z`、`S_2(γ)=∫_{s<t}dγ_s⊗dγ_t`、一般に `S_m(γ)=∫_{t_1<...<t_m}dγ_{t_1}⊗...⊗dγ_{t_m}` と置く。これらすべてを並べたものが **path signature**。S₂ の反対称部分が符号付き面積、S₃ は前節の三次面積モーメントを含む。

【既知接続】接合で回転を合わせた場合には、Chenの積の公式

```
Sig(AB)=Sig(A) ⊗ (R_{α_A}·Sig(B))
```

が成り立つ。二階では `S₂(AB)=S₂(A)+R^{⊗2}S₂(B)+z_A⊗Rz_B` であり、直前の面積の2-コサイクルはこの反対称部分にほかならない。

この系列を m=1,2,3,... へ延ばす操作自体には有限の打ち切りがない。全階層まで保持すれば、有限長の有界変動曲線の**全signatureはtree-like同値まで曲線を決定する**というHambly–Lyons (2010) の既知定理に到達する。これは同一のパラメータ化時刻やtree-likeの往復部分まで完全再現するという主張ではない。したがって曲線の内部を保持する操作体系の自然な到達点が、平面曲線の積分署名という**非可換形式級数**になる。

この意味で、今回の「限界」は finite-order hierarchy の終端ではなく、必要な分解能を階層的に増やす際の **既知の普遍的な記述先** の発見である。非自明なのは、エラスティカの費用・面積拘束・線形入力から、具体的な衝突語を経由してこの構造へ達したことにある。

## 追加チェインL：相似則で階層全体を一度に制御する

【原文】相似倍率 σ>0 では長さが σ 倍、曲率が 1/σ 倍、二次曲げ費用は 1/σ 倍。前節の面積は σ² 倍、三次モーメントは σ³ 倍。終点線形入力を併用すると、同じ語集合について

```
J^{(σh)}_u(w) = σ^(−1) J^{(h)}_(σ²u)(w),
μ_{σh}(u)=σ^(−1)μ_h(σ²u),
Z^{(σh)}_n(u,β)=Z^{(h)}_n(σ²u,β/σ).
```

よって転移閾値が `u_*(h)=3π³/(4h²)` に従う理由は、この相似共変性だけからも確認できる。一般化した面積入力 pA や高階入力では、各入力の共変次数を合わせなければ同じモデルを比較できない。

## 本当に止まる場所（最終改訂）

- 0–2階までなら有限次元の `(z,α,F,A)` 状態と面積コサイクル。だが8文字ですでに識別不能な語が現れる。
- 3階まで上げるとこの特定の衝突は解消するが、任意の語が識別されるとまでは言えない。高階では反復積分を順に追加できる。
- **全階のpath signature** で tree-like 同値まで復元できる（Hambly–Lyons の既知定理）。tree-likeに関する非識別性は署名だけでは消えない。
- 原HTMLの固定端点問題では終点への線形入力は境界定数で、曲線選別に効かない。文字列模型の最適化では端点を変えてよい新しい許容集合を導入したことを忘れてはならない。
- 署名の全階層を持つことと、物理時間に沿う更新則や履歴選択を持つことも違う。更新則の導入なしに「自己増殖が必然」とは言えない。

追加の既知数学：Hambly–Lyons, *Uniqueness for the signature of a path of bounded variation and the reduced path group*, Annals of Mathematics 171 (2010), 109–167: https://annals.math.princeton.edu/2010/171-1/p02

## 追加チェインM：log-signatureは自由リー代数に入る

Chenの積の公式とshuffle関係から、全path signatureの形式的対数は生成子 X（x軸増分）、Y（y軸増分）上の自由リー代数の元となる。【既知接続】

```
log Sig(γ)=z_x X+z_y Y+A[ X,Y ]+(3階以上の入れ子交換子).
```

`[X,Y]=XY−YX`。二つの曲線のlog-signatureを接ぐには（後片の角度を回転させた後）Baker–Campbell–Hausdorff (BCH) 級数を使う。したがって「文字の交換が曲線として残す違い」は、一次の変位と二次の面積だけでなく、三次以上の入れ子交換子として階層的に記述される。

古典的な参照：K.-T. Chen の定理を含む *A Primer on the Signature Method in Machine Learning* のChen identity・log-signature節： https://link.springer.com/chapter/10.1007/978-3-031-97239-3_1
